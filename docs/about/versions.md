# 버전과 변경 이력

## 두 가지 버전

| 구분 | 현재 | 뜻 |
| --- | --- | --- |
| **교재 판** | V1 | 인쇄 교재 《처음 시작하는 AI 영상 제작》의 판. 판이 바뀌면 주소가 `/v2/`처럼 새로 생기고, V1 페이지는 그대로 남습니다. |
| **교재 개정** | 1.0.0-preview | 같은 판 안의 수정 번호. 공개 전 검토판입니다. |
| **FECINE 서비스 버전** | v1.38.0 | 원고의 화면 이름·버튼·기능을 확인한 FECINE 버전. 모든 페이지 위쪽에 표시합니다. |

FECINE이 업데이트되어 화면이 바뀌면, 바뀐 장과 [부록 A·D](/v1/appendix/)만 고치고 교재 개정 번호를 올립니다. 새 기능은 출시된 뒤에만 본문에 넣고, 그 전까지는 [부록 D 향후 기능](/v1/appendix/d-future)에 둡니다.

## 주소 규칙

- 교재 본문: `/v1/chapters/…`, PART 소개: `/v1/parts/…`
- 이론·자료: `/v1/foundations/`, `/v1/ai-basics/`, `/v1/models/`, `/v1/resources/`, `/v1/appendix/`
- 판과 상관없는 안내: `/guide/`, `/about/`
