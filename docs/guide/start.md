# 어디서 시작할까요?

FECINE ACADEMY는 로그인 없이 누구나 무료로 읽는 온라인 교재입니다. 인쇄 교재 《처음 시작하는 AI 영상 제작》 V1의 원고를 그대로 옮겼고, FECINE v1.74.0 화면을 기준으로 씁니다. FECINE 홈페이지 위쪽 메뉴의 `아카데미`에서도 이 교재로 들어올 수 있습니다.

## 나에게 맞는 시작점

| 이런 분이라면 | 여기서 시작하세요 | 이어서 |
| --- | --- | --- |
| AI 영상이 처음이고, 바로 만들어 보고 싶다 | [1장 AI 영상 제작이란?](/v1/chapters/01-ai-video-production) | PART 01 → PART 08 순서대로 |
| 영상 제작 경험은 있고, FECINE 사용법이 궁금하다 | [14장 FECINE 제작 흐름](/v1/chapters/14-production-flow) | [AI 기술 기초](/v1/ai-basics/)를 함께 |
| 영상 언어부터 차근차근 배우고 싶다 | [영상 제작 기초](/v1/foundations/) | [AI 기술 기초](/v1/ai-basics/) → PART 01 |
| 어떤 AI 모델을 써야 할지 고민이다 | [AI 모델 가이드](/v1/models/) | [부록 A 모델과 비용](/v1/appendix/a-models-cost) |
| 강의를 준비하는 강사·파트너사다 | [파트너사 강의 진행 가이드](/v1/instructor/) | [수업 예산 짜기](/v1/instructor/budget), [인쇄 교재 목차와 커리큘럼](/v1/about/curriculum) |

## 교재 구성

- **PART 01–08 (교재)** FECINE으로 직접 만들며 배우는 실습 과정입니다. 예제 작품 「비 오는 정류장」을 처음부터 끝까지 이어서 만듭니다.
- **영상 제작 기초 · AI 기술 기초 · AI 모델 가이드** 도구가 바뀌어도 오래 쓰는 이론입니다. 실습 중 모르는 개념이 나오면 이곳을 찾아보세요.
- **실습 자료실** 본문의 예제 대본·프롬프트, 체크리스트, 다운로드 파일을 모았습니다.
- **부록** 모델·요금처럼 자주 바뀌는 정보, 메뉴·버튼 찾아보기, 용어집, 향후 기능을 모았습니다.

## 장 번호에 대하여

장 번호(1장–33장)는 인쇄 교재의 번호입니다. 온라인 교재는 실습 과정을 PART 01–08로 묶고, 이론 장(2–13장)은 영상 제작 기초·AI 기술 기초·AI 모델 가이드 메뉴에 두었습니다. 본문에 “13장 참고”처럼 다른 장이 나오면 왼쪽 목차나 [집필 현황](/about/status)에서 찾을 수 있습니다.

## 각 장을 읽는 법

모든 장은 네 단계로 되어 있습니다.

| 단계 | 담는 내용 |
| --- | --- |
| **WHY** | 장을 여는 질문, 이번 장에서 배울 내용, 완성 결과물 |
| **HOW** | 영상 기술·AI 개념, FECINE 기능과 화면 따라 하기 (TIP · NOTE · 주의) |
| **PRACTICE** | 실제 제작 실습, 복사해 쓰는 예제, 결과 확인, COST(비용) |
| **REVIEW** | 체크리스트, 문제 해결 표, 확인 문제, 응용 과제 |

::: info 표시 읽는 법
- <Badge type="tip" text="게시" /> 집필을 마친 페이지입니다.
- <Badge type="warning" text="작성 예정" /> 집필 계획만 있는 페이지입니다. 완성된 내용이 아닙니다.
- <Badge type="warning" text="자료 준비 중" /> 실제로 생성한 결과 이미지·영상을 준비하고 있는 자리입니다. 임의로 만든 그림을 넣지 않습니다.
- <Badge type="info" text="화면 갱신 예정" /> 최신 서비스 화면으로 다시 찍을 캡처입니다.
:::

::: tip 비용 안내
FECINE에서 AI로 이미지·영상을 만들면 크레딧이 차감됩니다. 비용이 드는 실습에는 **COST** 상자가 있으니 실습 전에 꼭 읽어 보세요. 요금은 [부록 A](/v1/appendix/a-models-cost)와 FECINE 화면에 표시된 값이 기준입니다. 크레딧 없이 할 수 있는 범위는 [무료로 해 볼 수 있는 범위](/guide/free)에 정리했습니다.
:::
