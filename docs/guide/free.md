# 무료로 해 볼 수 있는 범위

이 교재는 누구나 무료로 읽을 수 있습니다. FECINE에서 따라 할 때 크레딧이 드는 것은 **AI가 무언가를 만들어 낼 때**(글·이미지·영상 생성)와 **합친 영상을 내보낼 때**입니다. 기획, 직접 쓰기, 장면 구성, 편집은 크레딧 없이 할 수 있습니다.

::: tip 먼저 알아 둘 것
- 가입하면 무료 크레딧이 지급됩니다. 금액은 운영 설정에 따라 다르며, 현재 값은 [부록 A](/v1/appendix/a-models-cost)와 FECINE 화면에서 확인하세요.
- 크레딧이 드는 버튼 옆에는 예상 크레딧이 표시됩니다. 누르기 전에 확인하는 습관을 들이세요([13장](/v1/chapters/13-credits-and-cost)).
:::

## 한눈에 보기 (FECINE v1.38.0)

| 무료 | 크레딧 필요 |
| --- | --- |
| 작품 만들기(새 작품 · 템플릿), 작품 설정 | 프리소스 원작으로 작품 만들기(구성 비용 표시) |
| 스토리에서 회차·장면·원고 직접 쓰기 | AI로 장면 나누기 · AI로 쓰기 · AI로 다듬기, AI 어시스턴트 |
| 캐릭터·배경·소품의 설명 쓰기, **내 이미지 업로드** | AI로 작품 구성 |
| 오디오 파일 업로드, 캐릭터 보이스 연결 | 이미지 생성(캐릭터 · 배경 · 소품 · 캐릭터 시트 · 장면 프레임) |
| 스토리보드 장면 구성, 카메라·스타일 설정 | 원고로 프롬프트 만들기 |
| 가지고 있는 영상을 **영상 넣기**로 테이크에 넣기 | 장면 영상 생성(테이크마다) |
| 편집 전부(트림 · 전환 · 자막 · 음악 · 카드 · 색보정) | 합친 영상 내보내기 |
| 장면 영상 **로고 포함 다운로드**, **상태 다시 가져오기** | 로고 없이 내보내기 · 장면 영상 로고 없이 다운로드(받을 때마다) |

## 크레딧 없이 해 보는 학습 경로

1. **이론 먼저** — 영상 제작 기초와 AI 기술 기초를 읽고, 각 장의 기획 실습(기획 메모, 분해표, 룩 조합표, 소리 설계 메모)을 [실습 워크북](/v1/resources/workbook)에 채웁니다.
2. **작품 뼈대 만들기** — 새 작품을 만들고([16장](/v1/chapters/16-new-work)), 스토리에서 장면 3개와 원고를 직접 씁니다([17장](/v1/chapters/17-story)).
3. **장면 구성까지** — 캐릭터·배경은 설명만 쓰거나 직접 준비한 이미지를 올리고, 스토리보드에서 장면·카메라·스타일을 채웁니다([24장](/v1/chapters/24-storyboard)). 영상을 생성하기 직전까지 모두 무료입니다.
4. **편집 연습** — 직접 찍었거나 사용 권리가 있는 영상을 **영상 넣기**로 장면에 넣으면, 편집·자막·음악·색보정을 크레딧 없이 연습할 수 있습니다([27장](/v1/chapters/27-video-generation) NOTE, [28장](/v1/chapters/28-editing)).

::: info NOTE
합친 영상을 파일로 받는 **내보내기**는 요금이 있습니다. 크레딧 없이 결과를 받아 보려면 장면 영상을 하나씩 **로고 포함 다운로드**로 받을 수 있습니다([30장](/v1/chapters/30-export-publish)).
:::

## 크레딧을 쓸 때

AI 생성을 시작할 때는 [31장 크레딧 아끼는 제작 습관](/v1/chapters/31-saving-credits)의 순서를 따르세요. 짧고 낮은 해상도로 먼저 테스트하고, 한 번에 하나만 바꾸고, 다시 만들기 전에 편집으로 고칠 수 있는지 먼저 봅니다. 비용과 결과는 워크북의 **생성 기록지**에 적어 두면 다음 작품의 예산을 세우기 쉽습니다.
