# 연속 프로젝트 「비 오는 정류장」

교재 전체가 하나의 예제 작품을 이어서 만듭니다. 장마다 만든 결과물이 다음 장의 재료가 되므로, 처음 배울 때는 순서대로 따라 하는 것을 권합니다.

::: info 예제 작품 설정
- **설정** 16:9 · 720p · 실사 · 시네마틱 · 영화
- **등장인물** 수아, 도윤
- **씬** 1 비 오는 버스 정류장 · 2 건네진 우산 · 3 함께 기다리는 버스
:::

## 단계별 학습 흐름

| 단계 | 장 | 이 단계에서 만드는 것 |
| --- | --- | --- |
| 1. 기획 | [1장](/v1/chapters/01-ai-video-production) · [7장](/v1/chapters/07-story-structure) | 첫 영상 기획 메모, 3막 구조 기획서 |
| | [16장](/v1/chapters/16-new-work) | 「비 오는 정류장」 작품 (16:9 · 720p · 실사 · 시네마틱 · 영화) |
| | [17장](/v1/chapters/17-story) · [18장](/v1/chapters/18-ai-writing) | 1화의 씬 3개와 씬 대본, 등장인물 수아·도윤 등록, 씬 대본 다듬기 |
| 2. 등장인물 | [20장](/v1/chapters/20-characters) | 수아·도윤 대표 이미지 |
| | [21장](/v1/chapters/21-backgrounds-props) | 배경 ‘비 오는 버스 정류장’, 소품 ‘검은 우산’ |
| | [22장](/v1/chapters/22-character-sheets) · [23장](/v1/chapters/23-character-voice) | 수아 캐릭터 시트, 보이스 연결 |
| 3. 콘티 | [24장](/v1/chapters/24-storyboard) | 등장 요소가 모두 연결된 씬 3개 |

| | [26장](/v1/chapters/26-scene-frames) | 씬 1 시작 프레임 |
| 4. 영상 생성 | [27장](/v1/chapters/27-video-generation) | 씬 1의 테이크 2개 이상과 고른 테이크 |
| 5. 편집 | [28장](/v1/chapters/28-editing) · [29장](/v1/chapters/29-subtitles-music-cards) | 편집본 v1(트림·전환), 편집본 v2(자막·빗소리·배경음악·카드·룩) |
| 6. 내보내기 | [30장](/v1/chapters/30-export-publish) | 완성 MP4, 세로 9:16 버전, (선택) 채널 게시 요청 |

본문에 실린 결과 이미지·영상(결과 01-A, 27-A, 30-A 등)은 이 교재의 예제 프롬프트로 FECINE에서 **실제로 생성한 것만** 싣습니다. 아직 생성하지 않은 결과는 <Badge type="warning" text="자료 준비 중" />으로 표시해 두었습니다.
