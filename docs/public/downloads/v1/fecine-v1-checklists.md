# 처음 시작하는 AI 영상 제작 V1 — 체크리스트

FECINE v1.38.0 기준 · 2026-11-01


## 1장 AI 영상 제작이란?

- [ ] AI 영상 제작을 ‘프롬프트로 지시하면 AI가 장면을 만드는 방식’이라고 설명할 수 있다.
- [ ] 홈페이지 [워크플로]의 다섯 탭 이름을 순서대로 말할 수 있다.
- [ ] 가입하면 무료 크레딧을 받는다는 것을 확인했다.
- [ ] 장면 3개가 들어간 기획 메모를 완성했고, 비교표 다섯 칸을 모두 채웠다.

## 2장 기존 영상 제작과 AI 영상 제작의 차이

- [ ] 기존 제작의 세 단계와 AI 제작의 다섯 단계를 말할 수 있다.
- [ ] AI 제작에서 ‘비주얼’ 단계가 따로 필요한 이유를 설명할 수 있다.
- [ ] 제작 과정 비교표를 채웠다.

## 3장 영상의 기본 단위: 샷·컷·장면·시퀀스

- [ ] 샷과 컷의 차이를 한 문장으로 설명할 수 있다.
- [ ] FECINE의 ‘장면’이 한 번 생성하는 클립이라는 것을 안다.
- [ ] 분해표를 완성했다.

## 4장 카메라 언어: 샷 크기·앵글·움직임·렌즈

- [ ] 샷 크기 7가지를 가까운 순서로 말할 수 있다.
- [ ] 로우 앵글과 하이 앵글이 주는 느낌을 구분한다.
- [ ] 카메라 탭에서 항목을 고르고 모두 자동으로로 되돌릴 수 있다.

## 5장 빛·색·분위기

- [ ] 역광과 옆에서 오는 빛의 차이를 말할 수 있다.
- [ ] 작품 스타일, 장면 룩, 색보정이 각각 언제 쓰이는지 안다.
- [ ] 예제에 맞는 룩 조합을 골랐다.

## 6장 소리: 대사·음악·효과음

- [ ] 대사·내레이션·앰비언스·효과음·음악을 구분한다.
- [ ] 대사 음성은 영상 모델이 만든다는 것을 안다.
- [ ] 소리 설계 메모를 완성했다.

## 7장 이야기 구조와 스토리보드

- [ ] 내 작품의 로그라인을 한 문장으로 말할 수 있다.
- [ ] 1막과 3막의 차이(무엇이 바뀌었는가)를 설명할 수 있다.
- [ ] 기획서를 완성했다.

## 8장 AI는 어떻게 그림과 영상을 만드나

- [ ] AI가 결과를 ‘검색’이 아니라 ‘생성’한다는 것을 설명할 수 있다.
- [ ] 같은 프롬프트에도 결과가 다른 이유를 말할 수 있다.
- [ ] 참조와 첫 프레임의 차이를 안다.

## 9장 프롬프트가 결과를 바꾸는 방식

- [ ] 프롬프트 다섯 요소를 말할 수 있다.
- [ ] 구조 칸에 나눠 쓸 수 있다.
- [ ] 프롬프트 C의 문제점 세 가지를 찾았다.

## 10장 일관성: 같은 인물을 계속 등장시키는 법

- [ ] 일관성을 지키는 네 가지 방법을 말할 수 있다.
- [ ] 장면 프레임 1장과 2장 이상의 차이를 안다.
- [ ] 체크리스트를 완성했다.

## 11장 AI 결과물 평가, 안전, 저작권

- [ ] 테이크 평가 기준 네 가지를 말할 수 있다.
- [ ] 아쉬워요 이유에 따라 어느 탭을 고칠지 안다.
- [ ] 실존 인물을 쓰려면 무엇이 필요한지 안다.

## 12장 모델을 고르는 7가지 기준

- [ ] 모델을 고르는 일곱 가지 기준을 말할 수 있다.
- [ ] 모델 탭에서 길이 범위·예상 크레딧·예상 시간을 읽을 수 있다.
- [ ] 목적별 선택표를 채웠다.

## 13장 크레딧과 비용 계산

- [ ] 무료 작업 세 가지와 유료 작업 세 가지를 말할 수 있다.
- [ ] 사용량·결제에서 작품별 사용을 찾을 수 있다.
- [ ] 예산표를 채웠다.

## 14장 FECINE 제작 흐름과 두 가지 시작 경로

- [ ] 필수 모듈과 선택 모듈을 구분할 수 있다.
- [ ] 스토리와 AI 구성의 관계를 설명할 수 있다.
- [ ] 내 제작 흐름 지도를 그렸다.

## 15장 로그인·기본 화면·튜토리얼

- [ ] Google 계정으로 로그인했다.
- [ ] 새 작품·AI 작업·크레딧 잔액·언어의 위치를 안다.
- [ ] 튜토리얼을 끝까지 마쳤다.

## 16장 새 작품과 작품 설정

- [ ] 작품명을 더블클릭해 바꿨다.
- [ ] 설정 변경에서 네 가지 설정을 정했다.
- [ ] 작품정보의 설정 칩에 16:9 · 720p · 실사 · 시네마틱 · 영화가 보인다.

## 17장 스토리에서 회차·장면·원고 쓰기

- [ ] 장면 3개가 순서대로 있고 장면마다 요약·원고가 있다. (회차 목록에 ‘원고 3/3’)
- [ ] 수아·도윤이 캐릭터로 등록됐다.
- [ ] 이 회차 스토리보드 열기에서 같은 장면 3개가 보인다.

## 18장 AI로 원고 쓰고 다듬기

- [ ] 비교를 보고 적용할지 스스로 정했다.
- [ ] 되돌리기의 위치를 안다.
- [ ] 어시스턴트는 제안만 한다는 것을 안다.

## 19장 [선택] 대본 파일이 있을 때: AI 구성

- [ ] 대본 파일을 올리고 읽을 범위를 정할 수 있다.
- [ ] 1단계와 2단계의 차이를 안다.
- [ ] AI 구성은 이미지를 만들지 않는다는 것을 안다.

## 20장 캐릭터 만들기

- [ ] 수아·도윤 카드에 대표 이미지가 보인다.
- [ ] 새 캐릭터의 세 가지 이미지 소스를 안다.
- [ ] 대표 이미지를 바꾸는 방법(히스토리)을 안다.

## 21장 배경과 소품 만들기

- [ ] 배경·소품 탭에 각각 이미지가 하나씩 있다.
- [ ] 배경 이미지에 사람이 없다.
- [ ] 라이브러리의 세 범위를 안다.

## 22장 캐릭터 시트와 의상으로 일관성 지키기

- [ ] 수아의 시트 칸이 모두 같은 사람으로 보인다.
- [ ] 의상 추가와 변형 선택의 관계를 안다.
- [ ] 대표 이미지와 캐릭터 시트의 차이를 안다.

## 23장 캐릭터 목소리 연결

- [ ] 오디오 목록에 파일이 있고 재생된다.
- [ ] 수아에 보이스가 연결됐다.
- [ ] TTS가 아니라 ‘참조’라는 것을 안다.

## 24장 스토리보드에서 장면 구성하기

- [ ] 장면 3개 모두 캐릭터·배경이 연결됐다.
- [ ] 대사마다 말하는 인물이 있다.
- [ ] 장면 복제·장면 삭제의 위치를 안다.

## 25장 카메라와 스타일 지정하기

- [ ] 장면 3개에 프롬프트·카메라·룩이 모두 있다.
- [ ] 장면 2가 샷 2개로 나뉘고 샷별 카메라가 있다.
- [ ] ‘생성할 때 프롬프트 끝에 붙는 문장’을 확인했다.

## 26장 장면 프레임으로 시작 화면 정하기

- [ ] 장면 1의 상태가 프레임 1장이다.
- [ ] 프레임 1장과 2–4장의 차이를 안다.
- [ ] 끝 프레임 지정은 아직 없다는 것을 안다.

## 27장 영상 생성, 테이크 비교, 재생성

- [ ] 진행 단계 문구 5개의 의미를 설명할 수 있다.
- [ ] 테이크 2개 이상을 만들고 생성 정보를 열어 봤다.
- [ ] 대비 바뀐 점에 항목이 하나만 표시되도록 재생성했다.
- [ ] 이 테이크 어땠나요? 평가를 남겼다.
- [ ] 평가표로 남길 테이크를 정했다.

## 28장 편집: 장면 잇기·트림·전환

- [ ] 컷·디졸브·페이드·와이프가 각각 어떤 느낌을 주는지 말할 수 있다.
- [ ] 스토리보드 순서로 자동 배치로 장면을 놓았다.
- [ ] 장면마다 쓸 테이크를 골랐다.
- [ ] 앞뒤를 트림해 어색한 부분을 잘랐다.
- [ ] 편집본 v1을 저장했다.

## 29장 자막·음악·제목 카드·색보정

- [ ] 자막이 배경에 묻히지 않고 잘 읽힌다.
- [ ] 배경음악이 대사를 덮지 않는다.
- [ ] 제목 카드와 엔딩 카드를 넣었다.
- [ ] 모든 클립의 톤을 맞췄다.
- [ ] 편집본 v2를 저장했다.

## 30장 내보내기·다운로드·게시 요청

- [ ] 코덱·비율·해상도를 구분해 설명할 수 있다.
- [ ] 마스터를 렌더하고 내려받았다.
- [ ] 9:16 프리셋에서 화면 맞춤을 정했다.
- [ ] 장면 다운로드에서 로고 포함·로고 없음의 차이를 알았다.
- [ ] 게시 요청의 확인 항목 네 가지를 읽었다.

## 실습 1 짧은 시네마틱 영상

- [ ] 대사 없이도 이야기(시작 → 이동 → 도착)가 전달된다.
- [ ] 세 장면의 인물이 같은 사람으로 보인다.
- [ ] 장면마다 카메라가 다르게(클로즈업 → 미디엄 → 와이드) 움직인다.
- [ ] 예산표의 합계와 사용량 화면의 실제 사용이 크게 다르지 않다.

## 실습 2 제품 홍보 영상

- [ ] 네 장면의 제품 모양·색이 같다.
- [ ] 문제 → 제품 공개 → 사용 장면 → 행동 유도가 30초 안에 들어간다.
- [ ] 제품 이름·혜택은 화면 속 글자가 아니라 카드·자막으로 넣었다.
- [ ] 9:16에서 제품이 잘리지 않는다.

## 실습 3 스토리가 있는 AI 단편

- [ ] 두 인물이 처음부터 끝까지 같은 얼굴·의상으로 보인다.
- [ ] 대사가 자막으로 나오고, 화자가 누구인지 알 수 있다.
- [ ] 목소리가 인물마다 구분된다.
- [ ] 립싱크가 어색한 장면은 편집으로 가렸다.
- [ ] 게시 요청을 한다면 대본·원작의 권리를 확인했다.

## 31장 크레딧 아끼는 제작 습관

- [ ] 무료·유료 작업을 구분할 수 있다.
- [ ] 영상 예산 식에서 가장 큰 변수가 무엇인지 안다.
- [ ] 원장의 보류·정산됨·환불됨을 구분할 수 있다.
- [ ] 예산 점검표를 채웠다.

## 32장 초보자가 겪는 실패 상황

- [ ] 확인 순서 5단계를 외우고 있다.
- [ ] AI 작업에서 실패 항목의 오류 세부 정보를 복사할 수 있다.
- [ ] 휴지통에서 항목을 복원해 봤다.
- [ ] 문제 해결 카드를 출력했다.

## 33장 품질 높이기와 셀프 리뷰

- [ ] 5개 축을 말할 수 있다.
- [ ] 실습 1–3을 모두 채점했다.
- [ ] 가장 낮은 축의 원인과 고칠 화면을 적었다.
