# 실습 워크북

「비 오는 정류장」을 처음부터 끝까지 만들며 채우는 기록지입니다. 본문 실습의 표를 한곳에 모으고, 비용과 결과를 남기는 **생성 기록지**를 더했습니다. 수업에서는 이 워크북을 과제 제출 양식으로 쓸 수 있습니다.

<DownloadCard href="/downloads/v1/fecine-v1-workbook.md" title="실습 워크북 (.md)" note="인쇄하거나 문서 편집기에 붙여 넣어 쓰세요" />

::: tip 쓰는 법
- 장을 마칠 때마다 해당 기록지를 채웁니다. 기록지 옆의 장 번호를 누르면 본문으로 갑니다.
- 크레딧이 드는 작업은 모두 **생성 기록지**(12번)에 한 줄씩 적습니다. 끝나면 **크레딧 · 사용량** 화면의 `사용 내역`과 비교합니다([31장](/v1/chapters/31-saving-credits)).
:::
