## [1장 AI 영상 제작이란?](/v1/chapters/01-ai-video-production)

**실습 1. 첫 영상 기획 메모 쓰기**

```text
[첫 영상 기획 메모]
제목       : 비 오는 정류장
한 줄 아이디어 : 비 오는 밤, 우산 없는 주인공에게 낯선 사람이 우산을 건넨다.
전체 길이  : 약 15초 (씬 3개 × 5초)
화면 비율  : 16:9            (작품 설정 > 화면 비율)
스타일     : 실사 · 시네마틱  (작품 설정 > 스타일)

씬 1 : 비에 젖은 버스 정류장. 혼자 서 있는 수아.   (와이드, 천천히 다가감)
씬 2 : 옆에서 우산이 쓱 들어온다. 놀라는 수아. (클로즈업)
씬 3 : 한 우산 아래 두 사람, 버스가 들어온다.  (뒤쪽에서 넓게)
```

**실습 2. 씬 1을 프롬프트로 바꾸기**

```text
비 오는 밤의 도시 버스 정류장. 20대 여성이 우산 없이 혼자 서 있다.
젖은 아스팔트에 가로등 빛이 번진다. 카메라는 멀리서 천천히 다가간다.
차분하고 쓸쓸한 분위기, 영화 같은 조명.
```

## [2장 기존 영상 제작과 AI 영상 제작의 차이](/v1/chapters/02-traditional-vs-ai)

**PRACTICE — 직접 해 보기**

```text
[제작 과정 비교표] 「비 오는 정류장」 15초

단계      | 기존 방식에 필요한 것          | AI 방식(FECINE)에 필요한 것
기획      | 대본, 콘티                      | 씬 3개의 설명과 씬 대본
비주얼    | 배우 2명, 정류장 로케이션, 우산  | 수아·도윤 이미지, 정류장 배경, 우산 소품
생성/촬영 | 비 오는 밤 촬영, 살수차       | 씬별 프롬프트·카메라 설정, 재생성
편집      | 편집 프로그램, 색보정           | 자동 배치, 씬 전환, 자막
배포      | 인코딩                         | 출력 프리셋으로 렌더
```

```text
씬 3  함께 기다리는 버스  (5초)
```

## [6장 소리: 대사·음악·효과음](/v1/chapters/06-sound)

**PRACTICE — 소리 설계 메모 쓰기**

```text
[소리 설계] 「비 오는 정류장」

씬 1  앰비언스: 거센 빗소리, 멀리 지나는 차     → 프롬프트 + 사운드: 음성 있음
        대사: 수아 (작게) "오늘따라 왜 이렇게 안 와." → 씬 탭 대사, 말하는 인물: 수아
씬 2  효과음: 우산 위로 떨어지는 빗방울         → 프롬프트
        대사: 도윤 "같이 써요. 저도 같은 버스 기다리거든요." → 말하는 인물: 도윤
씬 3  효과음: 버스 브레이크, 문 열리는 소리       → 프롬프트
        대사: 수아 (미소) "고마워요."
전체   음악: 조용한 피아노 (직접 준비한 파일)  → 편집 > 배경음악, 씬 3에서 커짐
```

## [7장 이야기 구조와 스토리보드](/v1/chapters/07-story-structure)

**PRACTICE — 3막 구조 기획서**

```text
[기획서] 「비 오는 정류장」

로그라인 : 비 오는 밤, 우산 없는 주인공에게 낯선 사람이 우산을 건넨다.
주인공   : 수아(20대). 원하는 것 = 빨리 집에 가기. 부족한 것 = 우산
변화     : 혼자 → 누군가와 함께, 차가움 → 따뜻함

1막 (5초) 씬 1 비 오는 버스 정류장   훅: 빗방울이 번지는 와이드
2막 (5초) 씬 2 건네진 우산          전환: 우산이 들어오는 순간
3막 (5초) 씬 3 함께 기다리는 버스   마무리: 웃음, 따뜻한 톤(5장)
```
