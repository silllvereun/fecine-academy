# FECINE 제작 흐름

입구는 세 가지지만 결국 모두 `작품정보` → 장면 준비 → `스토리보드`에서의 영상 생성 → `편집` → `내보내기`로 모입니다.

<FlowDiagram />

점선 상자는 건너뛸 수 있는 단계입니다. 대본 파일이 있으면 `AI 구성`이 스토리의 회차·장면과 등장 요소를 한 번에 만들고, 없으면 `스토리`에서 직접 씁니다.

화면 단위로 풀면 다음 10단계입니다.

1. **로그인** — `작품 시작하기` → `Google 계정으로 계속하기` → (처음이면) `이름` 입력·약관 3개 체크 → `스튜디오 열기`. 개인 워크스페이스와 튜토리얼 작품이 자동으로 생깁니다.
2. **작품 만들기** — 상단 `새 작품`을 누르면 입력창 없이 ‘새 작품’이 바로 만들어지고 `작품정보`가 열립니다. `템플릿`·`프리소스`에서 시작해도 됩니다.
3. **작품정보** — 제목을 더블클릭해 바꾸고, `설정 변경`에서 화면 비율·해상도·스타일·형식을 정합니다. 비율·해상도는 작품 전체에 고정됩니다.
4. **AI 구성 또는 스토리** — 대본이 있으면 `파일 업로드` → `AI로 작품 구성` → `회차·장면 추출` → `고른 회차 항목 만들기`. 없으면 `스토리` → `대본 없이 시작해요` → `첫 회차 만들기` → `장면 추가` → `AI로 쓰기`.
5. **캐릭터 · 아트** — `캐릭터`·`배경`·`소품` 탭에서 이미지를 만들고, 캐릭터는 `캐릭터 시트`로 정면·측면·후면·표정을 맞춥니다.
6. **오디오 (선택)** — 목소리 파일을 `업로드` → `캐릭터 연결`.
7. **장면 프레임 (선택)** — `후보 {n}장 만들기` → `프레임에 추가` → `영상을 이 프레임으로 만들기`.
8. **스토리보드** — 장면마다 `장면`·`프롬프트`·`카메라`·`스타일`·`모델` 탭을 채우고 `생성`. 마음에 안 들면 다시 생성해 테이크(T1, T2…)를 고릅니다.
9. **편집** — `스토리보드 순서로 자동 배치` → 트림·전환·자막·BGM → `편집본 저장` → `내보내기`.
10. **내보내기** — `출력 프리셋` 선택 → `렌더 시작`(브라우저 탭을 닫지 않음) → `영상 다운로드`.

새 사용자에게는 작품 화면 위에 5단계 튜토리얼(`AI 작품 구성` → `참조 이미지` → `콘티` → `영상 생성` → `내보내기`)이 안내되므로, 교재 PART 02는 이 튜토리얼 작품으로 첫 실습을 하도록 구성했습니다.
