# FECINE 제작 흐름

입구는 세 가지지만 결국 모두 `작품 정보` → `스토리`에서 에피소드·씬 준비 → 제작설계(등장인물·배경·소품·콘티) → `스토리보드`에서의 영상 생성 → `편집` → `내보내기`로 모입니다.

<FlowDiagram />

점선 상자는 건너뛸 수 있는 단계입니다. 대본 파일이 있으면 `스토리`의 `작품 자료` 탭에 대본을 올리고 AI 어시스턴트의 `에피소드·씬 추출`(이어서 `등장 요소 만들기`·`촬영 설계 만들기`)이 에피소드·씬과 등장 요소를 만들고, 없으면 `스토리`의 `스토리 편집` 탭에서 직접 씁니다. 그림의 ‘등장인물 · 미술 · 공간’ 상자는 `등장인물`·`미술·소품`·`공간·배경`·`콘티` 메뉴를 묶어 나타냅니다.

화면 단위로 풀면 다음 10단계입니다.

1. **로그인** — 홈페이지의 `로그인`(또는 크레딧 알약·`내 첫 작품 시작하기`) → `Fecine에 로그인` 창에서 `Google 계정으로 계속하기` → (처음이면) `이름` 입력·약관 3개 체크 → `스튜디오 열기`. 개인 워크스페이스가 만들어지고, 새 스튜디오에는 튜토리얼 작품이 함께 생깁니다(운영 설정에 따라 다를 수 있음).
2. **작품 만들기** — 상단 `새 작품`을 누르면 입력창 없이 이름 없는 작품이 바로 만들어지고 `작품 정보`가 열리며 `작품 설정` 패널이 함께 열립니다. 사이드 메뉴의 `템플릿`·`프리소스`에서 시작해도 됩니다.
3. **작품 정보** — 제목을 더블클릭해 바꾸고, `작품 설정`(`설정 변경`)에서 화면 비율·해상도·스타일·형식을 정합니다. 비율·해상도는 작품 전체에 고정됩니다. 화면 위 `작품 위키` 탭에는 작품 공통 정보를 적어 둘 수 있습니다(선택).
4. **스토리** — 대본이 있으면 `작품 자료` 탭에서 원문에 대본을 올리거나 `스토리 작성`으로 직접 붙여 넣고 → AI 어시스턴트에서 `에피소드·씬 추출` → `등장 요소 만들기` → `촬영 설계 만들기`(`진행 상황` 탭에서 확인). 없으면 `스토리 편집` 탭에서 `대본 없이 시작해요` → `첫 에피소드 만들기` → 씬 추가 → 씬 대본 쓰기(직접 쓰거나 AI 어시스턴트의 `대본 쓰기`).
5. **등장인물 · 미술·소품 · 공간·배경 · 콘티** — 메뉴마다 이미지를 만들고, 등장인물은 `캐릭터 시트`로 정면·측면·후면·표정을 맞춥니다.
6. **음향 (선택)** — 목소리 파일을 `오디오 추가`로 올리고 → `등장인물`의 `보이스 선택`에서 연결.
7. **샷 이미지 (선택)** — `이미지 수`를 고르고 `생성 · 예상 크레딧` → `프레임에 추가` → `이 프레임으로 영상 만들기`.
8. **스토리보드** — 씬마다 `등장 요소`·`스토리`·`프롬프트`·`카메라`·`스타일`·`모델` 탭을 채우고(`영상 프롬프트 만들기`로 빈 씬의 프롬프트를 한 번에 채울 수 있음) `씬 영상 생성`. 마음에 안 들면 다시 생성해 테이크(T1, T2…)를 고릅니다.
9. **편집** — `스토리보드 순서로 자동 배치` → 트림·전환·자막·BGM → `편집본 저장` → `내보내기`.
10. **내보내기** — `출력 프리셋` 선택 → `렌더 시작`(브라우저 탭을 닫지 않음) → `영상 다운로드`. 다른 편집 프로그램에서 마무리하려면 `편집 프로젝트 (프리미어·다빈치)`를 받습니다.

새 사용자에게는 작품 목록의 `첫 영상 튜토리얼` 카드(`환영해요`)에서 `튜토리얼 시작 / 이어하기`로 5단계 튜토리얼(`AI 자동생성` → `참조 이미지` → `콘티` → `영상 생성` → `내보내기`)이 안내되므로, 교재 PART 02는 이 튜토리얼 작품으로 첫 실습을 하도록 구성했습니다.
