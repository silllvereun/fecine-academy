# FECINE 기능 요약 (v1.38.0)

이 페이지는 교재 구성에 영향을 주는 FECINE 기능만 추렸습니다. 기능별 사용법은 각 장에 있습니다.

- 작품을 열면 `제작 모듈` 10개가 제작 순서대로 나오며, `검토`만 `준비 중`입니다.
- 영상은 `스토리보드`에서만 만들고, `장면 프레임` 1장을 확정하면 그것이 첫 화면이 됩니다.
- `스토리`와 `AI 구성`은 같은 결과를 만드는 두 경로입니다(기본 경로는 스토리).
- 음성은 별도 TTS 없이 영상 모델이 대사와 함께 만듭니다. 자막도 입력한 대사로만 만듭니다.
- 로그인은 Google 계정만 지원하고, 렌더는 PC 브라우저에서 돌아갑니다.
- 1.36.0부터 장면 영상 다운로드는 ‘로고 포함 무료 / 로고 없이 유료’이고, 편집의 `전체 다운로드`는 없습니다.
- 1.38.0부터 Seedance가 일반과 VIP로 나뉘며, 실존 인물 인증은 VIP에만 있습니다.

모델 이름·한도·요금은 부록 A, 아직 없는 기능은 부록 D에서 다룹니다.
