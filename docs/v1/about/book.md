# 책 소개

**영상 제작의 기초부터 생성형 AI 모델 이해, FECINE 실전 워크플로까지**

이 책은 FECINE 사용법만 설명하지 않습니다. 처음 배우는 사람이 영상의 원리를 이해하고, 알맞은 AI 모델을 고르고, 스스로 작품을 기획·제작·평가하도록 돕습니다. FECINE은 그 이론을 바로 손으로 확인하는 실습 플랫폼 역할을 합니다.

| 배우는 축 | 내용 | PART |
| --- | --- | --- |
| 영상 제작 배경지식 | 샷·컷·장면, 카메라 언어, 빛·색, 소리, 이야기 구조 | PART 02 |
| 생성형 AI 기본 원리 | AI가 그림·영상을 만드는 방식, 프롬프트, 일관성, 평가·저작권 | PART 03 |
| AI 모델 이해 | 모델을 고르는 기준, 비용 계산 | PART 04 |
| FECINE 실전 워크플로 | 기획 → 비주얼 → 영상 생성 → 편집 → 내보내기 | PART 05–10 |
| 비용·오류 대응과 평가 | 크레딧 관리, 실패 상황 해결, 품질 점검 | PART 11 |

대상 독자는 AI 영상 입문자, 파트너사 실무자, 교육기관 수강생입니다. 기준 버전은 FECINE V1(v1.74.0)이며, 원고는 Markdown으로 작성해 PDF·인쇄·온라인 강의로 변환합니다.

## 모든 장의 공통 구조: WHY · HOW · PRACTICE · REVIEW

| 단계 | 독자의 질문 | 담는 내용 |
| --- | --- | --- |
| WHY | 이걸 왜 배우지? | 학습 목표, 완성할 결과물 미리보기, 실제 제작에서 필요한 상황 |
| HOW | 어떻게 작동하고, 어떻게 하지? | 개념 설명(그림), FECINE 화면 따라 하기(캡처 + 번호) |
| PRACTICE | 직접 만들어 보자 | 그대로 입력할 프롬프트·설정값, 예상 크레딧, 목표 결과물과 내 결과 비교 |
| REVIEW | 제대로 했나? | 체크리스트, 자주 겪는 실패와 해결, 확인 문제 3개, 응용 과제 |

학습 요소는 다섯 가지로 통일합니다. TIP(요령), NOTE(알아둘 점), CHECK(확인), 주의(실수 방지), COST(크레딧이 드는 지점)입니다.

## 오래가는 지식과 자주 바뀌는 정보 나누기

본문에는 버전이 바뀌어도 유효한 지식만 넣고, 모델 이름·한도·가격은 부록과 온라인 업데이트로 관리합니다. 그래야 V1 이후에도 책을 계속 쓸 수 있습니다.

| 구분 | 예 | 담는 곳 | 갱신 시점 |
| --- | --- | --- | --- |
| 오래가는 지식 | 샷 크기, 카메라 움직임, 빛, 이야기 구조, 생성 원리, 프롬프트 구성, 일관성 전략, 평가 기준 | 본문 | 개정판 |
| FECINE 화면 | 메뉴명, 버튼명, 제작 흐름 | 본문 + 캡처(버전 표기) | FECINE 큰 업데이트 |
| 자주 바뀌는 정보 | 모델 이름·버전, 길이·해상도 한도, 가격, 지원 기능 | 부록 A ‘모델 정보(버전별)’ + 온라인 업데이트 | FECINE 버전마다 |

본문은 숫자를 외우게 하지 않고 **확인하는 방법**을 가르칩니다. 예) “`모델` 탭에서 길이 범위와 `약 {n} 크레딧`을 확인한 뒤 고릅니다.” 구체적인 수치는 “부록 A 참고”로 연결합니다.

## 집필 원칙

1. 메뉴명·버튼명은 코드와 실제 화면에서 확인한 그대로 씁니다.
2. 구현되지 않은 기능은 부록 D ‘향후 기능’으로만 소개합니다.
3. 모든 실습에는 목표 결과물(이미지·영상)을 함께 싣고, 실제 FECINE에서 만든 결과만 씁니다.
4. 크레딧이 드는 모든 버튼 앞에는 COST 박스를 둡니다.
