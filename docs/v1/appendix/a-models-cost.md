# 부록 A 모델과 비용

> **읽기 전에** 이 부록의 모델 이름·수치·요금은 FECINE v1.82.0 기준입니다(표의 길이·해상도 값은 v1.74.0 확인값). 실제로 보이는 모델과 요금은 운영 설정과 워크스페이스마다 다를 수 있습니다. **항상 화면에 표시된 값이 기준**입니다. 모델을 고를 때 보이는 `약 n 크레딧`, `예상 시간 약 …`, 내보내기의 `요금: {credits} 크레딧`을 확인하세요.

- **경로: Standard · Enterprise · Global** 같은 모델을 서로 다른 공급 경로로 돌립니다. 모델 목록에서는 이름 옆 태그(Enterprise는 건물, Global은 지구본 아이콘)로 구분하고, **경로마다 가격이 다를 수 있습니다.** Seedance의 길이·해상도는 일반과 Enterprise가 같습니다. 예전 이름 ‘… VIP’ → ‘… Global’은 v1.80.0에서 ‘… Enterprise’로 바뀌었고, `Global`은 Wan 3.0 Global · Prime Global, Qwen Image 3.0처럼 승인된 글로벌 경로에 붙습니다.
- **실존 인물** 실존 인물 등장인물을 Seedance로 만들려면 `Seedance 실존 인물 인증`을 마쳐야 하고, 인증을 마치면 Seedance로 영상을 만들 수 있습니다(운영에서 테스트 완료, 2026-11-10). 다른 모델은 인증 없이 씁니다.
- **참조 1장 모델** Kling v3처럼 이미지를 1장만 받는 모델은 샷 이미지를 먼저 만들면 결과가 안정됩니다(26장).
- **모델 목록** 예상 크레딧이 낮은 순으로 보이고, 경로가 여럿인 모델은 한 줄(`약 n 크레딧부터`)에 묶여 있습니다. 공식 API 가격보다 저렴한 모델에는 `↓` 할인율이 붙습니다. 모델·가격 페이지에서는 `제공사`·`유형`으로 거르고 `정렬`(가격 낮은 순·높은 순·이름 순)할 수 있습니다. 보이는 모델은 운영 설정과 워크스페이스에 따라 다릅니다.
- **참조 이미지 자동 맞춤** 너무 작은 참조 이미지는 Seedance·Kling은 짧은 변 300px, Wan은 240px까지 키워 보내고, Wan에서 투명 배경은 흰 바탕 JPEG로 바꿉니다. 모델이 받을 수 없는 가로세로 비율(Seedance·Kling 2.5:1, Wan 8:1 초과)은 요청 전에 알려 주며 크레딧은 차감되지 않습니다.
- **릴리스 실측(참고)** Seedance 2.0 Fast, 480p, 4초 생성에 약 107–126초. Seedance 2.5, 480p, 4초 ≈ 0.39 크레딧(v1.35.1 기록). 시간과 요금은 상황에 따라 달라집니다.

:::

## A.4 예산 계산 예시

31장의 예산 식에 이 부록의 요금을 넣어 계산합니다. 단가는 모델을 고를 때 화면에 보이는 값을 씁니다.

```text
예: 「비 오는 정류장」 — 씬 3개 × 5초 × 테이크 2개 = 영상 30초
영상 예산      = 30초 × (화면의 초당 단가)
이미지 예산    = (등장인물 2 + 배경 1 + 샷 이미지 3) = 6장 × (장당 단가)
내보내기      = 3 크레딧 (로고 없이는 +5)
합계          = 영상 예산 + 이미지 예산 + 내보내기 (+ 텍스트 모델을 썼다면 그 비용)
```
