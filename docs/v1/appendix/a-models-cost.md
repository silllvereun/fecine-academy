## A.4 예산 계산 예시

31장의 예산 식에 이 부록의 요금을 넣어 계산합니다. 단가는 모델을 고를 때 화면에 보이는 값을 씁니다.

```text
예: 「비 오는 정류장」 — 장면 3개 × 5초 × 테이크 2개 = 영상 30초
영상 예산      = 30초 × (화면의 초당 단가)
이미지 예산    = (캐릭터 2 + 배경 1 + 장면 프레임 3) = 6장 × (장당 단가)
내보내기      = 3 크레딧 (로고 없이는 +5)
합계          = 영상 예산 + 이미지 예산 + 내보내기 (+ 텍스트 모델을 썼다면 그 비용)
```
