# 부록 A 모델과 비용

> **읽기 전에** 이 부록의 모델 이름·수치·요금은 FECINE v1.74.0 기준입니다. 실제로 보이는 모델과 요금은 운영 설정과 워크스페이스마다 다를 수 있습니다. **항상 화면에 표시된 값이 기준**입니다. 모델을 고를 때 보이는 `약 n 크레딧`, `예상 시간 약 …`, 내보내기의 `요금: {credits} 크레딧`을 확인하세요.

- **일반과 Global** 같은 모델을 서로 다른 공급 경로로 돌립니다. 모델 목록에서는 이름 옆 `GLOBAL` 배지로 구분합니다. Seedance의 길이·해상도는 일반과 Global이 같습니다. 예전 이름 ‘… VIP’는 이제 ‘… Global’입니다.
- **실존 인물** 실존 인물 등장인물을 Seedance로 만들려면 `Seedance 실존 인물 인증`이 필요하고, 다른 모델은 인증 없이 씁니다. 인증이 일반과 Global 중 어디에서 쓰이는지는 <Badge type="warning" text="확인 필요" />.
- **참조 1장 모델** Kling v3처럼 이미지를 1장만 받는 모델은 샷 이미지를 먼저 만들면 결과가 안정됩니다(26장).
- **모델 목록** 이름순으로 보이고, GLOBAL 모델은 배지로 구분합니다. 보이는 모델은 운영 설정과 워크스페이스에 따라 다릅니다.
- **릴리스 실측(참고)** Seedance 2.0 Fast, 480p, 4초 생성에 약 107–126초. Seedance 2.5, 480p, 4초 ≈ 0.39 크레딧(v1.35.1 기록). 시간과 요금은 상황에 따라 달라집니다.

모델별 단가는 `크레딧 · 사용량` 화면의 `모델 가격표`나 공개 메뉴 `모델·가격`(USD 표기)에서 봅니다.

::: info NOTE
크레딧 충전은 개인 스튜디오는 소유자, 회사 스튜디오는 기업관리자만 할 수 있습니다. `크레딧 충전` 패널의 결제 수단은 `카드·간편결제`(국내 카드) · `무통장입금`(입금이 확인되면 자동 충전) · `PayPal`(해외 계정 · USD)이고, `만 19세 이상입니다.`에 체크해야 결제할 수 있습니다. 크레딧은 무상(가입 혜택 등)부터 쓰이고, 환불은 유상으로 산 크레딧만 됩니다. 운영 화면에 어떤 결제 화면과 수단이 보이는지는 운영 설정이라 바뀔 수 있습니다 <Badge type="warning" text="확인 필요" />.
:::

## A.4 예산 계산 예시

31장의 예산 식에 이 부록의 요금을 넣어 계산합니다. 단가는 모델을 고를 때 화면에 보이는 값을 씁니다.

```text
예: 「비 오는 정류장」 — 씬 3개 × 5초 × 테이크 2개 = 영상 30초
영상 예산      = 30초 × (화면의 초당 단가)
이미지 예산    = (등장인물 2 + 배경 1 + 샷 이미지 3) = 6장 × (장당 단가)
내보내기      = 3 크레딧 (로고 없이는 +5)
합계          = 영상 예산 + 이미지 예산 + 내보내기 (+ 텍스트 모델을 썼다면 그 비용)
```
