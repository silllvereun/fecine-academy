# 부록 B 메뉴·버튼 찾아보기

화면에서 본 이름으로 찾습니다. ‘위치’의 `>`는 눌러서 들어가는 순서입니다. 작품 안의 메뉴는 왼쪽 **제작 모듈** 메뉴 이름으로 시작합니다.

## B.1 제작 모듈 메뉴 (작품 안 왼쪽, 제작 순서)

메뉴는 그룹 제목 없이 한 줄씩 보이고, 단계가 바뀌는 곳(제작설계 · 영상 · 후반)에 구분선이 있습니다. 설명은 메뉴에 마우스를 올리면 보입니다.

| 메뉴 | 설명 | 장 |
| --- | --- | --- |
| 작품정보 | 개요와 제작 현황. 화면 위 탭 `작품정보` · `작품 위키` | 16 |
| 스토리 | 에피소드와 씬 대본. 화면 위 탭 `스토리 편집` · `작품 자료` · `진행 상황` | 17–19 |
| 등장인물 | 인물 · 외형 · 목소리 | 20·22 |
| 미술·소품 | 소품 · 의상 · 오브젝트 | 21 |
| 공간·배경 | 장소와 배경 | 21 |
| 음향 | 음성과 음악 | 23 |
| 콘티 | 콘티 시트와 참고 영상 | 21 |
| 샷 이미지 | 씬별 샷 이미지 | 26 |
| 스토리보드 | 씬 구성 · 영상 생성 | 24–25·27 |
| 편집 | 영상 편집 | 28–29 |
| 검토 | 코멘트 · 승인 (준비 중) | 부록 D |
| 내보내기 | 렌더 · 배포 | 30 |

## B.3 키보드 단축키

어느 화면에서든 `?`를 누르면 단축키 목록이 열립니다. Mac에서는 Ctrl 대신 ⌘를 누릅니다.

| 키 | 동작 | 어디서 |
| --- | --- | --- |
| Ctrl + K | 검색 열기 | 전역 |
| ? | 단축키 보기 | 전역 |
| Esc | 닫기 | 창·서랍 |
| J 또는 Alt + → | 다음 씬 | 스토리보드 |
| K 또는 Alt + ← | 이전 씬 | 스토리보드 |
