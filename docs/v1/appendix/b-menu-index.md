## B.3 키보드 단축키

어느 화면에서든 `?`를 누르면 단축키 목록이 열립니다. Mac에서는 Ctrl 대신 ⌘를 누릅니다.

| 키 | 동작 | 어디서 |
| --- | --- | --- |
| Ctrl + K | 검색 열기 | 전역 |
| ? | 단축키 보기 | 전역 |
| Esc | 닫기 | 창·서랍 |
| J 또는 Alt + → | 다음 장면 | 스토리보드 |
| K 또는 Alt + ← | 이전 장면 | 스토리보드 |
