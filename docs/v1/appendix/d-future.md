# 부록 D 향후 기능

FECINE v1.74.0에는 없거나 `준비 중`인 기능입니다. 본문에서는 가르치지 않고, 독자가 찾을 때 쓸 수 있는 지금의 대안을 함께 적습니다. 기능이 출시되면 해당 장에 내용을 옮기고 이 표에서 뺍니다.

| 기능 | 현재 | 지금의 대안 | 관련 장 |
| --- | --- | --- | --- |
| 검토(코멘트·승인) | 제작 모듈 메뉴에 `준비 중` | 내보낸 영상을 팀에 공유해 검토 | 33 |
| 음성 합성(TTS), 음악 생성, 단독 립싱크 | 없음 | 대사를 입력하고 사운드 **음성 있음**으로 영상 모델이 함께 생성. 음악은 파일을 올려 **배경음악**에 배치 | 6·23·29 |
| 끝 프레임 지정 | ‘끝 프레임: 지금 연결된 영상 모델은 아직 받지 않습니다.’ | 샷 이미지 2–4장으로 샷마다 시작 화면 지정, 샷별 카메라 **끝 화면** | 25·26 |
| 자막 음성 인식·자동 번역 | 없음 (자막 언어는 표시용) | 대사를 입력하고 **대사에서 자막 자동 생성**, 번역은 직접 | 29 |
| 테이크 나란히 재생 비교 | 없음 | 테이크 전환 + **대비 바뀐 점** | 27 |
| 작품 복제, 공유 링크, 스토리보드 기록 | `준비 중` 또는 화면 없음 | 같은 틀이 필요하면 기본 제공 **템플릿**으로 새 작품 시작 (내 작품을 템플릿으로 저장하는 기능은 없음) | 16 |
| 월드 바이블, 작품 전체 등장인물 목록 화면 | ‘후속 업데이트에서 제공됩니다’ 안내만 | **작품 위키**의 등장인물 · 장소 · 세계관 · 소품 칸, **등장인물** · **공간·배경** · **미술·소품** 메뉴 | 16·20–21 |
| 내 SNS 계정으로 직접 게시·예약 게시 | 없음 (채널 게시는 FECINE 공식 채널만) | 내려받은 MP4를 직접 업로드 | 30 |
| 한 편 전체 씬 원본 ZIP | v1.36.0에서 삭제 | 내보내기로 합본을 받거나, **편집 프로젝트 (프리미어·다빈치)**로 원본 클립을 받거나, 스토리보드에서 씬별 **다운로드** | 30 |

::: info NOTE
FECINE **도움말**의 일부 문구(템플릿 저장, 캐릭터 저장)는 지금 화면에 없는 기능을 설명합니다. 이 책은 실제 화면을 따릅니다.
:::

## D.1 부록 갱신 절차 (강사·제휴사용)

1. 새 버전의 릴리스 노트에서 화면 이름·모델·요금 변경을 확인합니다.
2. 부록 A를 새 버전 파일로 만들고 A.5에 변경 기록을 더합니다.
3. 화면 이름이 바뀌었다면 부록 B와 해당 장을 고칩니다.
4. 출시된 기능은 부록 D에서 빼고 관련 장에 설명을 더합니다.
5. 바뀐 화면은 캡처를 다시 찍고, 온라인 업데이트로 배포합니다.
