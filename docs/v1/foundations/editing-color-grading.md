# 영상 편집과 색보정 이론

<ChapterGoals />

## WHY — 왜 이어 붙이면 어색해질까요?

> 장면 하나하나는 괜찮은데, 이어 붙이면 튀거나 다른 영상처럼 보입니다.

AI는 장면을 따로따로 만듭니다. 그래서 장면끼리 **움직임의 방향, 시선, 밝기와 색**이 조금씩 어긋나기 쉽습니다. 이 페이지는 편집 버튼을 **언제, 왜** 누르는지 설명합니다. FECINE 편집 화면의 사용법은 [28장](/v1/chapters/28-editing)과 [29장](/v1/chapters/29-subtitles-music-cards)에 있으며, 먼저 읽지 않아도 괜찮습니다.

- 컷이 자연스럽게 이어지는 세 가지 원리를 설명한다.
- 색보정(교정)과 색 그레이딩(연출)을 구분한다.
- AI로 만든 여러 장면의 색을 하나로 맞춘다.

**완성 결과물** 「비 오는 정류장」 컷 연결 메모와 색 맞추기 기록

## HOW — 컷 편집과 색의 원리

### 컷이 이어져 보이는 세 가지 원리

관객이 컷을 눈치채지 못하는 편집을 **연속 편집**이라고 합니다. 기본 원리는 세 가지입니다.

| 원리 | 뜻 | 「비 오는 정류장」에서 |
| --- | --- | --- |
| 동작 연결 | 앞 컷의 동작이 다음 컷에서 이어짐 (예: 손을 뻗는 순간에 컷) | 도윤이 우산을 내미는 동작 중간에 씬 2로 |
| 시선 연결 | 인물이 보는 쪽에 다음 컷의 대상이 있음 | 수아가 오른쪽을 보면, 다음 컷에서 도윤이 오른쪽에서 등장 |
| 방향 유지 | 이동 방향·위치 관계를 컷마다 바꾸지 않음 | 버스는 계속 같은 방향에서 들어옴 |

::: tip TIP
AI 장면은 방향과 시선이 어긋나기 쉬우므로, 생성 전에 프롬프트에 방향을 적어 두면 편집이 쉬워집니다. 예) “수아는 화면 왼쪽에 서서 오른쪽 도로를 바라본다.” 카메라 방향은 [4장](/v1/chapters/04-camera-language)과 [25장](/v1/chapters/25-camera-style)을 참고하세요.
:::

### 편집의 리듬

컷의 길이가 반복되는 모양이 **리듬**입니다.

| 리듬 | 만드는 법 | 느낌 |
| --- | --- | --- |
| 느린 리듬 | 컷을 길게, 전환을 부드럽게(디졸브) | 서정적, 여운 |
| 빠른 리듬 | 컷을 짧게, 바로 바꿈(컷) | 긴장, 활기 |
| 리듬의 변화 | 짧은 컷이 이어지다 긴 컷 하나 | 강조, 감정의 정점 |

FECINE에서는 클립의 앞뒤를 잘라 내는 트림, 속도, 씬 전환으로 리듬을 조절합니다([28장](/v1/chapters/28-editing)).

### 색보정과 색 그레이딩

| 구분 | 목적 | 예 |
| --- | --- | --- |
| 색보정 (교정) | 잘못된 것을 바로잡아 장면끼리 같게 만들기 | 너무 어두운 장면 밝히기, 한 장면만 노란 색 맞추기 |
| 색 그레이딩 (연출) | 작품 전체의 분위기를 정하기 | 차갑고 쓸쓸한 톤, 따뜻한 회상 톤 |

순서는 항상 **교정 먼저, 연출 나중**입니다. 장면끼리 밝기·색이 다른 채로 룩을 입히면 차이가 더 커집니다.

| 값 | 바꾸면 | 너무 많이 바꾸면 |
| --- | --- | --- |
| 노출 | 화면 전체가 밝아지거나 어두워짐 | 밝은 곳이 하얗게 날아가거나 어두운 곳이 뭉개짐 |
| 대비 | 밝은 곳과 어두운 곳의 차이가 커지거나 작아짐 | 딱딱하거나 뿌옇게 보임 |
| 채도 | 색이 진해지거나 흐려짐 | 피부색이 부자연스러워짐 |

### FECINE에서 하기

1. **편집**에서 클립을 선택하고 **속성**의 **색보정** 탭을 엽니다.
2. 씬을 하나씩 보며 **노출**·**대비**·**채도**로 밝기와 색을 비슷하게 맞춥니다(교정).
3. 기준 씬에서 **룩**(원본 · 따뜻하게 · 차갑게 · 흑백)을 고릅니다(연출).
4. **모든 클립에 적용**으로 작품 전체에 같은 룩을 입힙니다.

::: info NOTE
룩은 화면 전체에 입히는 색감 필터입니다. FECINE의 **색보정** 탭에서는 교정(노출·대비·채도)과 연출(룩)을 함께 합니다. 생성 단계의 분위기는 스토리보드 **스타일** 탭의 **룩**(조명 · 색 · 질감 · 공기)으로 먼저 정하고, 편집의 색보정은 마무리로 씁니다([5장](/v1/chapters/05-light-color-mood)).
:::

## PRACTICE — 컷 연결과 색 맞추기

**실습 F2-1 컷 연결 메모**

씬 1 → 2 → 3이 이어지는 지점을 적어 봅니다.

| 컷 | 연결 원리 | 확인할 것 | 어긋나면 |
| --- | --- | --- | --- |
| 씬 1 → 2 | 시선 연결 | 수아가 보는 쪽에서 도윤이 오는가 | 테이크 바꾸기 또는 재생성 |
| 씬 2 → 3 | 동작 연결 | 우산을 받는 동작이 이어지는가 | 트림으로 동작 중간에 자르기 |
| 씬 3 끝 | 방향 유지 | 버스가 들어오는 방향 | 프롬프트에 방향 적고 재생성 |

**실습 F2-2 색 맞추기 기록**

| 씬 | 처음 느낌 | 노출 | 대비 | 채도 | 룩 |
| --- | --- | --- | --- | --- | --- |
| 1 비 오는 버스 정류장 | (기준 씬) | 0 | 1 | 1 | |
| 2 건네진 우산 | | | | | (모든 클립에 적용) |
| 3 함께 기다리는 버스 | | | | | (모든 클립에 적용) |

::: cost COST · 비용
편집과 색보정은 무료입니다. 어긋남이 작으면 재생성하기 전에 트림과 색보정으로 먼저 고쳐 보세요.
:::

## REVIEW — 제대로 했나요?

- [ ] 동작 연결 · 시선 연결 · 방향 유지를 예로 설명할 수 있다.
- [ ] 교정과 연출의 순서를 안다.
- [ ] 세 장면의 밝기와 색을 비슷하게 맞췄다.

| 상황 | 원인 | 해결 |
| --- | --- | --- |
| 컷이 바뀔 때 인물이 튐 | 동작·위치가 이어지지 않음 | 트림으로 자르는 지점을 옮기거나 다른 테이크 |
| 한 장면만 색이 다름 | 생성 결과의 차이 | 그 클립만 노출·채도로 교정한 뒤 룩 적용 |
| 룩을 입히니 더 어색함 | 교정 없이 연출부터 함 | 룩을 원본으로 되돌리고 교정부터 |

**확인 문제**

1. 인물이 오른쪽을 본 뒤 다음 컷에서 보는 대상이 오른쪽에 있게 하는 원리는?
2. 색보정에서 먼저 해야 하는 것은 교정과 연출 중 무엇인가요?

정답: 1. 시선 연결 2. 교정

**응용 과제** 같은 세 장면으로 느린 리듬(디졸브, 긴 컷)과 빠른 리듬(컷, 짧은 컷) 편집본을 각각 저장하고, 어느 쪽이 「비 오는 정류장」에 어울리는지 한 문단으로 적어 보세요.
