# 후반 제작 기술

<ChapterGoals />

## WHY — 편집이 끝나면 다 된 걸까요?

> 편집본은 마음에 드는데, 휴대폰으로 보니 대사가 음악에 묻히고 자막은 너무 빨리 지나갑니다.

**후반 제작**(포스트 프로덕션)은 편집 뒤에 소리·자막·파일을 다듬어 **어디서 보든 같은 경험**이 되게 하는 단계입니다. AI 영상도 마지막 품질은 이 단계에서 결정됩니다.

- 대사·음악·효과음의 음량 균형을 잡는 기준을 안다.
- 읽기 쉬운 자막의 규칙과 SRT 파일 형식을 안다.
- 보관용 마스터와 배포용 파일을 나누어 납품·보관한다.

**완성 결과물** 「비 오는 정류장」 납품 체크리스트와 SRT 자막 파일

## HOW — 소리, 자막, 납품

### 소리의 균형

소리는 [6장](/v1/chapters/06-sound)에서 본 다섯 요소(대사 · 내레이션 · 앰비언스 · 효과음 · 음악)가 겹쳐 만들어집니다. 섞을 때의 기본 순서는 이렇습니다.

| 순서 | 원칙 |
| --- | --- |
| 1 | **대사가 가장 잘 들려야 합니다.** 다른 소리는 대사를 기준으로 맞춥니다. |
| 2 | 음악은 대사가 있는 동안 낮추고, 대사가 없을 때 조금 올립니다. |
| 3 | 앰비언스(빗소리 등)는 끊기지 않게 깔되, 의식하지 못할 정도로 작게 둡니다. |
| 4 | 시작과 끝은 갑자기 끊기지 않게 페이드로 처리합니다. |
| 5 | 휴대폰 스피커와 이어폰으로 각각 들어 봅니다. 작은 스피커에서는 낮은 음이 거의 들리지 않습니다. |

::: info NOTE
영상 플랫폼은 대부분 올라온 영상의 음량을 자동으로 맞춥니다. 전체를 무조건 크게 만들기보다 **소리끼리의 균형**에 집중하세요.
:::

### 자막 규칙

| 규칙 | 기준 |
| --- | --- |
| 길이 | 한 줄은 짧게(한국어 15자 안팎), 최대 두 줄 |
| 표시 시간 | 읽을 시간을 줌 — 짧은 문장도 1.5초 이상 ([29장](/v1/chapters/29-subtitles-music-cards)) |
| 끊는 곳 | 말의 의미 단위로 끊기. 조사·어미 중간에서 줄을 바꾸지 않기 |
| 위치 | 기본은 하단. 화면 아래에 중요한 그림이나 글자가 있으면 상단 |
| 가독성 | 밝은 배경 위에서는 배경 띠를 깔기 |
| 화자 | 화면에 말하는 사람이 안 보이면 화자 이름 표시 |

자막을 영상에 입히면(번인) 어디서나 보이지만 끌 수 없습니다. 별도 파일로 주면 플랫폼에서 켜고 끄거나 언어를 바꿀 수 있습니다. 가장 널리 쓰는 자막 파일 형식이 **SRT**입니다.

```text
1
00:00:05,000 --> 00:00:07,500
도윤: 같이 쓸래요?

2
00:00:10,200 --> 00:00:13,000
수아: 버스, 오늘은 늦게 와도 되겠다.
```

번호, `시작 --> 끝`(시:분:초,밀리초), 문장, 빈 줄이 한 묶음입니다.

### 납품과 보관

| 파일 | 목적 | 원칙 |
| --- | --- | --- |
| 마스터 | 보관·재가공의 원본 | 작품 그대로의 비율·크기, 가장 좋은 품질. 자막은 별도 파일로 함께 보관 |
| 배포본 | 플랫폼별 업로드 | 플랫폼 비율에 맞춤(16:9 · 9:16 · 1:1), 필요하면 자막을 입힘 |
| 분리 트랙 | 다른 편집 프로그램에서 소리 다시 섞기 | 대사 · 음악 · 효과음을 따로 |

파일 이름에는 작품 · 판 · 비율 · 날짜를 넣어 두면 나중에 찾기 쉽습니다. 예) `비오는정류장_v2_16x9_20261101.mp4`

### FECINE에서 하기

1. **편집**에서 **배경음악**·**효과음** 클립을 선택해 **음량**과 **페이드 인**/**페이드 아웃**을 정합니다([29장](/v1/chapters/29-subtitles-music-cards)).
2. **자막** 탭에서 **글자 크기**(24–96), **위치**(하단/상단), **배경 띠**, **화자 이름 표시**를 정합니다.
3. **내보내기** 출력 탭의 **자막**에서 **영상에 입힘** · **별도 파일** · **없음** 중 하나를 고릅니다.
4. 다른 프로그램에서 소리를 다시 섞을 계획이면 **대사 · 음악 분리 트랙**을 켭니다. 대사·음악·효과음이 WAV로 따로 만들어집니다.
5. 렌더가 끝나면 **렌더 이력**의 **자막 · 분리 트랙**에서 자막(SRT)과 분리 트랙을 받을 수 있습니다.

::: warning 주의
렌더 이력의 파일은 **보관 기간 지남**이 되면 받을 수 없습니다. 마스터와 자막 파일은 받아서 따로 보관하세요.
:::

## PRACTICE — 납품 준비

**실습 F3-1 소리 균형 점검표**

| 구간 | 대사 | 음악 | 앰비언스·효과음 | 확인 |
| --- | --- | --- | --- | --- |
| 씬 1 (대사 없음) | — | 조금 높게 | 빗소리 | 휴대폰 스피커로 들어 보기 |
| 씬 2 | 가장 크게 | 낮게 | 빗소리 작게 | 대사가 또렷한가 |
| 씬 3 | 가장 크게 | 낮게 → 끝에서 페이드 아웃 | 버스 도착 소리 | 끝이 갑자기 끊기지 않는가 |

**실습 F3-2 납품 체크리스트**

- [ ] 마스터(MP4 / H.264, 작품 원본 크기)를 받았다.
- [ ] 자막을 별도 파일(SRT)로도 받았다.
- [ ] 올릴 플랫폼별 배포본(비율·자막 입힘 여부)을 정했다.
- [ ] 파일 이름에 작품·판·비율·날짜를 넣었다.
- [ ] 음악·목소리·이미지의 사용 권리를 확인했다([11장](/v1/chapters/11-evaluation-safety-copyright)).

::: cost COST · 비용
소리·자막 설정은 무료입니다. 마스터와 배포본을 따로 내보내면 내보내기 요금이 각각 듭니다([부록 A](/v1/appendix/a-models-cost)). 어떤 파일이 필요한지 먼저 정하고 내보내세요.
:::

## REVIEW — 제대로 했나요?

- [ ] 대사를 기준으로 소리 균형을 잡는 이유를 설명할 수 있다.
- [ ] SRT 한 묶음의 구성을 안다.
- [ ] 마스터와 배포본의 차이를 안다.

| 상황 | 원인 | 해결 |
| --- | --- | --- |
| 대사가 음악에 묻힘 | 음악 음량이 큼 | 음악 클립 **음량**을 낮추기 |
| 끝에서 소리가 뚝 끊김 | 페이드 없음 | **페이드 아웃** 설정 |
| 자막을 다른 언어로 바꾸고 싶음 | 영상에 입힌 자막은 바꿀 수 없음 | **별도 파일**로 내보내 번역본 만들기 |
| 예전 렌더 파일을 받을 수 없음 | 보관 기간 지남 | 다시 렌더하거나, 앞으로는 받아서 보관 |

**확인 문제**

1. 소리를 섞을 때 기준이 되는 소리는?
2. 자막을 별도 파일로 주면 좋은 점은?
3. SRT에서 `00:00:05,000`의 마지막 세 자리는 무엇인가요?

정답: 1. 대사 2. 플랫폼에서 켜고 끄거나 다른 언어 자막으로 바꿀 수 있다. 3. 밀리초

**응용 과제** 「비 오는 정류장」의 대사 두 줄로 SRT 파일을 직접 써 보고, FECINE에서 **별도 파일**로 받은 SRT와 비교해 보세요.
