# 이미지 생성 AI

이미지 생성 AI는 프롬프트와 참조 이미지로 정지 화면을 만듭니다. FECINE에서는 **등장인물** · **공간·배경** · **미술·소품** 이미지([20장](/v1/chapters/20-characters), [21장](/v1/chapters/21-backgrounds-props)), 캐릭터 시트([22장](/v1/chapters/22-character-sheets)), **샷 이미지**([26장](/v1/chapters/26-scene-frames))를 만들 때 씁니다.

## FECINE v1.82.0의 이미지 모델

모델 이름과 참조 이미지 한도, 한 번에 만드는 후보 수만 모델 정의에서 확인했습니다(v1.82.0 기준으로 다시 대조하지 않은 값은 v1.74.0 확인값).  요금은 공개 [모델·가격](https://fecine.ai/models/pricing) 페이지(2026-11-05 기준, USD 1 = 1 크레딧)에서 확인했습니다. 개발사·특징은 아직 검증하지 않았습니다.

::: tip FECINE에서 확인하는 법
이미지를 만들 때 모델을 고르면 모델에 따라 비율·크기·수량, 품질·형식·배경(투명) 같은 선택지가 달라집니다. 캐릭터 시트는 대표 이미지와 참조 이미지를 받는 모델이 필요합니다(22장). 샷 이미지의 `장수`는 모델이 한 번에 만들 수 있는 만큼 고를 수 있고, 후보를 1장만 만드는 모델(Nano Banana 계열)에서는 `장수` 선택이 보이지 않습니다. 후보는 실제로 받은 장수만큼만 크레딧이 차감되고, 일부만 만들어지면 “후보 {n}장은 만들었지만 나머지는 만들지 못했어요. 만들지 못한 후보는 크레딧이 차감되지 않았어요.”가 나옵니다.

모델 목록은 예상 크레딧이 낮은 순이고 `제공사`로 거를 수 있습니다. 같은 모델이 Standard · Enterprise · Global 경로로 여럿이면 경로마다 가격이 다르며([12장](/v1/chapters/12-choosing-models)), 공식 가격보다 싸면 `↓` 할인율이 붙습니다. Nano Banana처럼 **수정 전용** 모델은 목록에 `참조 이미지 필요`가 표시되고, 참조 이미지를 1장 이상 넣어야 고를 수 있습니다. 마음에 들지 않는 후보는 이미지 화면에서 **이 이미지 지우기**로 지울 수 있고, 지운 이미지는 작품정보의 휴지통으로 옮겨집니다.
:::
