FECINE의 모델 목록은 예상 크레딧이 낮은 순입니다. 같은 모델이 Standard · Enterprise · Global 경로로 여럿이면 한 줄로 묶여 경로마다 가격이 다르고(Enterprise·Global은 이름 옆 아이콘), 공식 가격보다 싼 모델에는 `↓` 할인율이 붙습니다. 모델 종류별 가격 비교는 공개 메뉴 `모델·가격`에서 `제공사`·`유형`으로 거르고 `정렬`합니다([12장](/v1/chapters/12-choosing-models)).

## 비교와 요금

모델별 비교표와 크레딧 요금은 [부록 A 모델과 비용](/v1/appendix/a-models-cost)에 있습니다.

::: warning 모델 정보의 원칙
모델의 지원 기능·성능·가격은 추측하지 않습니다. 확인하지 못한 값은 <Badge type="warning" text="확인 필요" />로 표시하고, 모든 모델 페이지에 기준 버전·출처·확인 날짜를 적습니다. 작성 기준은 [모델 페이지 작성 기준](/v1/models/template)을 따릅니다.
:::
