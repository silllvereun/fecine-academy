# 모델 페이지 작성 기준

AI 모델 가이드의 모든 모델 페이지는 아래 순서와 규칙을 따릅니다. 새 모델을 추가할 때는 저장소의 `academy/templates/model-template.md`를 복사해 씁니다.

## 표준 항목

| 순서 | 항목 | 쓰는 내용 |
| --- | --- | --- |
| 1 | 모델 이름 및 개발사 | FECINE 화면에 보이는 이름 그대로. 개발사는 공식 출처로 확인 |
| 2 | 모델의 역할과 생성 원리 | FECINE에서 맡는 역할, 생성 방식 |
| 3 | 입력 및 출력 유형 | 프롬프트·참조 이미지·참조 음성 / 길이·해상도·비율 |
| 4 | 주요 기능과 장점 | 확인된 기능만 |
| 5 | 제약사항 및 한계 | 지원하지 않는 비율·참조·음성 등 |
| 6 | 추천 활용 상황 | 확인된 사양에서 판단한 쓰임 |
| 7 | FECINE에서 사용하는 방법 | 화면 이름·버튼 이름 그대로, 관련 장 링크 |
| 8 | 실제 생성 예제 | FECINE에서 실제 생성한 결과만. 없으면 “자료 준비 중” |
| 9 | 비용 및 생성 시간 | 화면 표시값 기준. 측정값은 버전·조건과 함께 |
| 10 | 다른 모델과 비교 | 부록 A의 비교표 링크 |
| — | 출처와 확인 | 기준 버전, 출처, 확인 날짜 |

## 검증 규칙

::: warning 추측하지 않습니다
- 지원 기능, 성능, 가격은 FECINE 화면·설정이나 공식 문서로 확인한 값만 씁니다.
- 확인하지 못한 값은 <Badge type="warning" text="확인 필요" />로 둡니다. 비워 두거나 다른 모델 값으로 채우지 않습니다.
- 측정값(생성 시간, 실제 차감 크레딧)은 측정한 FECINE 버전, 해상도, 길이를 함께 적습니다.
- 페이지마다 **기준 버전 · 출처 · 확인 날짜**를 적습니다. FECINE 버전이 바뀌면 다시 확인하고 날짜를 고칩니다.
:::

## 장(chapter) 페이지와의 관계

모델 이름과 수치는 본문 장에 직접 쓰지 않고 이 메뉴와 [부록 A](/v1/appendix/a-models-cost)에만 둡니다. 그래서 모델이 바뀌어도 본문은 그대로 두고 모델 페이지와 부록 A만 고치면 됩니다.
