# 4장 카메라 언어: 샷 크기·앵글·움직임·렌즈

<ChapterGoals />

::: info 이 장의 예제
이 책은 예제 작품 「비 오는 정류장」을 이어서 만듭니다. 비 오는 밤, 우산 없는 수아에게 처음 보는 도윤이 우산을 건네는 15초짜리 영상(씬 3개)입니다. FECINE을 아직 써 보지 않았다면 화면 따라 하기는 건너뛰고 개념과 표만 읽어도 됩니다.
:::

## WHY — 같은 장면인데 왜 다르게 느껴질까요?

비 오는 정류장에 혼자 선 사람도, 멀리서 보면 외로움이, 얼굴을 가까이 보면 초조함이 느껴집니다. 카메라는 관객의 눈이고, 어디서 어떻게 보여줄지가 감정을 정합니다.

- 샷 크기·앵글·움직임·렌즈·구도가 주는 느낌을 구분한다.
- FECINE `카메라` 탭에서 원하는 촬영 방식을 고른다.
- 같은 씬을 세 가지 카메라로 만들어 비교한다.

**완성 결과물** — 씬 1을 와이드·클로즈업·하이 앵글로 만든 대표 프레임 3장 (결과 04-A)

## HOW — 카메라가 말하는 방식

### 샷 크기: 얼마나 가까이 볼까

| FECINE 선택지 | 화면에 담기는 것 | 주는 느낌·쓰임 |
| --- | --- | --- |
| `익스트림 와이드` | 넓은 풍경, 사람은 아주 작게 | 장소 소개, 압도감·고립감 |
| `와이드` | 장소와 사람의 관계 | 장면의 시작, 상황 설명 |
| `풀 샷` | 사람의 전신 | 동작·의상 보여주기 |
| `미디엄` | 허리 위 | 대화, 일상적인 거리감 |
| `미디엄 클로즈업` | 가슴 위 | 감정이 드러나기 시작 |
| `클로즈업` | 얼굴 | 표정·반응, 감정 강조 |
| `익스트림 클로즈업` | 눈·손 등 일부 | 긴장, 중요한 디테일 |

### 앵글: 어느 높이에서 볼까

| FECINE 선택지 | 느낌 |
| --- | --- |
| `아이 레벨` | 중립적, 관객과 대등 |
| `로우 앵글` | 인물이 크고 강해 보임 |
| `하이 앵글` | 인물이 작고 약해 보임 |
| `버즈 아이(부감)` | 위에서 내려다본 전체 모습 |
| `더치 앵글` | 기울어진 화면, 불안·혼란 |
| `오버 더 숄더` | 한 사람의 어깨 너머로 상대를 봄, 대화 |
| `주관 시점` | 인물의 눈으로 봄 |

### 움직임·렌즈·구도

- **카메라 움직임** — 예: `고정`(차분함), `푸시 인`(카메라가 다가가며 집중), `풀 아웃`(물러나며 쓸쓸함), 팬(좌우로 둘러보기), `트래킹`(인물을 따라가기). 처음에는 움직임을 하나만 고릅니다.
- **렌즈** — mm 숫자가 작을수록 넓게(광각), 클수록 멀리 있는 것을 당겨 좁게(망원) 담습니다. 예: `24mm 광각`(넓은 공간), `35mm`(눈으로 보는 것과 비슷), `85mm 인물`(얼굴을 돋보이게). `얕은 심도`는 인물만 또렷하고 배경이 흐려지는 화면입니다.
- **구도** — 예: `중앙`, `삼분할`(인물을 화면 가운데가 아닌 1/3 지점에 두기), `대칭`, `여백`. 잘 모르겠으면 자동으로 둡니다.

### FECINE에서 하기 — `카메라` 탭

1. `스토리보드`에서 씬을 고르고 오른쪽 위 `카메라` 탭을 누릅니다.
2. `클립 전체`에서 `샷 크기`, `앵글`, `카메라 움직임`, `렌즈`, `구도`를 고릅니다. 모두 처음에는 `자동`입니다.
3. 고른 항목은 ‘생성할 때 프롬프트 끝에 붙는 문장’으로 보입니다. `저장됨`이 뜨면 끝입니다.
4. 다시 처음으로 돌리려면 `모두 자동으로`를 누릅니다.

**[캡처 16-01]** 카메라 탭 — ① 샷 크기 `와이드` ② 카메라 움직임 `푸시 인`

![캡처 16-01](/images/v1/captures/cap-16-01.png)

::: tip TIP
프롬프트에 이미 ‘멀리서 천천히 다가간다’처럼 카메라 설명이 있다면 그 항목은 `자동`으로 둡니다. 두 곳에 서로 다른 지시가 있으면 AI가 헷갈립니다.
:::

::: info NOTE
씬에 샷을 여러 개 나눠 두었다면 `샷별 카메라`에서 샷마다 `연결`(앞 샷에서 이어서/컷 전환), `시작 화면`, `움직임`, `속도`, `끝 화면`을 따로 정합니다. 이때 클립 전체의 샷 크기·앵글·움직임은 쓰이지 않고, 렌즈와 구도만 적용됩니다(25장).
:::

## PRACTICE — 같은 씬, 세 가지 카메라

씬 1의 프롬프트는 그대로 두고 카메라만 바꿔 세 번 만듭니다. 실제 생성은 27장에서 배우므로, 지금은 설정만 정해 두고 결과 04-A와 비교해도 됩니다.

| 버전 | 샷 크기 | 앵글 | 카메라 움직임 | 렌즈 | 기대하는 느낌 |
| --- | --- | --- | --- | --- | --- |
| A | `와이드` | `아이 레벨` | `푸시 인` | `35mm` | 외로움, 천천히 다가감 |
| B | `클로즈업` | `아이 레벨` | `고정` | `85mm 인물` | 초조한 표정 |
| C | `풀 샷` | `하이 앵글` | `고정` | `24mm 광각` | 빗속에 갇힌 작은 사람 |

::: cost COST · 비용
설정을 고르는 것은 무료입니다. 세 버전을 실제로 생성하면 영상 3회분의 크레딧이 듭니다. 비교용이라면 짧은 길이·낮은 해상도로 충분합니다.
:::

## REVIEW — 제대로 했나요?

- [ ] 샷 크기 7가지를 가까운 순서로 말할 수 있다.
- [ ] 로우 앵글과 하이 앵글이 주는 느낌을 구분한다.
- [ ] `카메라` 탭에서 항목을 고르고 `모두 자동으로`로 되돌릴 수 있다.

| 자주 겪는 실패 | 원인 | 해결 |
| --- | --- | --- |
| ‘입력 길이 초과’ 오류 | 카메라·스타일 선택이 모두 문장으로 붙음 | 꼭 필요한 항목만 고르고 나머지는 `자동` |
| 고른 카메라와 다르게 나옴 | 프롬프트 안의 카메라 설명과 충돌 | 한 곳에만 쓰기 |
| 움직임이 과하거나 어지러움 | 짧은 씬에 큰 움직임 여럿 | 씬 하나에 움직임 하나 |
