# 2장 기존 영상 제작과 AI 영상 제작의 차이

<ChapterGoals />

::: info 이 장의 예제
이 책은 예제 작품 「비 오는 정류장」을 이어서 만듭니다. 비 오는 밤, 우산 없는 수아에게 처음 보는 도윤이 우산을 건네는 15초짜리 영상(씬 3개)입니다. FECINE을 아직 써 보지 않았다면 화면 따라 하기는 건너뛰고 개념과 표만 읽어도 됩니다.
:::

## WHY — 무엇이 쉬워지고, 무엇이 여전히 사람의 일일까요?

AI가 촬영을 대신해도 영상을 기획하고 고르고 잇는 일은 여전히 사람의 몫입니다. 이 차이를 알면 어디에 시간을 써야 하는지 보입니다.

- 기존 제작과 AI 제작의 단계를 비교한다.
- AI 제작에서 사람이 맡는 역할 네 가지를 말한다.
- FECINE의 제작 모듈을 제작 단계에 대응시킨다.

**완성 결과물** — 「비 오는 정류장」을 기존 방식과 AI 방식으로 만들 때의 제작 과정 비교표

## HOW — 어떻게 다른가요?

### 기존 영상 제작의 세 단계

일반적인 영상 제작은 세 단계로 나뉩니다. 촬영 전에 준비하는 **프리프로덕션**, 카메라로 찍는 **프로덕션**, 찍은 것을 다듬는 **포스트프로덕션**입니다. 실사 영상은 보통 촬영 단계에 비용과 시간이 많이 듭니다. 장소를 빌리고, 배우와 스태프를 모으고, 날씨와 빛을 기다려야 합니다.

### AI 영상 제작의 다섯 단계

AI 제작에서는 촬영이 ‘생성’으로 바뀝니다. 대신 촬영 전에 인물과 장소를 그림으로 고정하는 ‘비주얼’ 단계가 생깁니다. 배우가 없으니 ‘같은 사람’을 그림으로 정해 두어야 하기 때문입니다.

| 기존 제작 | AI 제작 | FECINE 메뉴 |
| --- | --- | --- |
| 기획·대본 | 기획 | `작품정보`, `스토리`(대본이 있으면 `스토리` 안의 `✦ AI 자동생성` 탭) |
| 캐스팅·미술·로케이션 | 비주얼 | `등장인물`, `미술·소품`, `공간·배경`, `음향` |
| 콘티·촬영 | 생성 | `콘티`, `샷 이미지`, `스토리보드` |
| 편집·색보정·사운드 | 편집 | `편집` |
| 마스터링·배급 | 배포 | `내보내기` |

### 무엇이 쉬워지고 무엇이 남는가

| 쉬워지는 것 | 여전히 사람의 일 |
| --- | --- |
| 장소·배우·장비 없이 씬 만들기 | 무엇을 보여줄지 정하는 **기획** |
| 마음에 안 들면 몇 분 만에 다시 찍기 | 결과를 보고 고르는 **판단** |
| 비싼 장면(폭발·군중·날씨) 만들기 | 같은 인물·장소를 유지하는 **일관성 관리** |
| 여러 버전 비교하기 | 씬을 잇고 리듬을 만드는 **편집** |

::: info NOTE
AI 제작은 ‘한 번 누르면 완성’이 아닙니다. 만들고, 보고, 고치고, 다시 만드는 반복이 기본입니다. FECINE이 결과를 테이크(T1, T2…)로 모아 두는 이유입니다.
:::

### FECINE에서 확인하기

1. 작품을 하나 열고 왼쪽 `제작 모듈` 메뉴 12개를 위에서 아래로 읽습니다. 단계가 바뀌는 곳마다 구분선이 있습니다.
2. 메뉴에 마우스를 올리면 부제(예: `스토리보드` — 씬 구성 · 영상 생성)가 보입니다. 위 표의 단계와 맞춰 봅니다.
3. `작품정보`의 `제작 현황` 8칸이 같은 흐름을 보여 주는지 확인합니다.

## PRACTICE — 직접 해 보기

1장의 기획 메모를 보며, 「비 오는 정류장」을 두 방식으로 만들 때 필요한 것을 적습니다. 빈칸을 채우고 예시와 비교하세요.

```text
[제작 과정 비교표] 「비 오는 정류장」 15초

단계      | 기존 방식에 필요한 것          | AI 방식(FECINE)에 필요한 것
기획      | 대본, 콘티                      | 씬 3개의 설명과 씬 대본
비주얼    | 배우 2명, 정류장 로케이션, 우산  | 수아·도윤 이미지, 정류장 배경, 우산 소품
생성/촬영 | 비 오는 밤 촬영, 살수차       | 씬별 프롬프트·카메라 설정, 재생성
편집      | 편집 프로그램, 색보정           | 자동 배치, 씬 전환, 자막
배포      | 인코딩                         | 출력 프리셋으로 렌더
```

::: tip TIP
‘살수차’처럼 기존 방식에서 비싼 항목이 AI 방식에서는 프롬프트(AI에게 글로 주는 지시문) 한 줄로 바뀝니다. 반대로 ‘같은 얼굴 유지’처럼 기존에는 저절로 되던 일이 AI에서는 따로 챙겨야 하는 일이 됩니다.
:::

## REVIEW — 제대로 했나요?

- [ ] 기존 제작의 세 단계와 AI 제작의 다섯 단계를 말할 수 있다.
- [ ] AI 제작에서 ‘비주얼’ 단계가 따로 필요한 이유를 설명할 수 있다.
- [ ] 제작 과정 비교표를 채웠다.

| 자주 하는 오해 | 실제 |
| --- | --- |
| AI가 알아서 한 편을 만들어 준다 | 씬 단위로 만들고 사람이 고르고 잇는다 |
| 한 번 만든 결과를 그대로 쓴다 | 보통 씬마다 여러 번 만들고 테이크를 고른다 |
| 모든 메뉴를 순서대로 거쳐야 한다 | `✦ AI 자동생성`, `음향`, `샷 이미지`는 건너뛸 수 있다 |
