# 29장 자막·음악·제목 카드·색보정

<ChapterGoals />

## WHY

> 영상은 좋은데 왜 '완성된 작품'처럼 보이지 않을까요?

- 자막을 읽기 쉽게 넣고 위치·크기를 다듬습니다.
- 배경음악과 효과음을 넣고 음량을 맞춥니다.
- 제목 카드·엔딩 카드와 색보정으로 작품의 통일감을 만듭니다.

**완성 결과물** 「비 오는 정류장」 편집본 v2 (자막·빗소리·배경음악·제목/엔딩 카드·따뜻한 룩)

## HOW

### 보고 듣는 완성도

관객은 화면보다 **소리의 어색함**을 더 빨리 느낍니다. 또 휴대폰으로 소리 없이 보는 사람이 많아서 자막은 이제 기본입니다.

| 요소 | 좋은 상태 | 흔한 실수 |
| --- | --- | --- |
| 자막 | 한 줄 15자 안팎, 화면에 1.5초 이상 | 너무 작거나 밝은 배경 위에 흰 글자 |
| 배경음악 | 대사보다 작게, 처음·끝은 페이드 | 대사를 덮음, 끝에서 뚝 끊김 |
| 효과음·앰비언스(장소의 배경 소리) | 장소를 설명하는 소리(빗소리, 버스 소리) | 화면과 안 맞는 소리 |
| 제목·엔딩 카드 | 2–3초, 짧은 문구 | 너무 길거나 글자가 많음 |
| 색보정 | 모든 클립이 같은 톤 | 씬마다 색이 튐 |

### FECINE에서 하기 — 자막

1. 편집본 v1을 열고 <Badge type="warning" text="저장한 편집본을 다시 여는 방법 확인 필요" /> 위쪽 **대사에서 자막 자동 생성**을 누릅니다. 대사가 있는 테이크가 있으면 `자막 n개를 만들었습니다`가 나타나고 자막 트랙에 블록이 생깁니다.
2. 대사가 없는 씬에 글을 넣으려면 재생 위치를 옮기고 **재생 위치에 자막 추가**를 누릅니다. **새 자막** 블록이 생기면 문구를 고칩니다.
3. 타임라인의 자막 블록을 끌어 시작 위치와 길이를 맞춥니다.
4. **속성**의 **자막** 탭에서 **글자 크기**(24–96), **위치**(하단/상단), **배경 띠**, **화자 이름 표시**를 정합니다.

### FECINE에서 하기 — 음악·효과음

1. **미디어**의 **음악 · 효과음**을 엽니다. 작품의 **음향** 메뉴에 올린 파일이 보입니다. **전체 / 이 작품 / 공용**으로 걸러 보고, **이름으로 검색**할 수 있습니다.
2. 파일을 **미리 듣기**한 뒤 **배경음악** 또는 **효과음**으로 넣습니다. 가지고 있는 파일은 **올리기**로 추가합니다.
3. 타임라인의 오디오 클립을 선택하고 **음량**을 낮추고 **페이드 인**/**페이드 아웃**을 정합니다.

### FECINE에서 하기 — 카드·색보정

1. **미디어**의 **카드**에서 **제목 카드 추가**와 **엔딩 카드 추가**를 누릅니다. 각 카드의 **문구**, **부제**, **길이**를 고칩니다.
2. 아무 클립을 선택하고 **속성**의 **색보정** 탭을 엽니다. **룩**에서 **원본 / 따뜻하게 / 차갑게 / 흑백** 중 하나를 고르고, **노출**·**대비**·**채도**를 미세하게 조절합니다.
3. **모든 클립에 적용**을 눌러 작품 전체 톤을 맞춥니다.
4. **편집본 저장 (v2)** 를 누릅니다.

**[캡처 29-01]** <Badge type="warning" text="캡처 준비 중" /> 자막 탭 — ① 대사에서 자막 자동 생성 ② 자막 트랙 ③ 글자 크기 ④ 위치 ⑤ 배경 띠

**[캡처 29-02]** <Badge type="warning" text="캡처 준비 중" /> 음악 · 효과음과 카드 — ① 미리 듣기 ② 배경음악 트랙 ③ 음량·페이드 ④ 제목 카드 추가

::: info NOTE
**자막 언어**는 자막이 어떤 언어인지 표시하는 값입니다. 바꿔도 문구가 번역되지는 않습니다. 다른 언어 자막이 필요하면 문구를 직접 고칩니다.
:::

::: tip TIP
스토리에서 씬을 합치거나 옮기거나 지워 클립이 빠져도, 그 위에 있던 자막은 지워지지 않고 자리에 남습니다. 씬 구조를 바꾼 뒤에는 자막 위치를 다시 확인하세요.

대사를 고친 뒤 **대사에서 자막 자동 생성**을 다시 누르면 `자막 n개를 대사에서 다시 만들었습니다`가 나오며 새로 만들어집니다. 직접 손본 자막이 있다면 누르기 전에 편집본을 저장해 두세요.
:::

::: warning 주의
인터넷에서 내려받은 음악은 대부분 저작권이 있습니다. 30장의 게시 요청에서는 음악을 포함한 모든 요소에 대한 권리를 확인해야 합니다. 직접 만든 음악, 사용 허락을 받은 음악만 씁니다.
:::

## PRACTICE

**실습 29-1 자막 문구**

```text
씬 1  (자막 없음 — 빗소리만)
씬 2  도윤: 같이 쓸래요?
씬 3  수아: 버스, 오늘은 늦게 와도 되겠다.
```

**실습 29-2 소리·카드·룩 설정표**

| 항목 | 설정 |
| --- | --- |
| 효과음 | 빗소리(전체), 버스 도착 소리(씬 3 끝) |
| 배경음악 | 잔잔한 피아노, 음량 낮게, 페이드 인 · 페이드 아웃 |
| 제목 카드 | 문구 “비 오는 정류장”, 길이 2초 |
| 엔딩 카드 | 문구 “끝”, 부제 “FECINE으로 만듦” |
| 색보정 | 룩 따뜻하게 → 모든 클립에 적용 |

## REVIEW

- [ ] 자막이 배경에 묻히지 않고 잘 읽힌다.
- [ ] 배경음악이 대사를 덮지 않는다.
- [ ] 제목 카드와 엔딩 카드를 넣었다.
- [ ] 모든 클립의 톤을 맞췄다.
- [ ] 편집본 v2를 저장했다.

| 상황 | 화면 문구 | 해결 |
| --- | --- | --- |
| 자막이 안 생김 | 대사가 있는 테이크가 없어 자막을 그대로 두었습니다 | **재생 위치에 자막 추가**로 직접 입력 |
| 음악 목록이 비어 있음 | 작품 음향에 올린 파일이 여기에 나타납니다 | **올리기**로 파일 추가 |
| 검색에 없음 | 검색 결과가 없습니다 | 필터를 **전체**로 바꾸고 다시 검색 |
| 번역이 안 됨 | (자막 언어를 바꿔도 문구 그대로) | 자막 언어는 표시용. 문구를 직접 번역 |

**확인 문제**

1. 배경음악의 처음과 끝에 페이드를 넣는 이유는 무엇인가요?
2. 색보정을 한 클립에만 하면 어떤 문제가 생기나요?
3. **자막 언어**를 영어로 바꾸면 자막 문구는 어떻게 되나요?

정답: 1. 소리가 갑자기 시작하거나 뚝 끊기지 않게 하려고. 2. 그 씬만 톤이 달라 튄다. **모든 클립에 적용**을 쓴다. 3. 번역되지 않고 그대로다.

**응용 과제** 같은 편집본을 룩 **차갑게**와 **흑백**으로 바꿔 보고, 「비 오는 정류장」의 분위기에 가장 어울리는 것을 고른 이유를 적어 보세요.
