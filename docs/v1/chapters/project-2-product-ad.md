# 실습 2 제품 홍보 영상

<ChapterGoals />

## WHY

> 사람이 아니라 제품이 주인공일 때, 제품 모양이 장면마다 바뀌지 않게 하려면 어떻게 해야 할까요?

- 템플릿 **30초 제품 광고**로 광고의 기본 구조를 따라 만듭니다.
- 제품을 **소품**으로 만들어 모든 장면에 연결합니다.
- 세로 9:16 영상으로 내보냅니다.

**완성 결과물** 9:16 30초 제품 광고 1편 (결과 P2-A)

## HOW

**30초 제품 광고** 템플릿은 회차 “30초 스팟”을 약 7초씩 네 부분으로 나눠 두었습니다.

| 장면 | 템플릿 설명 | 이 실습의 내용 (예: 보온 텀블러) |
| --- | --- | --- |
| 문제 | 타깃이 공감하는 일상의 불편 | 출근길, 금방 식어 버린 커피 |
| 제품 공개 | 제품을 깔끔하고 자신 있게 등장 | 흰 배경 위 텀블러, 천천히 회전 |
| 사용 장면 | 실제 손과 실제 결과로 문제 해결 | 점심에 뚜껑을 열자 김이 오름 |
| 행동 유도 | 로고와 혜택, 다음에 할 일 하나 | 엔딩 카드: 로고 + “지금 만나보세요” |

| 단계 | 할 일 | 다시 볼 장 |
| --- | --- | --- |
| 1 작품 만들기 | 템플릿 **30초 제품 광고**, 9:16 | 16장 |
| 2 스토리 | 네 장면의 지문을 내 제품에 맞게 고침 | 17–18장 |
| 3 소품 | 제품을 소품으로 만들고 정면·측면·디테일 앵글 저장 | 21장 |
| 4 장면 구성 | 모든 장면에 제품 소품 연결 | 24장 |
| 5 장면 프레임·생성 | 제품이 나오는 장면은 프레임을 먼저 | 26–27장 |
| 6 편집 | 제목 카드·엔딩 카드, 자막, 배경음악 | 28–29장 |
| 7 내보내기 | **Shorts · Reels** 프리셋 | 30장 |

::: tip TIP
제품 사진을 가지고 있다면 소품 이미지를 생성하기보다 실제 사진을 올려 참조로 쓰는 편이 모양 변형을 줄입니다. 제품 이름·로고 글자는 영상 모델이 정확히 그리지 못하므로 화면 속 글자 대신 **엔딩 카드**로 넣습니다.
:::

::: warning 주의
다른 회사의 상표나 제품을 허락 없이 광고에 쓰지 않습니다(11장).
:::

## PRACTICE

**제품 소품 설명 (예시)**

```text
소품 이름: 보온 텀블러
요약: 무광 네이비 스테인리스 텀블러, 높이 18cm, 투명한 슬라이드 뚜껑, 손잡이 없음.
아트 노트: 글자·로고 없음. 모서리는 둥글고, 표면에 잔잔한 빛 반사.
```

**장면 2 영상 프롬프트 (예시)**

```text
@보온 텀블러 가 흰 배경 위 회전판에서 천천히 회전한다.
부드러운 스튜디오 조명, 옆에서 빛이 길게 흐른다. 카메라는 고정.
```

| --- | --- |

::: cost COST · 비용
유료 실습입니다. 장면이 4개, 장면당 약 7초라 실습 1보다 영상 생성량이 많습니다. 로고 없이 내보내면 추가 요금이 있으니, 연습 단계에서는 로고 포함으로 내보냅니다.
:::

## REVIEW

- [ ] 네 장면의 제품 모양·색이 같다.
- [ ] 문제 → 제품 공개 → 사용 장면 → 행동 유도가 30초 안에 들어간다.
- [ ] 제품 이름·혜택은 화면 속 글자가 아니라 카드·자막으로 넣었다.
- [ ] 9:16에서 제품이 잘리지 않는다.

| 상황 | 해결 |
| --- | --- |
| 제품 모양이 장면마다 다름 | 소품이 장면에 연결됐는지 확인, 장면 프레임을 먼저 만들기 |
| 화면에 이상한 글자가 생김 | 프롬프트에서 글자·로고 표현을 빼고 테이크 평가에서 “글자·워터마크” 팁 확인 |
| 세로 화면에서 제품이 잘림 | 작품을 처음부터 9:16으로 만들거나, 내보내기에서 **피사체 따라가기** |
