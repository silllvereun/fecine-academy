# 23장 등장인물 목소리 연결

<ChapterGoals />

## WHY — 목소리도 인물의 일부입니다

얼굴이 같아도 씬마다 목소리가 다르면 다른 사람처럼 느껴집니다. FECINE에서는 등장인물에 목소리 파일을 연결해 두면, 그 인물이 나오는 영상을 만들 때 목소리가 함께 전달됩니다.

- `음향`에 목소리·음악 파일을 올린다.
- 등장인물 상세에서 목소리 파일을 `보이스`로 정한다.
- 보이스 참조의 한계를 안다.

**완성 결과물** — 보이스가 연결된 수아

## HOW — 화면 따라 하기

1. 제작 모듈에서 `음향`을 누릅니다. 비어 있다면 ‘아직 오디오가 없어요. 음성이나 음악 파일을 올리면 등장인물 보이스로 쓸 수 있어요.’가 보입니다.
2. `오디오 추가`를 누르고 `업로드` 탭에서 파일(MP3·WAV·AAC·OGG)을 고릅니다. 스튜디오 라이브러리에 있는 오디오를 가져오는 탭도 있습니다.
3. 목록에서 재생해 확인하고, 필요하면 `이름 바꾸기`로 ‘수아_목소리’처럼 바꿉니다. 각 파일 옆에는 그 파일을 보이스로 쓰는 등장인물이 칩으로 보이고(없으면 `쓰는 등장인물 없음`), 칩을 누르면 그 등장인물로 이동합니다.
4. 보이스는 **등장인물 쪽에서** 정합니다. `등장인물`에서 수아를 열고 `보이스` 칸의 `보이스 선택`을 누릅니다. `보이스 선택` 패널의 `라이브러리에서` 탭에서 방금 올린 파일을 고르거나, `업로드` 탭에서 바로 올립니다. 이미 보이스가 있으면 `변경`, 없애려면 `보이스 제거`, 들어 보려면 `미리 듣기`를 누릅니다.

::: info NOTE
FECINE V1에는 목소리를 새로 만드는 음성 합성(TTS)이 없습니다. 연결한 목소리는 **참조**로 영상 모델에 전달되고, 실제 대사 음성은 영상 모델이 만듭니다. 참조 음성을 받지 못하는 모델도 있습니다(‘이 모델은 참조 음성을 사용할 수 없어요’, 부록 A). 긴 참조 음성은 15초로 잘라서 씁니다. 사이드 메뉴 `캐릭터`의 `목소리` 탭에 공개된 목소리를 작품에 추가해 쓸 수도 있으며, 추가할 때마다 사용료가 듭니다(20장).
:::

::: warning 주의
다른 사람의 목소리는 본인 동의 없이 쓰지 않습니다. 직접 녹음한 목소리나 사용 허락을 받은 파일만 올립니다.
:::

## PRACTICE — 수아 보이스 연결

1. 휴대폰 녹음기로 자신의 목소리를 10–20초 녹음하고, 파일을 PC로 옮깁니다. FECINE에는 MP3·WAV·AAC·OGG만 올릴 수 있으므로, 아이폰 음성 메모처럼 .m4a로 저장되는 파일은 MP3로 바꿔서 올립니다. 조용한 곳에서 아래 문장을 천천히 읽습니다.

```text
오늘따라 왜 이렇게 안 와. 비는 그칠 생각을 안 하네.
고마워요. 덕분에 덜 젖었어요.
```

1. 파일을 `음향`에 올리고 `이름 바꾸기`로 ‘수아_목소리’로 바꿉니다.
2. `등장인물` → 수아 → `보이스` → `보이스 선택` → ‘수아_목소리’.
3. 27장에서 씬 1을 만들 때 목소리가 비슷하게 나오는지 확인합니다.

::: cost COST · 비용
음향 파일 업로드와 연결은 무료입니다.
:::

## REVIEW — 제대로 했나요?

- [ ] `음향` 목록에 파일이 있고 재생된다.
- [ ] 수아의 `보이스` 칸에 목소리가 보이고, `음향` 목록의 그 파일 옆에 수아 칩이 보인다.
- [ ] TTS가 아니라 ‘참조’라는 것을 안다.

| 자주 겪는 실패 | 해결 |
| --- | --- |
| 업로드가 안 됨 | MP3·WAV·AAC·OGG인지, 용량이 너무 크지 않은지 확인 |
| 영상의 목소리가 연결한 것과 다름 | 참조 음성을 받는 모델인지 확인, 씬에 등장인물이 연결됐는지 확인 |
| 대사가 다른 인물 목소리로 나옴 | `씬` 탭 대사의 `말하는 인물` 지정(24장) |

**확인 문제** 1) 목소리 파일을 등장인물에 붙이는 버튼(등장인물 상세의 `보이스` 칸)은? 2) V1에서 대사 음성을 실제로 만드는 것은? 3) 올릴 수 있는 파일 형식은?

정답: 1) `보이스 선택` 2) 영상 모델 3) MP3·WAV·AAC·OGG

**응용 과제** — 도윤 역의 목소리를 친구에게 부탁해 녹음하고(동의 받기), 도윤에 연결해 보세요.
