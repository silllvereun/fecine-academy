# 11장 AI 결과물 평가, 안전, 저작권

<ChapterGoals />

::: info 이 장의 예제
이 책은 예제 작품 「비 오는 정류장」을 이어서 만듭니다. 비 오는 밤, 우산 없는 수아에게 처음 보는 도윤이 우산을 건네는 15초짜리 영상(장면 3개)입니다. FECINE을 아직 써 보지 않았다면 화면 따라 하기는 건너뛰고 개념과 표만 읽어도 됩니다.
:::

## WHY — 좋은 결과인지 어떻게 판단하고, 무엇을 조심해야 할까요?

테이크가 여러 개 쌓이면 무엇을 고를지, 무엇을 고쳐 다시 만들지 정해야 합니다. 또 AI로 만든 영상도 실존 인물·저작물을 다루면 법적 책임이 따릅니다. 평가 기준과 안전 기준을 함께 익힙니다.

- 테이크를 네 가지 기준으로 평가한다.
- FECINE의 테이크 피드백으로 다음 수정 방향을 정한다.
- 안전 필터, 실존 인물, 저작권, AI 표기의 기본을 안다.

**완성 결과물** — 테이크 평가표

## HOW — 평가와 안전

### 테이크를 보는 네 가지 기준

| 기준 | 확인할 것 |
| --- | --- |
| 의도 | 기획한 감정·행동이 보이나? 카메라가 지시대로인가? |
| 일관성 | 얼굴·의상·배경이 다른 장면과 같은가? |
| 움직임 | 동작이 자연스러운가? 손·발·물체가 녹거나 튀지 않나? |
| 오류 | 이상한 글자·워터마크, 어색한 소리가 없나? |

### FECINE에서 하기 — 테이크 피드백

스토리보드에서 테이크를 고르면 `이 테이크 어땠나요?`가 나옵니다. `아쉬워요`를 누르고 이유를 고르면, FECINE이 고칠 곳을 알려 주고 해당 탭을 열어 줍니다.

| 이유 | FECINE의 안내 | 열리는 탭 |
| --- | --- | --- |
| `스타일이 다름` | 스타일 탭에서 스타일이나 룩 한 줄만 바꿔 다시 생성 | `스타일` |
| `얼굴·의상이 바뀜` | 캐릭터 참조 이미지 연결, 프롬프트의 얼굴·머리·옷 특징 확인 | `장면` |
| `움직임이 어색함` | 샷 수를 줄이고 샷마다 움직임을 하나만 | `프롬프트` |
| `카메라가 지시와 다름` | 샷마다 시작 → 움직임 → 끝을 정하기 | `카메라` |
| `글자·워터마크` | 프롬프트에 화면 글자가 없는지 확인, 대사는 대사 칸에만 | `프롬프트` |
| `소리` | 모델 탭의 오디오 설정 확인, 대사 없는 장면은 소리 끄기 | `모델` |

::: tip TIP
한 번에 하나만 바꾸세요. 여러 가지를 한꺼번에 바꾸면 무엇 때문에 좋아졌는지 알 수 없습니다. 테이크 정보의 `대비 바뀐 점`(이전 테이크와 비교해 바뀐 설정)이 무엇을 바꿨는지 기록해 줍니다.
:::

### 안전 필터

폭력·선정적 표현이나 실존 인물을 보여 주는 요청은 막힐 수 있습니다. 이때 ‘콘텐츠 안전 필터에 의해 요청이 차단되었습니다. 프롬프트, 대사 또는 참고 이미지를 수정한 후 다시 시도해 주세요.’가 나옵니다. 표현을 완화하거나 참고 이미지를 바꿉니다.

### 실존 인물

실제 사람의 얼굴로 영상을 만들려면 **그 사람 본인의 동의와 인증**이 필요합니다. FECINE에서는 캐릭터 메뉴의 `Seedance 실존 인물 인증`으로 본인이 휴대폰에서 직접 인증합니다. v1.38.0부터는 ‘… VIP’ 모델에서만 쓸 수 있습니다(부록 A). AI로 만든 가상 인물 사진은 본인이 없으므로 인증되지 않습니다.

### 저작권과 AI 표기

- 대본·이미지·음악·목소리 중 남의 것을 쓸 때는 사용 허락을 받습니다. `프리소스` 원작은 `원작 이용 조건`에 동의하고 씁니다.
- 특정 작품·브랜드·캐릭터를 그대로 따라 하는 프롬프트는 피합니다.
- 영상을 공개할 때는 AI로 만든 영상임을 밝힙니다.

FECINE의 `채널` 게시 요청은 권리 보유, 실존 인물 미사용, AI 생성 표시, 게시 동의 네 가지를 확인해야 넣을 수 있습니다. 이 항목은 게시하지 않는 영상에도 좋은 점검표입니다.

1. 대본·이미지·음악·목소리 등 영상의 모든 요소에 대한 권리를 가지고 있거나 사용 허락을 받았습니다.
2. 실존 인물의 얼굴이나 목소리를 본인 동의 없이 쓰지 않았습니다.
3. AI로 만든 영상이며, 채널에 AI 생성 콘텐츠로 표시되는 데 동의합니다.
4. (게시 요청 시) FECINE 공식 채널 게시와 수익 배분 정책에 동의합니다.

| 자주 겪는 실패 | 해결 |
| --- | --- |
| 요청이 안전 필터에 막힘 | 표현을 완화하고 참고 이미지를 바꾼 뒤 재시도. 캐릭터 시트는 다른 모델로 |
| 가상 인물 사진으로 실존 인물 인증 시도 | 인증은 실제 본인만 가능. 가상 인물은 인증 없이 사용 |
