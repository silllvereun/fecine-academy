# 16장 새 작품과 작품 설정

<ChapterGoals />

## WHY — 작품을 만들 때 무엇을 먼저 정해야 할까요?

화면 비율과 해상도는 작품 전체에 고정됩니다. 중간에 바꾸면 이미 만든 장면과 새 장면의 비율이 달라져 다시 만들어야 합니다. 그래서 첫 장면을 만들기 전에 정해 둡니다.

- 새 작품을 만드는 세 가지 방법(새 작품·템플릿·프리소스)을 안다.
- 작품명을 바꾸고 작품 설정을 정한다.
- 「비 오는 정류장」 작품을 만든다.

**완성 결과물** — 「비 오는 정류장」 작품(16:9 · 720p · 실사 · 시네마틱 · 영화)

## HOW — 화면 따라 하기

### 1. 새 작품 만들기

1. 상단 `새 작품`을 누릅니다. (작품이 하나도 없으면 가운데 `새 작품 시작`도 같습니다.)
2. 입력창 없이 ‘새 작품’이라는 작품이 만들어지고 `작품정보` 화면이 열립니다.
3. ① 작품명 ‘새 작품’을 **더블클릭**하고 ‘비 오는 정류장’을 입력한 뒤 Enter를 누릅니다.

::: info NOTE
`새 작품`을 눌렀는데 이름을 묻는 창이 뜨지 않는 것은 정상입니다. 같은 이름이 있으면 ‘새 작품 2’처럼 번호가 붙습니다.
:::

### 2. 작품 설정

1. ③ `설정 변경`을 누르면 오른쪽에 `작품 설정` 서랍이 열립니다.
2. `화면 비율`을 `16:9`로 바꿉니다. (기본값은 세로 `9:16`)
3. `해상도`는 `720p` 그대로 둡니다.
4. `스타일`을 `실사 · 시네마틱`으로 바꿉니다.
5. `형식`을 `영화`로 바꿉니다.
6. `작품 설명`에 한 줄을 적습니다. 예) 비 오는 밤, 낯선 사람이 우산을 건네는 15초 단편.
7. 바꾼 값은 바로 저장되며 `저장됨`이 보입니다. ‘바꾸면 이후 생성부터 적용돼요.’라는 안내에 주의합니다.

### 3. 다른 시작 방법

| 방법 | 순서 | 언제 |
| --- | --- | --- |
| 템플릿 | 사이드 `템플릿` → `기본 제공`(세로형 숏드라마, 3막 단편 영화, 30초 제품 광고, 뮤직비디오, 애니메이션 단편) → `템플릿 사용` | 형식이 정해진 작품(예: 실습 2의 제품 광고) |
| 프리소스 | 사이드 `프리소스` → 원작 선택 → `원문 읽기` → `원작 이용 조건` 동의 → `이 원작으로 작품 만들기` | 공개 원작을 영상으로(예: 실습 3) |
| 내 템플릿 | 작품 카드 ⋯ → `템플릿으로 저장` → 다음에 `템플릿`에서 사용 | 같은 설정으로 여러 편 만들 때 |

## PRACTICE — 「비 오는 정류장」 만들기

아래 설정값을 그대로 입력합니다.

| 항목 | 값 |
| --- | --- |
| 작품명 | 비 오는 정류장 |
| `화면 비율` | 16:9 |
| `해상도` | 720p |
| `스타일` | 실사 · 시네마틱 |
| `형식` | 영화 |
| `작품 설명` | 비 오는 밤, 낯선 사람이 우산을 건네는 15초 단편. |
| `작품 개요` > `직접 입력` | 작품을 한 문장으로 요약한 글(로그라인)과 짧은 줄거리 → `개요 저장` |

::: cost COST · 비용
작품을 만들고 설정하는 것은 무료입니다. 프리소스 원작으로 시작하면 ‘구성 비용’이 표시되며 크레딧이 듭니다.
:::

## REVIEW — 제대로 했나요?

- [ ] 작품명을 더블클릭해 바꿨다.
- [ ] `설정 변경`에서 네 가지 설정을 정했다.
- [ ] 작품정보의 설정 칩에 16:9 · 720p · 실사 · 시네마틱 · 영화가 보인다.

| 자주 겪는 실패 | 해결 |
| --- | --- |
| 작품명을 한 번 클릭하고 수정이 안 된다고 함 | **더블클릭** |
| 영상을 만든 뒤에 비율을 바꿈 | 이후 생성부터 적용됨. 이전 장면은 다시 생성 |
| 작품이 목록에서 사라짐 | `보관` 필터 확인, 지웠다면 `설정` > `휴지통`에서 `복원`(30일) |
| 저장이 안 됨 | ‘저장하지 못했어요. 다시 시도해 주세요.’ → 잠시 후 다시 선택 |

**확인 문제** 1) 새 작품의 기본 화면 비율은? 2) 작품 설정 서랍을 여는 버튼은? 3) 형식이 정해진 작품을 빠르게 시작하는 메뉴는?

정답: 1) 9:16 2) `설정 변경` 3) `템플릿`

**응용 과제** — 템플릿 `세로형 숏드라마`로 작품을 하나 더 만들고, 「비 오는 정류장」과 설정이 어떻게 다른지 비교해 보세요.
