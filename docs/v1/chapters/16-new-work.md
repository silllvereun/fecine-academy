# 16장 새 작품과 작품 설정

<ChapterGoals />

## WHY — 작품을 만들 때 무엇을 먼저 정해야 할까요?

화면 비율과 해상도는 작품 전체에 고정됩니다. 중간에 바꾸면 이미 만든 씬과 새 씬의 비율이 달라져 다시 만들어야 합니다. 그래서 첫 씬을 만들기 전에 정해 둡니다.

- 새 작품을 만드는 세 가지 방법(새 작품·템플릿·프리소스)을 안다.
- 작품명을 바꾸고 작품 설정을 정한다.
- 「비 오는 정류장」 작품을 만든다.

**완성 결과물** — 「비 오는 정류장」 작품(16:9 · 720p · 실사 · 시네마틱 · 영화)

## HOW — 화면 따라 하기

### 1. 새 작품 만들기

1. 작품 목록 상단의 `새 작품`을 누릅니다. (작품이 하나도 없으면 가운데 `새 작품 시작`도 같습니다.)
2. 입력창 없이 ‘새 작품’이라는 작품이 만들어지고 `작품정보` 화면이 열립니다. 오른쪽에는 `작품 설정` 패널이 바로 열려 있어, 첫 영상을 만들기 전에 비율과 스타일부터 확인할 수 있습니다(아래 2번).
3. ① 작품명 ‘새 작품’을 **더블클릭**하고 ‘비 오는 정류장’을 입력한 뒤 Enter를 누릅니다.

**[캡처 06-01]** `새 작품` 직후의 작품정보 — ① 작품명 ② 다음 단계 ③ 설정 변경 ④ 제작 현황 (지금은 `작품 설정` 패널이 함께 열립니다)

![캡처 06-01](/images/v1/captures/cap-06-01.png)

::: info NOTE
`새 작품`을 눌렀는데 이름을 묻는 창이 뜨지 않는 것은 정상입니다. 같은 이름이 있으면 ‘새 작품 2’처럼 번호가 붙습니다.
:::

### 2. 작품 설정

1. 새 작품을 만든 직후에는 `작품 설정` 패널이 이미 열려 있습니다. 닫았거나 나중에 다시 열 때는 ③ `설정 변경`을 누릅니다. 다른 화면으로 이동하면 패널은 닫힙니다.
2. `화면 비율`을 `16:9`로 바꿉니다. (기본값은 세로 `9:16`) 선택 목록에는 숫자와 함께 비율의 모양이 보입니다.
3. `해상도`는 `720p` 그대로 둡니다.
4. `스타일`을 `실사 · 시네마틱`으로 바꿉니다.
5. `형식`을 `영화`로 바꿉니다.
6. `작품 설명`에 한 줄을 적습니다. 예) 비 오는 밤, 낯선 사람이 우산을 건네는 15초 단편.
7. 바꾼 값은 바로 저장되며 `저장됨`이 보입니다. 비율과 해상도는 작품 전체에 고정되므로, 영상을 만든 뒤에 바꾸면 이미 만든 씬과 어긋납니다.

**[캡처 06-03]** 스타일 목록(실사·2D·3D·CG·공필화·커스텀 16종)

![캡처 06-03](/images/v1/captures/cap-06-03.png)

패널은 `기본` · `멤버` · `상태` 탭으로 나뉩니다. (스튜디오 소유자가 아니면 `기본` 탭만 보입니다.)

| 탭 | 있는 것 |
| --- | --- |
| `기본` | 위의 네 가지 설정, `작품 설명`, `태그`, `대표 이미지`(고르기 전까지는 처음 만든 영상이 대표 이미지) |
| `멤버` | 이 작품을 보고 편집할 수 있는 워크스페이스 멤버를 고릅니다. 스튜디오에 없는 사람은 `스튜디오 멤버` 메뉴에서 먼저 초대합니다 |
| `상태` | `작품 상태`를 `제작 중`과 `보관됨` 사이에서 바꿉니다(`보관`·`다시 열기`). 스튜디오 관리자에게는 `삭제`(`휴지통으로 이동`)도 보입니다 |

예전의 `고급` 접이식은 없어졌고, 크루라는 이름은 `멤버`로 바뀌었습니다.

### 3. 작품 위키 (선택)

`작품정보` 화면 위에는 `작품정보`와 `작품 위키` 두 탭이 있습니다. `작품 위키`는 작품 개요, 등장인물, 장소 · 세계관, 소품, 용어집, 프롬프트 규칙, 연속성 메모처럼 **모든 씬에서 같아야 하는 기준**을 모아 두는 문서입니다. FECINE의 AI 요청은 이 위키를 먼저 읽고 따릅니다.

- 처음에는 비어 있습니다. `기존 정보 가져오기`를 누르면 작품 개요와 등장인물·장소·소품 설명을 위키로 옮깁니다(AI를 쓰지 않음). `항목 추가`로 직접 써도 됩니다.
- 사람이 쓰거나 고친 항목은 `직접 고침 · 잠김`이 되어, AI는 제안만 하고 바꾸지 않습니다.
- 지금은 탭 위치만 알아 두고, 등장인물과 씬이 생긴 뒤에 채워도 됩니다.

### 4. 다른 시작 방법

| 방법 | 순서 | 언제 |
| --- | --- | --- |
| 템플릿 | 사이드 공개 메뉴의 `템플릿` → `기본 제공`(세로형 숏드라마, 3막 단편 영화, 30초 제품 광고, 뮤직비디오, 애니메이션 단편) → `템플릿 사용` | 형식이 정해진 작품(예: 실습 2의 제품 광고) |
| 프리소스 | 사이드 메뉴의 `프리소스` → 원작 선택 → `원작 읽기`·`원작 이용 조건` 확인 → 동의 체크 → `이 원작으로 작품 만들기` | 공개 원작을 영상으로(실습 4). 원작이 작품의 `원문`에 들어가고, AI 생성은 내가 요청할 때만 시작됩니다. 새 스튜디오의 `환영해요` 카드(첫 영상 튜토리얼)도 프리소스 원작을 씁니다(15장) |

::: info NOTE
템플릿은 기본 제공 5개만 있습니다. 내 작품을 템플릿으로 저장하는 기능은 없습니다.
:::

## PRACTICE — 「비 오는 정류장」 만들기

아래 설정값을 그대로 입력합니다.

| 항목 | 값 |
| --- | --- |
| 작품명 | 비 오는 정류장 |
| `화면 비율` | 16:9 |
| `해상도` | 720p |
| `스타일` | 실사 · 시네마틱 |
| `형식` | 영화 |
| `작품 설명` | 비 오는 밤, 낯선 사람이 우산을 건네는 15초 단편. |
| `작품 개요` > `직접 입력` | 작품을 한 문장으로 요약한 글(로그라인)과 짧은 줄거리 → `개요 저장` |

::: cost COST · 비용
작품을 만들고 설정하는 것은 무료입니다. 프리소스 원작으로 작품을 만드는 것도 무료입니다. 이후 AI 자동생성(에피소드·씬 추출 등)을 직접 요청할 때 사용한 만큼 크레딧이 들고, 첫 영상 튜토리얼의 작품 구성에는 `구성 비용`이 표시됩니다(실습 4).
:::

## REVIEW — 제대로 했나요?

- [ ] 작품명을 더블클릭해 바꿨다.
- [ ] `작품 설정` 패널에서 네 가지 설정을 정했다.
- [ ] 작품정보의 설정 칩에 16:9 · 720p · 실사 · 시네마틱 · 영화가 보인다.
- [ ] `작품 위키` 탭의 위치를 안다.

| 자주 겪는 실패 | 해결 |
| --- | --- |
| 작품명을 한 번 클릭하고 수정이 안 된다고 함 | **더블클릭** |
| 영상을 만든 뒤에 비율을 바꿈 | 새로 만드는 영상부터 새 비율. 이전 씬은 다시 생성 |
| 새 작품이 만들어지지 않음 | 워크스페이스의 작품 생성 한도에 도달했어요. → 기존 작품에서 이어 하거나 관리자에게 한도 변경 요청 (새 스튜디오는 튜토리얼 포함 작품 1개로 시작할 수 있음, 15장) |
| 작품이 목록에서 사라짐 | `보관` 필터 확인, 지웠다면 `설정` > `휴지통`에서 `복원`(30일) |
| 저장이 안 됨 | ‘저장하지 못했어요. 다시 시도해 주세요.’ → 잠시 후 다시 선택 |
| 내 작품을 템플릿으로 저장하려 함 | 지원하지 않음. 같은 설정이 필요하면 새 작품에서 설정을 다시 고르기 |

**확인 문제** 1) 새 작품의 기본 화면 비율은? 2) 작품 설정 패널을 다시 여는 버튼은? 3) 형식이 정해진 작품을 빠르게 시작하는 메뉴는?

정답: 1) 9:16 2) `설정 변경` 3) `템플릿`

**응용 과제** — 템플릿 `세로형 숏드라마`로 작품을 하나 더 만들고, 「비 오는 정류장」과 설정이 어떻게 다른지 비교해 보세요.
