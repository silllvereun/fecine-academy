# 21장 배경과 소품 만들기

<ChapterGoals />

## WHY — 장소와 물건도 고정해야 할까요?

씬 1의 정류장과 씬 3의 정류장이 다르게 생기면 관객은 장소가 바뀐 줄 알고 헷갈립니다. 도윤의 검은 우산도 씬마다 색이 달라지면 어색합니다. 배경과 소품도 등장인물처럼 이미지로 고정합니다.

- `공간·배경`·`미술·소품`·`콘티` 메뉴의 차이를 안다.
- 배경·소품 이미지를 만든다.
- `라이브러리`에서 이미지를 모아 두고 다시 쓴다.

**완성 결과물** — 배경 ‘비 오는 버스 정류장’, 소품 ‘검은 우산’ (결과 21-A)

## HOW — 디자인의 종류

작품 왼쪽 `제작 모듈` 메뉴에서 제작설계 단계의 메뉴가 각각 따로 있습니다.

| 메뉴 | 무엇을 만드나 | 예제 |
| --- | --- | --- |
| `등장인물` | 인물(20장) | 수아, 도윤 |
| `공간·배경` | 장소. 인물 없이(`배경`) | 비 오는 버스 정류장 |
| `미술·소품` | 중요한 물건·의상·오브젝트(`소품`) | 검은 우산 |
| `콘티` › `콘티` 탭 | 여러 칸으로 된 참고 시트(구도·흐름 참고) | 씬 2의 동작 흐름 |
| `콘티` › `참고 영상` 탭 | 참고용 짧은 영상 | 빗방울이 떨어지는 움직임 |

::: tip TIP
배경 프롬프트에는 사람을 넣지 않습니다. 배경 이미지에 사람이 있으면 영상에서 모르는 사람이 나타나기 쉽습니다.
:::

### FECINE에서 하기

1. `제작 모듈` 메뉴에서 `공간·배경`을 누르고 `새 배경`을 누릅니다.
2. `생성`을 고르고 `이름`을 ‘비_오는_버스_정류장’처럼 적습니다(공백은 _로).
3. `프롬프트`를 적고 `모델`·`수량`을 정한 뒤 `확인`을 누릅니다. 배경은 작품 비율(16:9)과 같은 가로 비율이 좋습니다.
4. `미술·소품` 메뉴에서 `새 소품`으로 같은 과정을 반복합니다.

::: tip TIP
`콘티` 카드에는 그 시트를 쓰는 씬이 `쓰인 씬`으로 표시됩니다. 시트의 칸 하나만 마음에 들지 않으면, 상세 정보의 `칸 구성`에서 그 칸만 다시 만들고 `시트에 적용`할 수 있습니다.
:::

### 라이브러리 활용

사이드 작업 메뉴의 `라이브러리`는 스튜디오의 모든 이미지·영상·오디오를 모아 보여 줍니다. 범위는 `나만 보기`·`팀 공유`·`작품`으로 나뉘며, `업로드`·`일괄 업로드`·`생성`을 할 수 있습니다. 만들어 둔 이미지는 `새 배경`·`새 소품` 창에서 `라이브러리에서`로 불러옵니다.

## PRACTICE — 배경과 소품

```text
[배경] 비_오는_버스_정류장
밤, 비 내리는 도시의 버스 정류장. 유리 가림막과 벤치, 노선 안내판.
빗물에 젖은 아스팔트에 가로등과 간판 불빛이 반사된다. 사람 없음.
와이드, 눈높이, 차분한 푸른 밤빛, 실사.

[소품] 검은_우산
펼쳐진 큰 검은 장우산. 나무 손잡이, 무늬 없는 무광 천.
단색 회색 배경, 부드러운 조명, 제품 사진처럼.
```

이미지 한 장마다 크레딧이 듭니다. 작은 소품까지 모두 만들 필요는 없고, 이야기에 중요하거나 여러 씬에 나오는 것만 만듭니다.
:::

## REVIEW — 제대로 했나요?

- [ ] `공간·배경`·`미술·소품` 메뉴에 각각 이미지가 하나씩 있다.
- [ ] 배경 이미지에 사람이 없다.
- [ ] `라이브러리`의 세 범위를 안다.

| 자주 겪는 실패 | 해결 |
| --- | --- |
| 배경에 사람이 나옴 | 프롬프트에 ‘사람 없음’, 인물 묘사 빼기 |
| 업로드가 건너뛰어짐 | 이미지와 zip만 가능. PNG·JPG·WebP·AVIF 사용 |
| 이름으로 @참조가 안 됨 | 공백 대신 _를 쓴 이름으로 @ 입력 |

**확인 문제** 1) 씬의 동작 흐름을 여러 칸으로 참고하는 디자인은? 2) 팀원과 함께 보는 라이브러리 범위는? 3) 배경 프롬프트에서 빼야 할 것은?

정답: 1) `콘티` 2) `팀 공유` 3) 사람

**응용 과제** — 같은 정류장을 ‘비가 그친 새벽’ 버전으로 만들고, 두 배경을 나란히 놓고 분위기를 비교해 보세요.
