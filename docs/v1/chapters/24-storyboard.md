# 24장 스토리보드에서 씬 구성하기

<ChapterGoals />

## WHY — 영상을 만들기 전 씬에 무엇을 채워야 할까요?

스토리보드의 씬은 ‘생성 지시서’입니다(7장). 씬 설명, 대사, 등장 요소가 비어 있으면 AI가 임의로 채웁니다. 이 장에서는 영상을 만들기 전 마지막 점검으로 `등장 요소` 탭과 대사를 채웁니다.

- 스토리보드 화면의 구역을 안다.
- `등장 요소` 탭에서 등장인물·배경·소품을 연결하고, `프롬프트` 탭에서 대사를 채운다.
- 씬을 추가·복제·삭제하고 에피소드를 관리한다.

**완성 결과물** — 등장 요소가 모두 연결된 씬 3개

## HOW — 화면 따라 하기

### 스토리보드 화면의 구역

작품 왼쪽 `제작 모듈` 메뉴에서 `스토리보드`를 누르면 이 화면이 열립니다. 메뉴에서는 `샷 이미지`(26장)가 스토리보드 바로 위에 있지만, 씬 내용을 먼저 채워 두면 샷 이미지도 더 잘 나옵니다. 에피소드는 화면 위쪽 띠의 `에피소드 고르기` 메뉴에서 고릅니다(`스토리`·`샷 이미지`와 같은 메뉴입니다).

| 위치 | 내용 |
| --- | --- |
| ① 왼쪽 | `씬 {n}개`와 전체 길이, `영상 프롬프트 만들기 · 빈 씬 {n}개`, 씬 목록(씬마다 `초안`·`생성 중`·`실패`·`완료`), 아래 `새 씬` |
| ② 가운데 | `S#n` 씬 번호·제목과 상태, 위쪽 `씬 복제`·`씬 삭제`·`이전 씬`·`다음 씬`, 영상 테이크(미리보기) |
| ③ 오른쪽 | `등장 요소`·`스토리`·`프롬프트`·`카메라`·`스타일`·`모델` 탭 |
| ④ 오른쪽 아래 | 고른 모델과 `생성`(옆에 예상 크레딧) 버튼(27장) |

화면이 좁으면 왼쪽 씬 목록과 오른쪽 탭이 서랍으로 접힙니다. 위쪽 띠의 씬 목록·`인스펙터` 버튼으로 엽니다.

**[캡처 15-01]** 스토리보드 — ① 씬 목록 ② 미리보기 ③ 탭 ④ `생성`

### 등장 요소와 대사 채우기

1. 왼쪽 목록에서 `S#1`을 고릅니다.
2. `스토리` 탭을 엽니다. 17장에서 쓴 `씬 요약`·`씬 대본`·`연출 노트`와 `샷 나누기`가 그대로 보이고, 여기서 바로 고칠 수도 있습니다(스토리 편집과 같은 글입니다). 연출 의도를 `연출 노트`에 한 줄 더합니다.
3. `프롬프트` 탭의 `대사 / 내레이션`에서 종류(`대사`·`내레이션`·`가사`)를 고르고 `추가`를 누릅니다. 대사를 적고 `말하는 인물`을 고릅니다. `시작 시각`은 비워 두면 자동입니다.
4. `등장 요소` 탭에서 `등장인물`의 `추가`를 눌러 수아를 넣습니다. 의상이 여럿이면 `변형 선택`으로 고릅니다.
5. 같은 탭의 `배경`에 ‘비_오는_버스_정류장’, 필요하면 `소품`·`콘티`도 `추가`합니다. 이미지가 아직 없는 항목에는 `참조 이미지 생성 →`이 보입니다.
6. 씬 2·3도 같은 방법으로 채웁니다.

::: tip TIP
`스토리`·`샷 이미지`·`스토리보드`의 `등장 요소`는 같은 연결입니다. 스토리 편집에서 붙인 등장인물·공간·소품은 여기서도 연결된 상태로 보이고, AI 어시스턴트의 `등장 요소 만들기`로 만든 항목도 씬에 연결돼 있습니다. 영상 프롬프트에서 `@수아`처럼 불러야 영상 생성에 쓰이는 항목에는 ‘프롬프트에 @이름 언급이 없어 영상 생성에 쓰이지 않아요.’가 표시됩니다(25장).
:::

::: info NOTE
`프롬프트` 탭 위쪽의 ‘샷 이미지가 아직 없어요.’와 `샷 이미지 열기`는 26장에서 다룹니다. 샷 이미지 없이도 영상은 만들 수 있고, 이때는 연결한 등장 요소가 참조로 쓰입니다(10장). @로 부른 항목에 이미지가 없으면 ‘일부 @ 참조에 아직 이미지가 없어요’ 안내가 뜨고 영상 생성이 멈춥니다. 각 이름을 눌러 이미지를 먼저 만드세요.
:::

### 씬·에피소드 관리

- `새 씬`: 에피소드 끝에 빈 씬 추가
- `씬 복제`: 설정을 그대로 복사(비슷한 씬을 만들 때 편리)
- `씬 삭제`: 지운 씬은 테이크·샷 이미지와 함께 휴지통으로 가고, 7일 안에 작품정보의 휴지통에서 복구할 수 있습니다
- 위쪽 띠 `에피소드 고르기` 메뉴 → `에피소드 추가`, `에피소드 삭제`. 제목과 한 줄 줄거리는 ⓘ 개요 패널에서 고칩니다

씬을 합치거나 나누거나 다른 에피소드로 옮기는 일은 `스토리`에서 합니다(17장). 스토리보드는 그 구조를 따라오고, 구성이 바뀐 씬에는 `수정됨`이 붙습니다. 이런 씬은 25장의 방법으로 영상 프롬프트를 다시 만듭니다.

## REVIEW — 제대로 했나요?

- [ ] 씬 3개 모두 등장인물·배경이 연결됐다.
- [ ] 대사마다 `말하는 인물`이 있다.
- [ ] `씬 복제`·`씬 삭제`의 위치를 안다.

**확인 문제** 1) 대사의 종류 세 가지는? 2) 씬에 등장인물을 연결하는 곳은? 3) 지운 씬은 얼마나 보관되나요?

정답: 1) `대사`·`내레이션`·`가사` 2) `등장 요소` 탭(스토리·샷 이미지의 `등장 요소`와 같은 연결) 3) 7일(작품정보의 휴지통)

**응용 과제** — 씬 1을 `씬 복제`해 ‘비가 더 거세진 버전’을 만들고, 연출 의도만 바꿔 보세요.
