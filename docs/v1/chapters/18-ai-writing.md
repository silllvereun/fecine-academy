# 18장 AI로 씬 대본 쓰고 다듬기

<ChapterGoals />

## WHY — AI에게 글을 맡길 때 무엇을 확인해야 할까요?

텍스트 AI는 씬을 나누고 대사를 다듬는 일을 잘합니다. 하지만 작품의 방향을 아는 것은 여러분입니다. FECINE의 AI 요청은 두 종류입니다.

- **제안만 받는 요청**: `씬 요약`·`씬 대본`·`연출 노트`. AI는 글을 답변 카드로 보여 줄 뿐이고, 작품은 그대로입니다. 마음에 들 때 `복사`해서 직접 붙여 넣습니다.
- **작품에 바로 넣는 요청**: `씬 추가`·`등장 요소 만들기`·`촬영 설계 만들기`. 시작하면 결과가 작품에 저장됩니다. 그래서 시작하기 전에 무엇을 읽고 무엇을 만들지 고르고, 끝난 뒤에는 결과를 확인합니다.

- AI 어시스턴트의 `씬 추가` 요청으로 새 씬을 만든다.
- `대본 쓰기`·`대본 다듬기`로 받은 제안을 읽고, 마음에 들 때만 복사해 넣는다.
- 씬 하나를 AI로 나눈다.

**완성 결과물** — 씬 2 씬 대본의 다듬기 전후 비교표 (결과 18-A)

## HOW — 화면 따라 하기

`스토리` › `스토리 편집` 화면 오른쪽에는 `AI 어시스턴트`가 열려 있습니다(닫았다면 `AI 어시스턴트 열기`). 지금 보는 씬이 ‘EP.01 · S#2 건네진 우산’ 같은 칩으로 맥락에 들어가고, 아래에는 요청 단추들이 있습니다.

| 어시스턴트 아래쪽 | 하는 일 |
| --- | --- |
| `씬 추가` · `등장 요소 만들기` · `촬영 설계 만들기` | 작품에 바로 넣는 요청. 눌러서 질문에 하나씩 답합니다 |
| `씬 요약` · `씬 대본` · `연출 노트` | 제안만 받는 요청. 요청 문장이 입력칸에 채워집니다 |
| 입력칸과 `보내기` | 하고 싶은 일을 적어 보냅니다(Ctrl+Enter도 됩니다) |
| 맨 아래 모델 선택 | 쓸 텍스트 모델. 쓸 수 있는 모델을 모두 고를 수 있습니다 |

::: info NOTE
FECINE의 AI 요청은 `작품 위키`(16장)를 먼저 읽습니다. 위키의 등장인물 설명이나 `프롬프트 규칙`을 채워 두면 AI가 쓴 글도 그 기준을 따릅니다.
:::

### 1. AI로 새 씬 추가하기 (`씬 추가`)

씬 이야기만 말로 설명하면 AI가 제목·요약·대본·연출 노트까지 한 씬을 써서 넣습니다.

1. 어시스턴트의 `씬 추가`를 누릅니다. (씬이 하나도 없을 때 가운데에 보이는 ✦ `씬 추가` 버튼도 같은 요청입니다.)
2. ‘어떤 씬을 추가할까요?’에 이야기를 적습니다. 예) 민지가 트럭에서 내려 물류센터 앞에서 준호의 전화를 엿듣는 씬 → `다음`
3. ‘어디에 넣을까요?’에서 `지금 보는 S#n 다음`, `맨 뒤`, `몇 번째 씬으로` 중 고릅니다. 중간에 넣으면 ‘뒤 씬 번호는 하나씩 밀립니다.’
4. ‘이 씬과 함께 무엇을 만들까요?’에서 고릅니다. 제목·요약·대본·연출 노트는 항상 만들고, 선택으로 `등장인물`·`공간·배경`·`미술·소품`(이미 있는 등장 요소는 연결하고 없는 것만 설정을 만들며, 이미지는 만들지 않습니다)과 `샷 나누기`를 켤 수 있습니다. `다음`
5. 읽는 내용(현재 에피소드, 각 씬 내용, 작품 위키, 요청 사항)을 확인하고 `씬 추가 시작`을 누릅니다. 버튼 옆에 예상 크레딧이 보입니다.

시작하면 가운데에 ‘새 씬을 쓰고 있어요’(읽기 → 씬 쓰기 → 작품에 저장)가 보이고, 왼쪽 목록에는 점선 칸 ‘새 씬 추가 중’이 생깁니다. 다른 화면으로 가도 계속되고, 끝나면 새 씬이 바로 열립니다. 진행 중에는 **그 에피소드의 씬 글과 순서만 잠기고** 이미지·영상 생성은 계속할 수 있습니다. 작업은 `진행 상황` 탭에도 요청별 카드로 쌓입니다(19장).

### 2. 씬 대본 쓰기·다듬기 (제안 받기)

1. 왼쪽 목록에서 씬을 고릅니다. 씬 대본이 비어 있으면 `씬 대본` 카드의 `대본 쓰기`, 이미 있으면 `대본 다듬기`를 누릅니다. (어시스턴트의 `씬 대본` 단추와 같습니다.) 요약은 `요약 만들기`, 연출 노트는 `초안 쓰기`가 같은 방식입니다.
2. 입력칸에 ‘이 씬의 대본(지문과 대사)을 써 주세요. 요청: ’이 채워집니다. 뒤에 원하는 방향을 이어서 적습니다. 예) 도윤의 대사를 더 짧고 자연스럽게
3. 모델을 확인하고 `보내기`를 누릅니다.
4. 답변에 ‘씬 대본’ 같은 제목의 카드가 한 장 나옵니다. 지금 씬 대본과 나란히 비교해 읽습니다.
5. 마음에 들면 카드의 `복사`를 누르고, 가운데 `씬 대본` 칸을 클릭해 붙여 넣습니다(바로 자동 저장됩니다). 마음에 들지 않으면 아무것도 하지 않으면 됩니다. 작품은 바뀌지 않습니다.

::: warning 주의
어시스턴트는 제안만 합니다. 붙여 넣기 전에는 씬이 바뀌지 않지만, 붙여 넣으면 그 글이 바로 저장됩니다. 붙이기 전에 지금 씬 대본을 다른 곳에 복사해 두면 안전합니다.
:::

### 3. 씬 하나를 AI로 나누기

씬 하나가 너무 길 때는 AI에게 나눌 곳을 제안받을 수 있습니다.

1. 씬 이름 줄의 ✂ 버튼(`S#n 나누기`)을 누르고 `나누는 방법`에서 `AI로 나누기`를 고릅니다.
2. `나눌 수`를 고르고, 필요하면 `바라는 점 (선택)`을 적습니다. 예) 대사 앞뒤로 나눠 주세요
3. `나누기 제안 받기`를 누릅니다. 제안을 적용하기 전에는 아무것도 바뀌지 않습니다.
4. 마음에 들면 `이대로 {count}개로 나누기`, 아니면 `다시 제안받기`를 누릅니다.

### 4. 그 밖의 요청

- `등장 요소 만들기`: 고른 씬(지금 씬 또는 에피소드 전체)에 필요한 등장인물·공간·소품을 만들어 씬에 연결하고, 이미지 프롬프트까지 저장합니다(이미지는 만들지 않음). 20–21장에서 이미지를 만듭니다.
- `촬영 설계 만들기`: 씬 대본을 샷으로 나누고 샷마다 영상 프롬프트를 씬에 저장합니다(씬 대본이 있는 씬만). 이미 샷이 있는 씬은 `있는 샷은 그대로 두기`와 `이미 있는 것도 다시 만들기` 중 고릅니다. 25장에서 이어집니다. 콘티 시트는 `작품 자료`에서 만듭니다.
- 어시스턴트에 자유롭게 질문할 수도 있습니다. ‘무엇을 도와드릴까요? 예: 이 씬 영상 프롬프트를 더 역동적으로’처럼 적고 `보내기`를 누릅니다. 영상 프롬프트 제안만 `적용`할 수 있고, 나머지 글은 `복사`합니다.

::: info NOTE
패널 아래에 ‘사용할 수 있는 텍스트 모델이 없어요’가 보이면 워크스페이스에 텍스트 모델이 열려 있지 않은 것입니다. 팀 스튜디오라면 소유자나 관리자에게, 혼자 쓰는 스튜디오라면 도움말로 문의합니다.
:::

## PRACTICE — 씬 2 다듬기

1. 왼쪽 목록에서 `S#2`를 고르고 `씬 대본` 카드의 `대본 다듬기`를 누릅니다.
2. 입력칸의 ‘요청: ’ 뒤에 아래를 이어 적고 `보내기`를 누릅니다.

```text
도윤의 대사를 더 짧고 자연스럽게. 처음 보는 사이니 존댓말을 유지하고, 너무 다정하지 않게.
```

3. 답변 카드를 지금 씬 대본과 나란히 놓고 아래 표를 채운 뒤 붙여 넣을지 정합니다.

| 확인 | 지금 씬 대본 | 새 씬 대본 |
| --- | --- | --- |
| 도윤 대사 길이 |  |  |
| 존댓말 유지 |  |  |
| 씬 1·3과 어울림 |  |  |
| 결정 |  | `복사` 후 붙여 넣기 / 버리기 |

::: cost COST · 비용
`씬 추가`·`등장 요소 만들기`·`촬영 설계 만들기`·`AI로 나누기`와 어시스턴트 질문은 텍스트 AI 사용량만큼 크레딧이 듭니다. 시작 버튼 옆의 예상 크레딧을 확인하세요. 영상·이미지보다는 적게 듭니다.
:::

## REVIEW — 제대로 했나요?

- [ ] 답변 카드를 읽고 붙여 넣을지 스스로 정했다.
- [ ] 제안만 받는 요청과 작품에 바로 넣는 요청의 차이를 안다.
- [ ] `씬 추가`가 진행 중이면 그 에피소드의 씬 글과 순서를 고칠 수 없다는 것을 안다.

| 자주 겪는 실패 | 화면 문구 | 해결 |
| --- | --- | --- |
| 보내기가 안 됨 | 이전 질문에 답하는 중이에요. 잠시 후 다시 보내 주세요. | 답이 올 때까지 기다린 뒤 다시 |
| 답변이 오지 않음 | 답변을 만들지 못했어요. 다시 보내 주세요. | 다시 보내기, 다른 모델 고르기 |
| 크레딧 부족 | 크레딧이 부족해요. 충전한 뒤 다시 보내 주세요. | 충전 |
| 씬 추가가 끝나지 않음 | 작업을 끝내지 못했어요. 작품에는 아무것도 들어가지 않았어요 | 작품은 그대로입니다. 요청을 줄여 다시 시작 |
| 다른 작업 중 | 다른 작업이 끝난 뒤에 다시 시도해 주세요 | `진행 상황` 탭에서 끝난 뒤 다시 |
| AI로 나누기 결과가 이상함 | AI 답변을 씬으로 읽지 못했어요. 다시 제안받아 보세요. | `다시 제안받기` |

**확인 문제** 1) 어시스턴트가 쓴 씬 대본을 내 씬에 넣는 방법은? 2) 새 씬을 AI가 써서 작품에 바로 넣는 요청은? 3) `씬 추가`가 진행되는 동안 잠기는 것은?

정답: 1) 답변 카드의 `복사` 후 `씬 대본` 칸에 붙여 넣기 2) `씬 추가` 3) 그 에피소드의 씬 글과 순서(이미지·영상 생성은 계속 가능)

**응용 과제** — 씬 1에서 `연출 노트`의 `초안 쓰기`를 눌러 ‘차가운 가로등 빛’이 드러나는 연출 노트를 받아 보고, 첫 문장이 어떻게 달라졌는지 비교해 보세요.
