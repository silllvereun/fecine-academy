# 18장 AI로 원고 쓰고 다듬기

<ChapterGoals />

## WHY — AI에게 글을 맡길 때 무엇을 확인해야 할까요?

텍스트 AI는 장면을 나누고 대사를 다듬는 일을 잘합니다. 하지만 작품의 방향을 아는 것은 여러분입니다. FECINE은 AI가 쓴 글을 바로 덮어쓰지 않고, **비교한 뒤 적용**하게 되어 있습니다.

- AI로 장면을 나누고 고른 장면만 추가한다.
- AI로 원고를 쓰고 다듬은 뒤 비교해 적용하거나 되돌린다.
- `AI 어시스턴트`에게 제안을 받는다.

**완성 결과물** — 장면 2 원고의 다듬기 전후 비교표 (결과 18-A)

## HOW — 화면 따라 하기

`스토리` 화면 오른쪽에는 AI 패널이 있고, 패널은 `요청`·`모델`·`결과` 탭으로 나뉩니다. 패널 아래에는 지금 요청할 장면·요청 내용·모델이 요약됩니다.

### 1. AI로 장면 나누기

회차 줄거리만 있고 장면이 없을 때 씁니다.

1. 회차의 한 줄 줄거리를 먼저 적습니다.
2. `AI로 장면 나누기`를 누릅니다 <Badge type="warning" text="버튼 위치 확인 필요" />.
3. `장면 수`에서 `자동`·`4개`·`6개`·`8개` 중 고르고, 필요하면 `바라는 점 (선택)`을 적습니다. 예) 마지막 장면은 버스가 도착하는 순간에서 끊기
4. `모델` 탭에서 텍스트 모델을 확인하고 `장면 나누기`를 누릅니다.
5. 제안된 장면 중 마음에 드는 것을 고르고 `선택한 장면 {n}개 추가`를 누릅니다.

### 2. AI로 원고 쓰기·다듬기

1. 원고가 비어 있는 장면은 `AI로 쓰기`, 원고가 있는 장면은 `AI로 다듬기`를 누릅니다.
2. 다듬기라면 `무엇을 바꿀까요?`에서 프리셋을 고릅니다: `대사 다듬기`, `긴장감 높이기`, `분량 줄이기`, `시작 훅 강화`, `맞춤법·띄어쓰기만`. 원하는 방향은 `직접 요청`에 적습니다.
3. `원고 쓰기` 또는 `다시 쓰기`를 누릅니다.
4. `결과` 탭의 `비교`에서 `지금 원고`와 `새 원고`를 나란히 봅니다.
5. 마음에 들면 `장면에 적용`, 아니면 `버리기`를 누릅니다. 적용한 뒤 마음이 바뀌면 `되돌리기`로 돌아갑니다.

### 3. AI 어시스턴트

상단 `AI 어시스턴트`를 누르면 지금 보고 있는 화면을 바탕으로 질문할 수 있는 패널이 열립니다. ‘무엇을 도와드릴까요? 예: 이 장면 영상 프롬프트를 더 역동적으로’처럼 요청하고 `보내기`를 누릅니다. 어시스턴트는 제안만 하고, 적용은 여러분이 `복사` 또는 `적용`을 눌러야 합니다.

::: info NOTE
패널 아래 ‘지금 사용할 수 있는 텍스트 모델이 없습니다’가 보이면 워크스페이스에 텍스트 모델이 열려 있지 않은 것입니다. 팀 스튜디오라면 소유자나 관리자에게, 혼자 쓰는 스튜디오라면 도움말로 문의합니다.
:::

## PRACTICE — 장면 2 다듬기

1. 장면 2의 `AI로 다듬기`를 누릅니다.
2. 프리셋 `대사 다듬기`를 고르고 `직접 요청`에 아래를 입력합니다.

```text
도윤의 대사를 더 짧고 자연스럽게. 처음 보는 사이니 존댓말을 유지하고, 너무 다정하지 않게.
```

1. `다시 쓰기` → `비교`를 보고 아래 표를 채운 뒤 적용 여부를 정합니다.

| 확인 | 지금 원고 | 새 원고 |
| --- | --- | --- |
| 도윤 대사 길이 |  |  |
| 존댓말 유지 |  |  |
| 장면 1·3과 어울림 |  |  |
| 결정 |  | `장면에 적용` / `버리기` |

::: cost COST · 비용
`장면 나누기`, `원고 쓰기`, `다시 쓰기`, 어시스턴트 질문은 텍스트 AI 사용량만큼 크레딧이 듭니다. 영상·이미지보다는 적게 듭니다.
:::

## REVIEW — 제대로 했나요?

- [ ] `비교`를 보고 적용할지 스스로 정했다.
- [ ] `되돌리기`의 위치를 안다.
- [ ] 어시스턴트는 제안만 한다는 것을 안다.

| 자주 겪는 실패 | 화면 문구 | 해결 |
| --- | --- | --- |
| 다시 쓰기가 안 됨 | 다시 쓰지 못했습니다. 잠시 후 다시 시도해 주세요. | 잠시 후 재시도 |
| 장면 추가가 중간에 멈춤 | {n}개를 추가한 뒤 멈췄습니다. 다시 시도해 주세요. | 남은 장면만 다시 추가 |
| 확인 없이 적용해 분위기가 바뀜 | — | `되돌리기` |

**확인 문제** 1) 맞춤법만 고치고 싶을 때 고르는 프리셋은? 2) AI 원고를 적용하기 전에 보는 화면은? 3) 어시스턴트의 제안을 반영하는 버튼은?

정답: 1) `맞춤법·띄어쓰기만` 2) `비교` 3) `복사` 또는 `적용`

**응용 과제** — 장면 1에 `시작 훅 강화`를 적용해 보고, 첫 문장이 어떻게 바뀌었는지 비교해 보세요.
