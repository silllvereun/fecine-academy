# 28장 편집: 씬 잇기·트림·전환

<ChapterGoals />

## WHY

> 좋은 테이크를 모았는데, 이어 붙이니 왜 어색할까요?

- 컷 길이와 전환이 이야기의 리듬을 만든다는 것을 이해합니다.
- 씬을 타임라인에 놓고, 쓸 테이크를 고르고, 앞뒤를 잘라 냅니다.
- 편집한 결과를 편집본으로 저장합니다.

**완성 결과물** 「비 오는 정류장」 편집본 v1 (캡처 23-01)

## HOW

### 편집이 하는 일

촬영(생성)이 재료를 만든다면 편집은 **무엇을, 얼마 동안, 어떤 순서로** 보여 줄지 정합니다. AI 영상은 씬마다 길이가 정해진 채 나오므로, 앞뒤의 머뭇거리는 부분을 잘라 내는 것만으로도 완성도가 크게 달라집니다.

| 개념 | 뜻 | 초보자 기준 |
| --- | --- | --- |
| 컷 길이 | 한 컷이 화면에 머무는 시간 | 정보가 하나면 2–4초, 감정을 보여 줄 때는 조금 길게 |
| 트림 | 클립의 앞(시작)과 뒤(끝)를 잘라 냄 | 생성 영상의 처음·끝 0.5초는 어색한 경우가 많음 |
| 컷 전환 | 장면이 바로 바뀜 | 기본값. 대부분 이것으로 충분 |
| 디졸브 | 앞 장면이 서서히 사라지며 겹침 | 시간이 흐름, 회상 |
| 페이드 | 검은 화면으로 사라지거나 나타남 | 시작·끝, 큰 단락 구분 |
| 와이프 | 화면을 밀어내며 바뀜 | 장소 이동. 진지한 장면에는 피함 |

### 편집 화면 구성

작품 왼쪽 제작 모듈 메뉴의 **편집**이 편집 화면입니다. 왼쪽 **미디어**(씬 · 음악 · 효과음 · 자막 · 카드), 가운데 재생 화면, 오른쪽 **속성**(클립 · 색보정 · 자막 탭), 아래 타임라인(자막 · 영상 · 오디오 · 배경음악 · 효과음 트랙)으로 나뉩니다. 타임라인은 영상을 시간 순서대로 늘어놓은 띠, 트랙은 그 안의 한 줄(영상 줄, 음악 줄 등), 클립은 트랙 위에 놓인 씬 영상 하나입니다. 편집 화면은 작품 비율에 맞춰지고, 영상은 원본 fps(초당 프레임 수)로 편집됩니다.

### FECINE에서 하기

1. 작품의 왼쪽 제작 모듈 메뉴에서 **편집**을 엽니다. 에피소드가 여럿이면 편집할 **에피소드**를 고릅니다.
2. 위쪽 **스토리보드 순서로 자동 배치**를 누릅니다. 씬 1·2·3이 스토리보드 순서대로 영상 트랙에 놓입니다. 테이크가 없는 씬은 미디어에 **영상 없음**으로 보입니다.
3. 타임라인에서 씬 1 클립을 누르면 오른쪽 **속성**의 **클립** 탭에 **선택한 클립** 정보가 나옵니다.
4. **테이크**에서 27장에서 고른 테이크를 선택합니다.
5. **시작 트림 (초)** 와 **끝 트림 (초)** 로 앞뒤를 잘라 냅니다. 클립 중간을 나누려면 재생 위치를 옮기고 **자르기**를 누릅니다. 작품 비율과 모양이 다른 영상이면 **화면 채우기**에서 **여백 넣기** / **흐린 배경** / **잘라서 채우기** 중 하나를 고릅니다.
6. 씬 2 클립을 선택하고 **씬 전환**에서 **디졸브**를 고르면 씬 1과 2 사이가 겹치며 바뀝니다. **전환 시간**은 0.5초 정도로 짧게 둡니다. 씬 3은 **컷**으로 둡니다.
7. **재생**으로 처음부터 끝까지 봅니다. 잘못 고쳤다면 **실행 취소**/**다시 실행**을 씁니다.
8. **편집본 저장 (v1)** 을 누릅니다. `편집본 v1을 저장했습니다`가 보이면 끝입니다.

**[캡처 23-01]** 편집 화면 — ① 미디어 ② 재생 화면 ③ 속성(클립) ④ 타임라인 ⑤ 스토리보드 순서로 자동 배치 ⑥ 편집본 저장

![캡처 23-01](/images/v1/captures/cap-23-01.png)

::: tip TIP
편집 중에는 **자동 저장됨**이 표시되며 작업이 임시로 저장됩니다. 하지만 내보내기는 **저장한 편집본**을 기준으로 합니다. 만족스러운 지점마다 편집본을 저장해 두세요.
:::

::: info NOTE
편집 화면은 스토리보드를 따라갑니다. 스토리보드에 새로 생긴 씬은 순서에 맞게 타임라인에 들어가고, 스토리보드에서 영상이 바뀐 클립은 잘라 낸 부분과 효과를 유지한 채 새 영상으로 바뀝니다. 삭제됐거나 영상이 없는 씬의 클립은 빠집니다. **스토리보드 순서로 자동 배치**는 영상 트랙만 다시 놓고 자막은 예전 위치에 두므로, 누른 뒤에는 자막이 대사와 어긋나지 않았는지 확인합니다.
:::

::: tip TIP
클립의 영상 자체를 바꾸려면 **스토리보드에서 이 씬 열기**로 돌아가 새로 만들거나 다른 테이크를 고릅니다. 편집에서 자르고 속도를 바꿔도 스토리보드 영상은 그대로입니다. **앞 씬과 이어짐**을 켠 씬(27장)은 처음 놓일 때 흐린 첫 0.2초가 자동으로 잘려 있습니다.
:::

::: info NOTE
편집 화면에는 씬 영상을 내려받는 버튼이 없습니다. 씬 하나를 받으려면 스토리보드에서, 자른 구간이 필요하면 내보내기(30장)로 받습니다. 원본이 출력 화면보다 작아 크게 확대되는 클립에는 흐릿해 보일 수 있다는 안내가 나옵니다.
:::

::: warning 주의
저장하지 않은 편집이 있을 때 **되돌리기**를 누르면 `변경 사항을 되돌릴까요?` 창이 뜨고, 확인하면 마지막 편집본으로 돌아갑니다. 지운 편집은 되살릴 수 없습니다. 방금 한 동작 하나만 되돌리려면 실행 취소를 쓰세요.
:::

**확인 문제**

1. 생성 영상을 편집할 때 앞뒤를 조금씩 트림하는 이유는 무엇인가요?
2. 자동 저장과 **편집본 저장**은 어떻게 다른가요?
3. 시간이 흘렀음을 보여 주고 싶을 때 어울리는 전환은 무엇인가요?

정답: 1. 생성 영상의 시작과 끝은 움직임이 어색하거나 멈춰 있는 경우가 많기 때문이다. 2. 자동 저장은 임시 저장이고, 내보내기는 저장한 편집본(v1, v2 …)을 기준으로 한다. 3. 디졸브.

**응용 과제** 같은 세 씬으로 전환을 모두 **컷**으로 한 편집본과, 씬 2에 **페이드**를 넣은 편집본을 각각 저장하고 느낌을 비교해 한 문단으로 적어 보세요.
