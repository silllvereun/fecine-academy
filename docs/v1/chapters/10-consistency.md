# 10장 일관성: 같은 인물을 계속 등장시키는 법

<ChapterGoals />

::: info 이 장의 예제
이 책은 예제 작품 「비 오는 정류장」을 이어서 만듭니다. 비 오는 밤, 우산 없는 수아에게 처음 보는 도윤이 우산을 건네는 15초짜리 영상(씬 3개)입니다. FECINE을 아직 써 보지 않았다면 화면 따라 하기는 건너뛰고 개념과 표만 읽어도 됩니다.
:::

## WHY — 주인공이 씬마다 다른 사람이 되는 이유는?

AI 영상에서 가장 흔한 실망은 ‘씬 1의 수아와 씬 3의 수아가 다른 사람’입니다. 글만으로는 얼굴을 고정할 수 없기 때문입니다. 일관성은 프롬프트가 아니라 **그림으로 지킵니다.**

- 일관성을 지키는 네 가지 방법을 안다.
- FECINE에서 참조·캐릭터 시트·첫 프레임이 각각 어떻게 영상에 전달되는지 안다.
- 일관성 체크리스트를 만든다.

**완성 결과물** — 「비 오는 정류장」 일관성 체크리스트 (참고: 결과 22-A 캐릭터 시트)

## HOW — 일관성을 지키는 네 가지 방법

| 방법 | 무엇을 고정하나 | FECINE에서 |
| --- | --- | --- |
| 1. 참조 이미지 | 인물의 얼굴·의상, 장소, 물건 | `등장인물`·`공간·배경`·`미술·소품`에서 이미지를 만들고, 스토리보드 `등장 요소` 탭에 `추가` |
| 2. 캐릭터 시트 | 여러 각도·표정에서의 같은 얼굴 | 등장인물 상세의 `캐릭터 시트`(정면·측면·후면·표정) |
| 3. 첫 프레임 | 영상의 시작 화면 전체 | `샷 이미지`에서 1장을 프레임에 추가 → `영상을 이 프레임으로 만들기` |
| 4. 스타일 고정 | 그림체·색감 | 작품 `스타일`을 하나로 정하고 씬은 `작품 스타일 따르기` |

### 영상 모델은 그림을 어떻게 받나

씬에 연결된 그림은 다음 규칙으로 영상 모델에 전달됩니다.

| 씬에 있는 것 | 영상에서의 역할 |
| --- | --- |
| 프레임에 넣은 샷 이미지 1장 | **첫 프레임** — 영상이 이 그림에서 시작 |
| 프레임에 넣은 샷 이미지 2–4장 | **연속 프레임** — 순서대로 따라가는 참조 |
| 샷 이미지 없음 | 등장인물·배경·의상·소품·콘티 이미지가 **참조**로 들어감 |

콘티·등장인물·배경 이미지는 첫 프레임이 되지 않고 항상 참조로만 쓰입니다. 샷 이미지를 프레임으로 쓰면 등장인물 참조와 목소리는 함께 가지만, 배경·의상 참조 그림은 영상 모델에 함께 보내지 않습니다. 그래서 첫 프레임 안에 이미 같은 인물·배경이 담겨 있어야 합니다.

씬에 샷을 여러 개 나눠 두었다면 프레임 1은 샷 1, 프레임 2는 샷 2의 시작 그림이 됩니다. `샷 이미지`에서 `샷 {n} 프레임 만들기`로 샷마다 시작 그림을 만들 수 있습니다.

::: info NOTE
모델마다 받을 수 있는 참조 이미지 수가 다릅니다. 이미지를 1장만 받는 모델도 있습니다(부록 A). 참조가 많은 씬은 참조를 많이 받는 모델을 고릅니다(12장).
:::

### 일관성을 돕는 FECINE 기능

- `스토리`의 `영상에 쓸 등장인물 준비`는 씬 대본에 나오지만 아직 디자인이 없는 인물을 알려 줍니다.
- 스토리보드에서 연결한 등장인물에 이미지가 없으면 ‘일부 @ 참조에 아직 이미지가 없습니다’라고 경고합니다.
- `샷 이미지`의 `다음 프레임({frame}) 후보 {n}장`은 같은 인물·의상·배경을 유지한 채 다음 순간을 그립니다.
- `작품정보` › `작품 위키`의 `등장인물`·`연속성 메모` 칸에 외모·의상·상처·날씨처럼 씬마다 같아야 할 것을 적어 두면, AI가 대본과 영상 프롬프트를 쓸 때 이 내용을 먼저 읽습니다.
- 같은 장소·시간에서 바로 이어지는 씬이면 스토리보드에서 `앞 씬과 이어짐`을 켭니다. 영상 프롬프트가 앞 영상이 끝난 순간에서 시작합니다. `앞 씬 끝 장면으로 시작`은 앞 씬 영상의 끝 무렵 장면을 이 씬의 첫 프레임으로 씁니다.
- 새 영상을 만들 때 작품의 등장인물·배경·소품 이미지를 참조 이미지로 골라 넣을 수 있습니다.
- 테이크 피드백에서 `얼굴·의상이 바뀜`을 고르면 ‘씬 탭에서 등장인물 참조 이미지가 연결돼 있는지, 프롬프트에 얼굴·머리·옷 특징이 적혀 있는지 확인’하라고 알려 줍니다.

## PRACTICE — 일관성 체크리스트

영상을 만들기 전에 씬마다 확인할 표입니다. 24–27장에서 그대로 씁니다.

| 확인 | 씬 1 | 씬 2 | 씬 3 |
| --- | --- | --- | --- |
| 등장인물이 모두 `등장 요소` 탭에 연결됐다 | 수아 | 수아, 도윤 | 수아, 도윤 |
| 연결된 등장인물에 대표 이미지가 있다 |  |  |  |
| 배경 ‘비 오는 버스 정류장’이 연결됐다 |  |  |  |
| 프롬프트에 얼굴·머리·옷 특징이 한 줄 있다 |  |  |  |
| 씬 스타일이 `작품 스타일 따르기`다 |  |  |  |
| (선택) 샷 이미지를 프레임에 넣었다 |  |  |  |

::: cost COST · 비용
체크리스트는 무료입니다. 대신 이 표를 채우고 생성하면 재생성 횟수가 줄어 크레딧을 가장 많이 아낄 수 있습니다.
:::

## REVIEW — 제대로 했나요?

- [ ] 일관성을 지키는 네 가지 방법을 말할 수 있다.
- [ ] 프레임에 넣은 샷 이미지가 1장일 때와 2장 이상일 때의 차이를 안다.
- [ ] 체크리스트를 완성했다.

| 자주 겪는 실패 | 해결 |
| --- | --- |
| 등장인물을 만들어 놓고 씬에 연결하지 않음 | `등장 요소` 탭에서 인물 `추가` |
| 의상이 씬마다 바뀜 | 등장인물 연결 후 `변형 선택`으로 같은 의상 고르기 |
| 콘티를 첫 화면으로 기대 | 콘티는 참조로만 쓰임. 첫 화면은 `샷 이미지` |

**확인 문제** 1) 여러 각도의 같은 얼굴을 만드는 기능은? 2) 샷 이미지를 프레임에 1장만 넣으면 영상에서 무엇이 되나요? 3) 연결된 등장인물에 이미지가 없을 때 나오는 경고는?

정답: 1) `캐릭터 시트` 2) 첫 프레임 3) ‘일부 @ 참조에 아직 이미지가 없습니다’

**응용 과제** — 수아의 외형을 프롬프트에 한 줄로 적어 보세요(나이·머리·옷·색). 이 한 줄을 씬 1–3에 똑같이 넣습니다.
