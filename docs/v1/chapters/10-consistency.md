# 10장 일관성: 같은 인물을 계속 등장시키는 법

<ChapterGoals />

::: info 이 장의 예제
이 책은 예제 작품 「비 오는 정류장」을 이어서 만듭니다. 비 오는 밤, 우산 없는 수아에게 처음 보는 도윤이 우산을 건네는 15초짜리 영상(장면 3개)입니다. FECINE을 아직 써 보지 않았다면 화면 따라 하기는 건너뛰고 개념과 표만 읽어도 됩니다.
:::

## WHY — 주인공이 장면마다 다른 사람이 되는 이유는?

AI 영상에서 가장 흔한 실망은 ‘장면 1의 수아와 장면 3의 수아가 다른 사람’입니다. 글만으로는 얼굴을 고정할 수 없기 때문입니다. 일관성은 프롬프트가 아니라 **그림으로 지킵니다.**

- 일관성을 지키는 네 가지 방법을 안다.
- FECINE에서 참조·캐릭터 시트·첫 프레임이 각각 어떻게 영상에 전달되는지 안다.
- 일관성 체크리스트를 만든다.

**완성 결과물** — 「비 오는 정류장」 일관성 체크리스트 (참고: 결과 22-A 캐릭터 시트)

## HOW — 일관성을 지키는 네 가지 방법

| 방법 | 무엇을 고정하나 | FECINE에서 |
| --- | --- | --- |
| 1. 참조 이미지 | 인물의 얼굴·의상, 장소, 물건 | `캐릭터 · 아트`에서 이미지를 만들고, 스토리보드 `장면` 탭 `참고 레퍼런스`에 `추가` |
| 2. 캐릭터 시트 | 여러 각도·표정에서의 같은 얼굴 | 캐릭터 상세의 `캐릭터 시트`(정면·측면·후면·표정) |
| 3. 첫 프레임 | 영상의 시작 화면 전체 | `장면 프레임`에서 1장을 확정 → `영상을 이 프레임으로 만들기` |
| 4. 스타일 고정 | 그림체·색감 | 작품 `스타일`을 하나로 정하고 장면은 `작품 스타일 따르기` |

### 영상 모델은 그림을 어떻게 받나 (v1.38.0)

장면에 연결된 그림은 다음 규칙으로 영상 모델에 전달됩니다.

| 장면에 있는 것 | 영상에서의 역할 |
| --- | --- |
| 확정한 장면 프레임 1장 | **첫 프레임** — 영상이 이 그림에서 시작 |
| 확정한 장면 프레임 2–4장 | **연속 프레임** — 순서대로 따라가는 참조 |
| 장면 프레임 없음 | 캐릭터·배경·의상·소품·콘티 이미지가 **참조**로 들어감 |

콘티·캐릭터·배경 이미지는 첫 프레임이 되지 않고 항상 참조로만 쓰입니다. 또 장면 프레임 1장을 첫 프레임으로 쓰면, 배경·의상 참조 그림은 영상 모델에 함께 보내지 않습니다. 그래서 첫 프레임 안에 이미 같은 인물·배경이 담겨 있어야 합니다.

::: info NOTE
모델마다 받을 수 있는 참조 이미지 수가 다릅니다. 이미지를 1장만 받는 모델도 있습니다(부록 A). 참조가 많은 장면은 참조를 많이 받는 모델을 고릅니다(12장).
:::

### 일관성을 돕는 FECINE 기능

- `스토리`의 `영상에 쓸 캐릭터 준비`는 원고에 나오지만 아직 디자인이 없는 인물을 알려 줍니다.
- 스토리보드에서 연결한 캐릭터에 이미지가 없으면 ‘일부 @ 참조에 아직 이미지가 없습니다’라고 경고합니다.
- `장면 프레임`의 `다음 프레임 후보`는 같은 인물·의상·배경을 유지한 채 다음 장면을 만듭니다.
- 테이크 피드백에서 `얼굴·의상이 바뀜`을 고르면 ‘장면 탭에서 캐릭터 참조 이미지가 연결돼 있는지, 프롬프트에 얼굴·머리·옷 특징이 적혀 있는지 확인’하라고 알려 줍니다.

## PRACTICE — 일관성 체크리스트

영상을 만들기 전에 장면마다 확인할 표입니다. 24–27장에서 그대로 씁니다.

| 확인 | 장면 1 | 장면 2 | 장면 3 |
| --- | --- | --- | --- |
| 등장인물이 모두 `참고 레퍼런스`에 연결됐다 | 수아 | 수아, 도윤 | 수아, 도윤 |
| 연결된 캐릭터에 대표 이미지가 있다 |  |  |  |
| 배경 ‘비 오는 버스 정류장’이 연결됐다 |  |  |  |
| 프롬프트에 얼굴·머리·옷 특징이 한 줄 있다 |  |  |  |
| 장면 스타일이 `작품 스타일 따르기`다 |  |  |  |
| (선택) 장면 프레임을 확정했다 |  |  |  |

::: cost COST · 비용
체크리스트는 무료입니다. 대신 이 표를 채우고 생성하면 재생성 횟수가 줄어 크레딧을 가장 많이 아낄 수 있습니다.
:::

## REVIEW — 제대로 했나요?

- [ ] 일관성을 지키는 네 가지 방법을 말할 수 있다.
- [ ] 장면 프레임 1장과 2장 이상의 차이를 안다.
- [ ] 체크리스트를 완성했다.

| 자주 겪는 실패 | 해결 |
| --- | --- |
| 캐릭터를 만들어 놓고 장면에 연결하지 않음 | `장면` 탭 `참고 레퍼런스` > `캐릭터` > `추가` |
| 의상이 장면마다 바뀜 | 캐릭터 연결 후 `변형 선택`으로 같은 의상 고르기 |
| 콘티를 첫 화면으로 기대 | 콘티는 참조로만 쓰임. 첫 화면은 `장면 프레임` |

**확인 문제** 1) 여러 각도의 같은 얼굴을 만드는 기능은? 2) 장면 프레임을 1장만 확정하면 영상에서 무엇이 되나요? 3) 연결된 캐릭터에 이미지가 없을 때 나오는 경고는?

정답: 1) `캐릭터 시트` 2) 첫 프레임 3) ‘일부 @ 참조에 아직 이미지가 없습니다’

**응용 과제** — 수아의 외형을 프롬프트에 한 줄로 적어 보세요(나이·머리·옷·색). 이 한 줄을 장면 1–3에 똑같이 넣습니다.
