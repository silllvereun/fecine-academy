# 실습 1 짧은 시네마틱 영상

<ChapterGoals />

## WHY

> 지금까지 배운 것만으로, 책을 보지 않고 한 편을 끝까지 만들 수 있을까요?

- 대사 없이 화면과 소리만으로 분위기를 전합니다.
- 샷 이미지를 먼저 만들고 영상을 생성하는 흐름을 혼자 반복합니다.
- 정해진 예산 안에서 끝냅니다.

**완성 결과물** 16:9 15초 무드 영상 1편 (결과 P1-A)

## HOW

| 단계 | 할 일 | 다시 볼 장 |
| --- | --- | --- |
| 1 기획 | 한 문장 이야기, 씬 3개, 각 5초 | 7장 |
| 2 작품 만들기 | 16:9 · 720p · 실사 · 시네마틱 | 16장 |
| 3 스토리 | 에피소드 1개, 씬 3개, 지문만(대사 없음) | 17장 |
| 4 등장인물·공간·배경 | 인물 1명, 배경 1–2개 | 20–21장 |
| 5 씬 구성 | 카메라·스타일 지정 | 24–25장 |
| 6 샷 이미지 | 씬마다 시작 프레임 1장 | 26장 |
| 7 생성 | 씬당 테이크 최대 2개 | 27장 |
| 8 편집·소리 | 트림, 디졸브 1회, 앰비언스·배경음악 | 28–29장 |
| 9 내보내기 | 마스터 | 30장 |

::: tip TIP
대사가 없으므로 스토리보드 `모델` 탭의 `사운드`를 `무음`으로 두고, 소리는 편집에서 배경음악·효과음으로 넣는 편이 안전합니다.
:::

씬 1 (5초) 등대 내부, 어두운 방. 노인이 램프를 끈다. 클로즈업, 고정.
씬 2 (5초) 등대 계단. 노인이 천천히 올라간다. 미디엄, 뒤에서 따라감.
씬 3 (5초) 등대 꼭대기. 수평선 위로 해가 뜬다. 와이드, 천천히 물러남.

## REVIEW

33장의 셀프 리뷰표로 채점합니다. 특히 다음을 확인합니다.

- [ ] 대사 없이도 이야기(시작 → 이동 → 도착)가 전달된다.
- [ ] 세 씬의 인물이 같은 사람으로 보인다.
- [ ] 씬마다 카메라가 다르게(클로즈업 → 미디엄 → 와이드) 움직인다.
- [ ] 예산표의 합계와 **크레딧 · 사용량** 화면의 실제 사용이 크게 다르지 않다.
