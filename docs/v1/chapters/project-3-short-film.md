# 실습 3 스토리가 있는 AI 단편

<ChapterGoals />

## WHY

> 대사가 있고 인물이 둘 이상 나오는 1분짜리 이야기는 무엇이 더 어려울까요?

- 대본 파일에서 시작하는 경로(**스토리** › **작품 자료** + AI 어시스턴트의 **에피소드·씬 추출**)를 써 봅니다.
- 캐릭터 시트·의상·목소리로 여러 씬의 인물을 일관되게 유지합니다.
- 대사 자막을 넣고 1분 내외의 단편을 끝냅니다.

**완성 결과물** 대사가 있는 1분 내외 단편 1편 (결과 P3-A)

## HOW

| 단계 | 할 일 | 다시 볼 장 |
| --- | --- | --- |
| 1 대본 준비 | 직접 쓴 대본 또는 사용이 허락된 원작(프리소스 포함, [실습 4](/v1/chapters/project-4-free-source)). 씬 6–8개, 인물 2명 | 7장, 11장 |
| 2 AI 자동생성 | **스토리** › **작품 자료**의 원문에 대본을 올리고(또는 **스토리 작성**) AI 어시스턴트에서 **에피소드·씬 추출** → **등장 요소 만들기** → (선택) **촬영 설계 만들기**. 진행은 **진행 상황** 탭 | 19장 |
| 3 검토 | 만들어진 에피소드·씬·등장인물·배경·소품을 스토리에서 확인하고 고침 (필요하면 씬 합치기·나누기) | 17–18장 |
| 4 일관성 | 캐릭터 시트·의상 정리 | 20장, 22장 |
| 5 목소리 | 두 인물에 목소리 연결 | 23장 |
| 6 씬 구성·샷 이미지 | 대사 씬은 인물 얼굴이 보이는 미디엄·클로즈업. 스토리보드에서 **영상 프롬프트 만들기**로 빈 씬의 프롬프트를 채움 | 24–26장 |
| 7 생성 | 대사 씬은 음성을 받는 모델 선택, 이어지는 씬은 **앞 씬과 이어짐** | 12장, 27장 |
| 8 편집 | **재생 위치에 자막 추가**로 대사 자막을 직접 입력, **화자 이름 표시** | 28–29장 |
| 9 내보내기·게시 요청 | 마스터 → (선택) 채널 게시 요청 | 30장 |

::: info NOTE
**AI 자동생성**은 원문의 대본을 읽어 에피소드와 씬, 등장인물·배경·소품(등장 요소), 촬영 설계를 만들지만, **이미지는 만들지 않습니다.** 씬 영상 프롬프트는 스토리보드에서 만듭니다. 등장인물·배경 이미지는 AI 자동생성이 끝난 뒤 직접 생성합니다. 소설처럼 긴 원문은 **읽을 범위**(쪽)를 정해 한 번에 최대 18,000자씩 추출하고, 나머지는 이어서 추출합니다.
:::

::: warning 주의
립싱크(입 모양과 소리를 맞추는 것)는 모델마다 수준이 다르고 완벽하지 않습니다. 긴 대사는 두세 씬으로 나누고, 얼굴이 작게 보이는 씬이나 뒷모습에 대사를 입히는 편집도 좋은 방법입니다.
:::

## PRACTICE

**대본 형식 (예시 한 씬)**

```text
S#3. 편의점 앞 / 밤
편의점 불빛 아래, 지훈이 캔커피 두 개를 들고 나온다. 서연이 벤치에 앉아 있다.
지훈: 단 거, 아니면 쓴 거?
서연: (웃으며) 오늘은 단 거.
```

**씬 계획표**

| 씬 | 길이 | 대사 | 샷 크기 | 음성 모델 필요 |
| --- | --- | --- | --- | --- |
| 1 | 5초 | 없음 | 와이드 | 아니오 |
| 2 | 8초 | 1줄 | 미디엄 | 예 |
| … |  |  |  |  |

| 결과 P3-A | 결과 P3-B |
| --- | --- |

::: cost COST · 비용
이 책에서 가장 비용이 큰 실습입니다. AI 자동생성(사용한 만큼 차감), 캐릭터 시트·의상 이미지, 씬 6–8개의 영상이 듭니다. 시작 전에 31장의 예산 점검표를 채웁니다. 프리소스 원작으로 시작하는 방법은 [실습 4](/v1/chapters/project-4-free-source)를 참고하세요.
:::

## REVIEW

- [ ] 두 인물이 처음부터 끝까지 같은 얼굴·의상으로 보인다.
- [ ] 대사가 자막으로 나오고, 화자가 누구인지 알 수 있다.
- [ ] 목소리가 인물마다 구분된다.
- [ ] 립싱크가 어색한 씬은 편집으로 가렸다.
- [ ] 게시 요청을 한다면 대본·원작의 권리를 확인했다.
