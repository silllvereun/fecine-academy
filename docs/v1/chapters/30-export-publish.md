# 30장 내보내기·다운로드·게시 요청

<ChapterGoals />

## WHY

> 완성한 영상을 YouTube에 올릴 때와 Shorts에 올릴 때, 같은 파일을 써도 될까요?

- 코덱·비율·해상도가 무엇인지, 플랫폼마다 무엇이 다른지 이해합니다.
- 출력 프리셋을 골라 렌더(편집본을 영상 파일 하나로 만드는 일)하고 파일을 내려받습니다.
- 씬 하나만 받기, 로고 없이 받기, 편집 프로젝트 받기, FECINE 공식 채널에 게시 요청하기를 구분합니다.

**완성 결과물** 「비 오는 정류장」 완성 MP4 (결과 30-A, 캡처 25-01)

## HOW

### 내보내기의 세 가지 값

| 값 | 뜻 | 고르는 기준 |
| --- | --- | --- |
| 코덱·포맷 | 영상을 압축하는 방식과 파일 형식 | 대부분 MP4 / H.264(거의 모든 기기에서 재생). 편집 전문가에게 넘길 때만 ProRes(화질 손실이 적고 파일이 큼) |
| 비율 | 가로:세로 (16:9, 9:16, 1:1) | 올릴 곳의 화면 모양 |
| 해상도·크기 | 화면의 점 개수 (예: 1280×720) | 편집본보다 크게는 못 만듦. 편집 화면은 작품과 같은 방향의 가장 선명한 테이크를 따르며 최대 4K |

### 출력 프리셋

| 프리셋 | 비율 | 포맷 | 쓰임 |
| --- | --- | --- | --- |
| 마스터 | 작품 그대로 | MP4 / H.264 | 보관용 원본, 채널 게시의 기준 |
| YouTube 고화질 | 16:9 | MP4 / H.264 | 가로 영상 |
| Shorts · Reels | 9:16 | MP4 / H.264 | 세로 짧은 영상 |
| 정사각 피드 | 1:1 | MP4 / H.264 | 피드 게시물 |
| 방송용 ProRes | 작품 그대로 | MOV / ProRes 422 | 편집·방송 단계로 넘길 때 (파일이 매우 큼) |

작품과 비율이 다른 프리셋(Shorts · Reels 9:16, 정사각 피드 1:1)은 화면 전체를 줄여 넣고 남는 곳을 검은 여백으로 채웁니다. 예를 들어 16:9 작품을 Shorts · Reels로 내보내면 위아래에 여백이 생깁니다. 세로 영상이 목적이라면 처음부터 9:16으로 작품을 만드는 것이 가장 좋습니다(16장). 미리보기는 여백을 포함한 실제 출력 모양을 보여 줍니다.

### FECINE에서 하기 — 작품 내보내기

1. 편집 화면 위쪽 **내보내기**를 누릅니다. 저장하지 않은 편집이 있으면 `편집본을 저장하고 내보낼까요?` 창이 뜹니다. **저장하고 내보내기**를 눌러 편집본을 저장한 뒤 **내보내기** 화면으로 이동합니다.
2. 왼쪽 **출력 프리셋**에서 **마스터**를 고릅니다.
3. 오른쪽 **출력** 탭에서 **포맷**(MP4 / H.264), **출력 크기**(원본), **자막**(영상에 입힘 / 별도 파일 / 없음), **범위**(EP.1만 / 작품 전체)를 확인합니다.
4. 필요하면 **대사 · 음악 분리 트랙**(WAV: 음질을 줄이지 않은 소리 파일)과 **로고 없이 내보내기 (+n 크레딧)**를 켭니다.
5. 아래 `요금: n 크레딧`을 확인하고 **렌더 시작**을 누릅니다. 크레딧은 시작할 때 잡아 두었다가 영상이 전달되면 차감되고, 전달되지 않으면 모두 돌려받습니다(화면에는 요금만 표시됩니다).
6. `n개 중 n번째 구간을 만드는 중…` → `…올리는 중…` → `구간을 이어 붙이고 확인하는 중입니다…` 순서로 진행됩니다. 끝날 때까지 탭을 열어 둡니다.
7. `내보내기가 끝났습니다.`가 나오면 **영상 다운로드**를 누릅니다. 이후에는 위쪽 **마스터 다운로드**나 아래 **렌더 이력**의 **다운로드**로도 받을 수 있습니다. 받은 파일은 `날짜_작품명`(예: `20261110_비 오는 정류장`)으로 저장되며, 날짜는 렌더를 만든 날입니다.
8. 필요하면 같은 방법으로 **Shorts · Reels**를 고르고 한 번 더 렌더합니다. 작품 비율이 16:9라면 미리보기에서 위아래 여백을 확인합니다.

::: info NOTE
씬 영상은 H.264로 저장됩니다. Seedance 2.5로 만든 영상이 든 작품도 내보낼 수 있습니다(v1.78.2에서 “영상을 읽지 못했습니다” 오류를 고쳤습니다).
:::

::: info NOTE
렌더는 서버가 아니라 **지금 쓰는 PC의 브라우저**가 합니다. PC의 Chrome·Edge·Safari 최신 버전에서 열고, 렌더 중에는 `이 탭을 열어 두세요. PC가 잠들지 않게 해 둡니다.`를 따릅니다. 멈췄다면 다시 열어 **이어서 진행**합니다. 직접 **내보내기 중단**을 누르면 **렌더 이력**에 **중단됨**으로 남고, 잡아 둔 크레딧은 돌려받습니다.
:::

::: info NOTE
내보낸 영상에는 화면 하단 가운데에 로고 하나가 들어갑니다. **로고 없이 내보내기**를 켜면 추가 요금으로 로고 없이 받습니다.
:::

::: tip TIP
**렌더 이력**의 **자막 · 분리 트랙**에서 자막 파일(SRT: 자막 문장과 시간만 담은 글자 파일)과 대사·음악·효과음 파일을 따로 받을 수 있습니다. 다른 편집 프로그램에서 마무리할 때 쓸모 있습니다.
:::

### FECINE에서 하기 — 편집 프로젝트 받기

Premiere·DaVinci 같은 편집 프로그램에서 마무리하고 싶다면, 렌더한 영상 대신 **편집 프로젝트**를 받습니다.

1. 내보내기 화면 **출력** 탭에서 **편집 프로젝트 (Premiere·DaVinci)**를 찾습니다. 제목 옆 ⓘ(`편집 프로젝트 설명`)를 누르면 무엇이 저장되는지 읽을 수 있습니다. 범위는 **범위** 선택(EP.1만 / 작품 전체)을 따릅니다.
2. **폴더를 골라 저장**을 누르고 저장할 폴더를 고릅니다. 저장한 편집에 쓰인 원본 클립이 재압축 없이 `clips` 폴더에, 편집 파일(XML·EDL)과 자막(SRT)과 함께 저장됩니다.
3. Premiere는 `파일 > 가져오기`, DaVinci는 `파일 > 가져오기 > 타임라인`에서 XML 파일을 엽니다. 미디어를 찾지 못하면 `clips` 폴더를 지정하면 파일 이름으로 다시 연결됩니다.

옮겨지는 것은 컷 순서·길이·속도, 전환, 소리와 음악·효과음입니다. 타이틀·엔딩 카드는 위치만 표시되고, 색보정(룩)과 흐린 배경 채우기는 옮겨지지 않습니다. EDL은 다른 프로그램용으로 화면만 담깁니다.

::: info NOTE
폴더에 바로 저장하므로 최신 Chrome 또는 Edge가 필요합니다. 원본 클립에는 로고가 없으므로, 로고가 들어가는 환경에서는 로고 제거 요금이 범위마다 한 번 붙고, 같은 범위를 다시 받아도 다시 결제되지 않습니다. 요금은 `{n} 크레딧`으로 표시됩니다(`무료`로 보이면 요금이 없습니다).
:::

### FECINE에서 하기 — 씬 하나만 받기

1. 스토리보드에서 씬의 테이크를 열고 **다운로드**를 누릅니다. 편집 화면에는 씬 다운로드가 없습니다. 자른 구간이 필요하면 작품 내보내기로 받습니다.
2. **로고 포함 다운로드 · 무료** 또는 **로고 없이 다운로드 · n 크레딧**을 고릅니다.
3. 로고 없이 받을 때는 확인 창에서 **차감하고 다운로드**를 누릅니다.

::: warning 주의
로고 없는 씬 다운로드는 `같은 영상을 다시 받을 때도 다시 차감됩니다.` 받은 파일은 잘 보관해 두세요.
:::

### FECINE에서 하기 — 채널 게시 요청

채널 게시는 내 YouTube 채널에 올리는 기능이 아닙니다. **FECINE 공식 채널**에 올려 달라고 요청하고, 운영자가 검토한 뒤 게시합니다.

1. **마스터**(MP4 / H.264)를 먼저 렌더합니다. 마스터가 없으면 **채널** 탭에 `채널에 올리려면 먼저 마스터(MP4 / H.264)를 렌더하세요.`가 보입니다.
2. 내보내기 화면의 **채널** 탭에서 **채널 게시 요청**을 누르면 **채널 게시** 화면이 열립니다.
3. **보낼 영상**을 고르고 **제목**, **설명**, **해시태그**(띄어쓰기나 쉼표로 구분)를 입력합니다.
4. **채널**을 고르고, 해당하면 **어린이를 위한 영상입니다**를 켭니다.
5. **확인**의 네 항목(권리 보유, 실존 인물 미사용, AI 생성 표시 동의, 게시·수익 배분 동의)을 읽고 모두 체크합니다.
6. **게시 요청**을 누릅니다. **요청 내역**에서 상태(검토 대기 → 게시 중 → 게시 완료, 또는 반려)를 확인합니다. 검토가 시작되기 전에는 **요청 취소**할 수 있습니다.

## REVIEW

- [ ] 코덱·비율·해상도를 구분해 설명할 수 있다.
- [ ] 마스터를 렌더하고 내려받았다.
- [ ] 작품과 비율이 다른 프리셋에서 여백이 어떻게 생기는지 미리보기로 확인했다.
- [ ] 씬 다운로드에서 로고 포함·로고 없음의 차이를 알았다.
- [ ] 편집 프로젝트 받기가 언제 쓸모 있는지 안다.
- [ ] 게시 요청의 확인 항목 네 가지를 읽었다.

**확인 문제**

1. 16:9 작품을 Shorts · Reels로 내보내면 화면은 어떻게 되나요?
2. 렌더를 서버가 아니라 내 PC가 한다는 것은 어떤 주의점을 만드나요?
3. 채널 게시 요청을 하면 영상은 어디에 올라가나요?
