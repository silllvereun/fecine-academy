# 22장 캐릭터 시트와 의상으로 일관성 지키기

<ChapterGoals />

## WHY — 같은 인물을 여러 각도에서 보여주려면?

대표 이미지는 정면 한 장뿐입니다. 씬 2에서 수아는 옆을 돌아보고 놀라는데, AI는 수아의 옆모습을 모릅니다. 캐릭터 시트는 같은 인물의 정면·측면·후면·표정을 미리 만들어 두는 기능입니다(10장의 실전).

- 대표 이미지로 캐릭터 시트를 만든다.
- 의상을 추가하고 씬마다 고른다.
- 캐릭터 시트가 왜 필요한지 설명한다.

**완성 결과물** — 수아 캐릭터 시트(정면·측면·후면·표정) (결과 22-A)

## HOW — 화면 따라 하기

### 1. 캐릭터 시트

1. `등장인물` 메뉴에서 수아를 눌러 상세 화면을 열고 `캐릭터 시트` 탭을 엽니다. (탭은 `정보`·`이미지`·`캐릭터 시트`)
2. 칸은 정면·측면·후면과 표정(웃음·화남·슬픔·놀람)입니다. 칸마다 `{칸} 만들기`를 누르거나, 한 번에 `빠진 {n}장 모두 만들기`를 누릅니다.
3. `모델`은 **참조 이미지를 쓸 수 있는 모델**이어야 합니다. 안 되는 모델은 ‘참조 이미지 생성 불가’로 표시됩니다.
4. 만드는 동안 ‘만드는 중… (남은 {n}장)’이 보입니다. 완성된 칸은 `{칸} 보기`로 크게 봅니다.

::: info NOTE
‘시트는 대표 이미지와 같은 인물로 만들어져요.’ 대표 이미지가 없으면 ‘대표 이미지를 먼저 만들어 주세요.’가 나옵니다. 대표 이미지를 바꾸면 시트도 다시 만드는 것이 좋습니다.
:::

### 2. 의상(변형)

같은 인물이 옷을 바꿔 입는 이야기라면 의상을 따로 만듭니다.

1. 등장인물 상세의 `이미지` 탭에서 `의상 추가`를 누릅니다.
2. `의상 이름`을 적고(기본 ‘의상1’) 이미지를 만듭니다.
3. 자주 쓰는 의상은 `기본으로 설정`, 필요 없는 의상은 `의상 삭제`.
4. 스토리보드에서 등장인물을 연결할 때 `변형 선택`으로 씬에 맞는 의상을 고릅니다(24장). 캐릭터 시트의 각 칸도 의상처럼 씬마다 고를 수 있고, 참조 목록에는 ‘수아 · 표정 · 웃음’처럼 표시됩니다.

### 3. 보이스

- 등장인물의 `보이스`는 23장에서 연결합니다.

1. 20장에서 만든 수아 대표 이미지를 확인합니다.
2. `캐릭터 시트` → `빠진 {n}장 모두 만들기`를 누릅니다.

## REVIEW — 제대로 했나요?

- [ ] 수아의 시트 칸이 모두 같은 사람으로 보인다.
- [ ] `의상 추가`와 `변형 선택`의 관계를 안다.
- [ ] 대표 이미지와 캐릭터 시트의 차이를 안다.

| 자주 겪는 실패 | 화면 문구 | 해결 |
| --- | --- | --- |
| 시트가 만들어지지 않음 | 대표 이미지를 먼저 만들어 주세요. | 20장으로 돌아가 대표 이미지 만들기 |
| 모델을 고를 수 없음 | 참조 이미지를 쓸 수 있는 모델을 골라 주세요. | 참조를 받는 모델 선택(부록 A) |
| 안전 정책 거절 | 안전 정책으로 거절됐어요. 다른 모델로 다시 시도해 보세요. | 다른 모델로 재시도 |
| 다른 생성이 진행 중 | 다른 이미지를 만드는 중이에요. 끝난 뒤 다시 눌러 주세요. | 완료 후 다시 |

**확인 문제** 1) 캐릭터 시트의 칸 종류는? 2) 씬마다 다른 옷을 고르는 기능은? 3) 시트에 필요한 모델 조건은?

정답: 1) 정면·측면·후면·표정(웃음·화남·슬픔·놀람) 2) 의상(`의상 추가`, 스토리보드 `변형 선택`) 3) 참조 이미지를 받는 모델

**응용 과제** — 도윤에게 ‘비에 젖은 코트’ 의상을 추가하고 씬 2에만 쓰도록 계획해 보세요.
