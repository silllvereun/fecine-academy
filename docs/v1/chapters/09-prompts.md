# 9장 프롬프트가 결과를 바꾸는 방식

<ChapterGoals />

::: info 이 장의 예제
이 책은 예제 작품 「비 오는 정류장」을 이어서 만듭니다. 비 오는 밤, 우산 없는 수아에게 처음 보는 도윤이 우산을 건네는 15초짜리 영상(장면 3개)입니다. FECINE을 아직 써 보지 않았다면 화면 따라 하기는 건너뛰고 개념과 표만 읽어도 됩니다.
:::

## WHY — 어떻게 쓰면 원하는 그림에 가까워질까요?

8장에서 본 것처럼 AI는 빈칸을 ‘흔한 모습’으로 채웁니다. 프롬프트(AI에게 무엇을 만들지 글로 알려 주는 지시문)는 그 빈칸을 줄이는 일입니다. 길게 쓰는 것보다 빠짐없이, 눈에 보이는 말로 쓰는 것이 핵심입니다.

- 좋은 프롬프트의 다섯 요소를 안다.
- FECINE `프롬프트` 탭의 구조 칸에 나눠 쓴다.
- 하나의 장면을 세 가지 프롬프트로 써 보고 차이를 비교한다.

**완성 결과물** — 장면 1 프롬프트 변형 3종(단순·구조화·과잉)

## HOW — 프롬프트의 구성

### 다섯 요소

| 요소 | 답하는 질문 | FECINE `프롬프트` 탭 칸 | 예제 |
| --- | --- | --- | --- |
| 주체 | 누가, 무엇을 하나? | `주체` | 20대 여성 수아가 우산 없이 서 있다 |
| 장소·소품 | 어디서, 무엇과? | `세트 디테일` | 비 오는 도시 버스 정류장, 젖은 아스팔트 |
| 빛·분위기 | 어떤 빛, 어떤 기분? | `조명·분위기` | 가로등 빛이 번짐, 차분하고 쓸쓸함 |
| 스타일 | 어떤 그림체? | `스타일·품질` | 영화 같은 실사 |
| 카메라 | 어떻게 보여줄까? | `카메라` 탭(또는 프롬프트 안에) | 멀리서 천천히 다가감 |

그 밖의 지시는 `기타` 칸에, 콘티 이미지를 따르게 하려면 `콘티 참조` 칸에 씁니다.

### 좋은 프롬프트의 규칙 다섯

1. **눈에 보이는 말로** — ‘슬픈 분위기’보다 ‘고개를 숙인, 차가운 푸른 빛’
2. **한 장면에 행동 하나** — 여러 행동은 샷이나 장면으로 나눕니다.
3. **하지 말아야 할 것보다 해야 할 것을** — ‘사람이 없는’보다 ‘테이블 위에 커피잔만 놓인’
4. **화면에 글자를 넣지 않기** — 글자는 잘 깨집니다. 제목은 편집의 `제목 카드`로 넣습니다.
5. **한 가지는 한 곳에만** — 카메라는 `카메라` 탭, 스타일은 `스타일` 탭이나 프롬프트 중 한 곳에만 씁니다.

### FECINE에서 하기 — `프롬프트` 탭

1. 스토리보드에서 장면을 고르고 `프롬프트` 탭을 엽니다.
2. `구조` 보기에서 칸마다 나눠 씁니다. `텍스트` 보기로 바꾸면 한 덩어리 문장으로 볼 수 있습니다.
3. `@`를 입력하면 연결된 캐릭터·배경·소품·콘티를 고를 수 있습니다. 예) `@수아`
4. 스토리 원고가 있다면 `원고로 프롬프트 만들기` → `프롬프트 만들기` → `프롬프트에 적용`으로 초안을 받을 수 있습니다. `권장 길이`도 함께 정해집니다.

::: info NOTE
`카메라`·`스타일` 탭에서 고른 항목은 생성할 때 프롬프트 끝에 문장으로 붙습니다. 모델마다 받을 수 있는 길이가 정해져 있어, 합친 길이가 넘으면 ‘입력 길이 초과’ 안내가 나옵니다.
:::

## PRACTICE — 세 가지 프롬프트 비교

같은 장면 1을 세 가지로 씁니다.

**A. 단순** — 빈칸이 많아 결과가 크게 흔들립니다.

```text
비 오는 정류장의 여자
```

**B. 구조화(권장)** — `구조` 칸에 나눠 씁니다.

```text
주체        : @수아 가 우산 없이 어깨를 움츠린 채 버스를 기다린다.
세트 디테일 : 밤의 도시 버스 정류장. 빗물에 젖은 아스팔트, 유리 가림막에 맺힌 빗방울.
조명·분위기 : 가로등 빛이 바닥에 번진다. 차분하고 쓸쓸한 분위기.
스타일·품질 : (비움 — 작품 스타일 실사 · 시네마틱을 따름)
카메라 탭   : 와이드 · 푸시 인
```

**C. 과잉** — 지시가 서로 부딪히고 길이가 넘칩니다.

```text
초고화질 8K 최고 품질 걸작 영화 같은 웹툰 느낌의 실사 여성이 슬프고 외롭고 행복한 표정으로
비 오는 정류장에서 뛰다가 멈추고 우산을 펴고 전화를 하며, 카메라는 클로즈업과 드론 샷을 동시에…
```

B가 좋은 이유를 적어 보세요. (예: 행동이 하나다 / 장소와 빛이 눈에 보인다 / 스타일과 카메라를 한 곳에만 썼다)

::: cost COST · 비용
프롬프트를 쓰는 것은 무료입니다. `원고로 프롬프트 만들기`와 `AI 어시스턴트`는 텍스트 AI를 쓰므로 소량의 크레딧이 듭니다.
:::

## REVIEW — 제대로 했나요?

- [ ] 프롬프트 다섯 요소를 말할 수 있다.
- [ ] `구조` 칸에 나눠 쓸 수 있다.
- [ ] 프롬프트 C의 문제점 세 가지를 찾았다.

| 자주 겪는 실패 | 원인 | 해결 |
| --- | --- | --- |
| ‘입력 길이 초과’ | 프롬프트 + 카메라 + 스타일 문장이 모델 한도를 넘음 | 프롬프트를 줄이거나 룩을 덜 고르기 |
| 화면에 이상한 글자·워터마크 | 프롬프트에 화면 글자가 들어 있음 | 글자 지시를 빼고 대사는 대사 칸에만 |
| 스타일이 섞임 | `스타일·품질` 칸과 작품 스타일이 다름 | 한쪽만 남기기 |

**확인 문제** 1) 장소와 소품을 쓰는 칸은? 2) 프롬프트에서 캐릭터를 불러오는 기호는? 3) 제목 글자는 어디서 넣나요?

정답: 1) `세트 디테일` 2) `@` 3) 편집의 `제목 카드`

**응용 과제** — 장면 2(건네진 우산)를 B 형식으로 직접 써 보세요. 행동은 하나만 넣습니다.
