# 13장 크레딧과 비용 계산

<ChapterGoals />

::: info 이 장의 예제
이 책은 예제 작품 「비 오는 정류장」을 이어서 만듭니다. 비 오는 밤, 우산 없는 수아에게 처음 보는 도윤이 우산을 건네는 15초짜리 영상(씬 3개)입니다. FECINE을 아직 써 보지 않았다면 화면 따라 하기는 건너뛰고 개념과 표만 읽어도 됩니다.
:::

## WHY — 내 작품은 얼마가 들까요?

AI 제작은 촬영비 대신 생성비가 듭니다. 씬 하나, 재생성 한 번이 모두 크레딧입니다. 미리 계산하면 중간에 크레딧이 떨어져 멈추는 일을 막을 수 있습니다.

- 크레딧이 드는 작업과 들지 않는 작업을 구분한다.
- 예상 비용과 실제 정산의 차이를 안다.
- `크레딧 · 사용량` 화면을 읽고 크레딧을 충전할 수 있다.

**완성 결과물** — 「비 오는 정류장」 예산표

## HOW — 크레딧의 구조

### 단위와 차감 방식

- FECINE의 모든 AI 기능은 **크레딧** 하나로 결제합니다. 구독료는 없고 쓴 만큼 차감됩니다.
- 생성 버튼은 `생성 · 0.04 크레딧`처럼 **「생성 · 예상 크레딧」** 모양으로 통일되어 있고, 예상치는 모델 목록에도 `예상 {n} 크레딧`으로 보입니다. 실제 차감은 `실제 사용량으로 정산`됩니다.
- 이미지 후보는 실제로 받은 장수만큼만 차감됩니다. 후보 일부만 만들어지면 “후보 {n}장은 만들었지만 나머지는 만들지 못했어요. 만들지 못한 후보는 크레딧이 차감되지 않았어요.”가 보입니다.
- 내보내기 요금은 시작할 때 잡아 두고 영상이 전달되면 차감되며, 전달되지 않으면 모두 돌려받습니다.
- 가입 혜택 같은 무상 크레딧이 먼저 쓰입니다.
- 단가·충전 수량·추가 지급·가입 혜택은 버전마다 바뀔 수 있어 부록 A에 둡니다.

### 무료와 유료

| 무료 | 유료 |
| --- | --- |
| 스토리·씬 직접 작성, 씬 합치기·직접 나누기, 카메라·스타일 설정 | AI 어시스턴트(씬 추가·대본 쓰기·다듬기·씬 나누기), 에피소드·씬 추출, 등장 요소 만들기, 촬영 설계 만들기, 영상 프롬프트 만들기 |
| 편집 전부(트림·전환·자막·색보정·음악) | 이미지 생성(등장인물·배경·소품·샷 이미지·캐릭터 시트) |
| 내 파일 업로드, `영상 넣기` | 씬 영상 생성, 공개 캐릭터·목소리를 작품에 추가(추가할 때마다) |
| 씬 영상 `로고 포함 다운로드 · 무료` | 합친 영상 내보내기, 로고 제거, 씬 영상 `로고 없이 다운로드`(받을 때마다), 로고 없는 편집 프로젝트 받기(한 번) |

### 예산 식

```text
예상 크레딧 = (씬 수 × 씬당 예상 크레딧 × 생성 횟수)
            + 이미지 생성 예상치 + 내보내기 요금
```

생성 횟수는 처음에는 씬당 2회로 잡는 것이 안전합니다. 씬당 예상 크레딧은 `모델` 탭에서 읽습니다. 모델별 단가는 공개 메뉴 `모델·가격`에서 봅니다. `모델 종류` 탭(텍스트·이미지·영상)별로 `제공사`·`유형`을 거르고 `정렬`(`가격 낮은 순`·`가격 높은 순`·`이름 순`)을 바꿀 수 있습니다. 모델 목록은 예상 크레딧이 낮은 순으로 보이며, 같은 모델이 여러 `경로`(Standard · Enterprise · Global)로 있으면 경로마다 가격이 다르고, 공식 API 가격보다 싼 모델에는 `↓` 할인율이 붙습니다([12장](/v1/chapters/12-choosing-models)).

### FECINE에서 하기 — 잔액·사용량·충전

1. 사이드 메뉴 아래 `크레딧 잔액`에서 남은 크레딧을 봅니다. 충전할 수 있는 사람에게는 `크레딧 구매`가 보입니다.
2. 아바타 메뉴 > `설정` > `사용량·결제`를 누르면 `크레딧 · 사용량` 화면이 열립니다. 잔액 카드에서 `현재 잔액`·`이번 달 사용`·`누적 획득`·`누적 사용`을 봅니다.
3. 아래 탭에서 `사용 내역`(언제·무엇에 썼는지), `작품별`(작품마다 쓴 크레딧), `결제 내역`(충전 기록)을 봅니다. `사용 내역` 표는 한 줄에 한 건씩 `시간`·`내용`·`작품·범위`·`종류`·`모델`·`사용량`·`상태`(`보류`·`정산됨`·`환불됨`)·`크레딧`으로 나뉘고, 위의 `기간`·`종류`로 거를 수 있습니다. 이 화면에는 모델 가격표가 없습니다. 단가는 `모델·가격`에서 봅니다.
4. 잔액 카드의 `크레딧 충전`을 누르면 오른쪽에 `크레딧 충전` 패널이 열립니다. 패널은 **두 단계**입니다.
   - **1단계**: `얼마나 충전할까요?`에서 수량 버튼을 고르거나 `직접 입력`으로 적고, 결제 수단(`카드·간편결제` · `무통장입금` · `PayPal`)을 고릅니다. 아래에 `받는 크레딧`(추가 지급분 포함)과 `결제 금액`이 보이고, 금액 옆 ⓘ(`결제 금액 안내`)를 누르면 `적용 환율`·기준·계산식과 PayPal 수수료가 나옵니다. 주문할 때의 환율로 금액이 고정됩니다. 준비가 되면 `다음`을 누릅니다.
   - **2단계**: 결제 수단에 필요한 정보를 적습니다(카드는 휴대폰 번호, 무통장은 `입금자명`). `만 19세 이상입니다.`에 체크하고 `결제` · `입금 안내 받기` · `PayPal로 결제` 중 하나를 누릅니다. 1단계로 돌아가려면 `이전`을 누릅니다.
5. 결제는 별도의 결제 서비스(FEPAY)가 처리합니다. 예전 결제 방식(포트원·페이액션 직접 결제)은 v1.82.0에서 없어졌고, 보이는 결제 수단은 운영 설정에 따라 다를 수 있습니다.
6. `무통장입금`은 `입금 안내 받기` 뒤에 안내된 계좌로 **안내된 이름과 정확한 금액**을 입금하면 자동으로 확인되어 충전됩니다. 패널을 닫아도 잔액 카드에 ‘입금 대기’로 남고, `입금 안내 다시 보기 (계좌 · QR)`로 다시 열 수 있습니다. 아직 입금하지 않은 주문은 입금 안내 화면이나 `결제 내역` 탭의 `주문 취소`로 취소할 수 있습니다.

::: info NOTE
충전은 개인 스튜디오는 **소유자**, 회사 스튜디오는 **기업관리자**만 할 수 있습니다. 회사 스튜디오 충전은 결제 금액에 **부가세 10%**가 더해지고(ⓘ에 `공급가액`·`부가세 10%` 표시), 무통장입금이 확인되면 회사 앞으로 세금계산서가 발행됩니다. 보이는 결제 수단과 충전 화면은 운영 설정에 따라 다를 수 있습니다 <Badge type="warning" text="확인 필요" />. 무통장 주문은 입금 기한이 지나면 자동으로 취소됩니다(기한은 입금 안내에 표시).
:::

::: warning 주의
탈퇴할 때는 **유상 잔액**(충전한 크레딧)이 남아 있는지 확인합니다. 가입 혜택 같은 무상 크레딧만 남았다면 탈퇴할 수 있고, 충전한 잔액이 있으면 환불을 받은 뒤 탈퇴하는 순서입니다. 세부 기준은 이용약관을 확인하세요.
:::

::: cost COST · 비용
계산은 무료입니다. 합계가 잔액보다 크면 씬 수나 재생성 횟수, 샷 이미지 `장수`를 줄이거나, 테스트는 짧고 낮은 해상도로 합니다.
:::

## REVIEW — 제대로 했나요?

- [ ] 무료 작업 세 가지와 유료 작업 세 가지를 말할 수 있다.
- [ ] `크레딧 · 사용량`의 `작품별` 탭에서 작품마다 쓴 크레딧을 찾을 수 있다.
- [ ] 예산표를 채웠다.

| 자주 겪는 실패 | 화면 문구 | 해결 |
| --- | --- | --- |
| 생성이 안 됨 | 크레딧이 부족합니다. 충전 후 다시 생성하세요. | `충전하기` |
| 충전 버튼이 없음 | 크레딧 충전은 워크스페이스 소유자만 할 수 있습니다. … | 소유자(회사 스튜디오는 기업관리자)에게 요청 |
| 입금했는데 충전 안 됨 | 입금자명이나 금액이 다르면 자동 확인되지 않습니다. | 이름·금액 확인 후 고객센터 문의 |
| 새 무통장 주문 불가 | 입금을 기다리는 주문이 이미 있습니다. … | 기존 주문 입금 또는 `주문 취소` |
| 결제가 진행되지 않음 | 만 19세 이상 확인에 체크해 주세요. | 2단계에서 `만 19세 이상입니다.`에 체크 |
| 원화 결제가 안 됨 | 오늘 환율을 아직 받지 못해 원화 결제를 할 수 없어요. | 잠시 뒤 다시 시도 |

**확인 문제** 1) 내보내기 영상이 전달되지 않으면 크레딧은? 2) 작품마다 얼마나 썼는지 보는 곳은? 3) 무통장입금이 자동 확인되려면 무엇이 맞아야 하나요?

정답: 1) 잡아 둔 크레딧을 모두 돌려받는다(차감되지 않는다) 2) `크레딧 · 사용량` 화면의 `작품별` 탭 3) 입금자명과 금액

**응용 과제** — 예산표의 합계를 절반으로 줄여야 한다면 무엇부터 줄일지 세 가지를 적어 보세요.
