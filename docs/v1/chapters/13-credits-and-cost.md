# 13장 크레딧과 비용 계산

<ChapterGoals />

::: info 이 장의 예제
이 책은 예제 작품 「비 오는 정류장」을 이어서 만듭니다. 비 오는 밤, 우산 없는 수아에게 처음 보는 도윤이 우산을 건네는 15초짜리 영상(장면 3개)입니다. FECINE을 아직 써 보지 않았다면 화면 따라 하기는 건너뛰고 개념과 표만 읽어도 됩니다.
:::

## WHY — 내 작품은 얼마가 들까요?

AI 제작은 촬영비 대신 생성비가 듭니다. 장면 하나, 재생성 한 번이 모두 크레딧입니다. 미리 계산하면 중간에 크레딧이 떨어져 멈추는 일을 막을 수 있습니다.

- 크레딧이 드는 작업과 들지 않는 작업을 구분한다.
- 예상 비용과 실제 정산의 차이를 안다.
- `사용량` 화면을 읽고 크레딧을 충전할 수 있다.

**완성 결과물** — 「비 오는 정류장」 예산표

## HOW — 크레딧의 구조

### 단위와 차감 방식

- FECINE의 모든 AI 기능은 **크레딧** 하나로 결제합니다. 구독료는 없고 쓴 만큼 차감됩니다.
- 생성 버튼 옆에는 **예상치**(`약 {n} 크레딧`, `예상 {cost}`)가 보이고, 실제 차감은 `실제 사용량으로 정산`됩니다.
- 내보내기는 완성 영상이 전달될 때 한 번만 차감되고, 실패하면 차감되지 않습니다.
- 단가·충전 패키지·가입 혜택은 버전마다 바뀔 수 있어 부록 A에 둡니다.

### 무료와 유료

| 무료 | 유료 |
| --- | --- |
| 스토리·장면 직접 작성, 카메라·스타일 설정 | AI로 쓰기·다듬기, AI 구성, AI 어시스턴트 |
| 편집 전부(트림·전환·자막·색보정·음악) | 이미지 생성(캐릭터·배경·장면 프레임·캐릭터 시트) |
| 내 파일 업로드, `영상 넣기` | 장면 영상 생성 |
| 장면 영상 `로고 포함 다운로드` | 합친 영상 내보내기, 로고 제거, 장면 영상 `로고 없이 다운로드`(받을 때마다) |

### 예산 식

```text
예상 크레딧 = (장면 수 × 장면당 예상 크레딧 × 생성 횟수)
            + 이미지 생성 예상치 + 내보내기 요금
```

생성 횟수는 처음에는 장면당 2회로 잡는 것이 안전합니다. 장면당 예상 크레딧은 `모델` 탭에서 읽습니다.

### FECINE에서 하기 — 잔액·사용량·충전

1. 사이드 메뉴 아래 `크레딧 잔액`에서 남은 크레딧을 봅니다.
2. 아바타 메뉴 > `설정` > `사용량·결제`에서 `현재 잔액`·`누적 획득`·`누적 사용`, `작품별 사용`, 잔액 변동 내역을 봅니다.
3. 충전은 `크레딧 구매`를 누르고 패키지를 고릅니다. 충전은 **워크스페이스 소유자만** 할 수 있습니다.
4. 결제수단으로 `무통장입금`을 고르면 `입금자명`을 적고 `입금 안내 받기`를 누릅니다. 안내된 계좌로 **안내된 이름과 정확한 금액**을 입금하면 자동으로 확인되어 충전됩니다.
5. 창을 닫아도 패키지 위 `입금 대기 중` 띠의 `입금 안내 보기`로 다시 열 수 있습니다. 입금이 확인되면 ‘결제 완료’ 창이 뜹니다.

::: info NOTE
카드 결제는 운영 설정에 따라 보이지 않을 수 있습니다. 무통장 주문은 한 번에 하나만 진행되며, 입금 기한이 지나면 취소됩니다(기한은 입금 안내에 표시).
:::

빈칸을 채우세요. 단가는 `모델` 탭의 예상치나 부록 A를 씁니다.

| 항목 | 수량 | 단가(크레딧) | 소계 |
| --- | --- | --- | --- |
| 캐릭터 대표 이미지(수아·도윤) | 2명 × 후보 2장 |  |  |
| 캐릭터 시트(수아) | 1세트 |  |  |
| 배경·소품 | 2장 |  |  |
| 장면 프레임 후보 | 3장면 × 4장 |  |  |
| 장면 영상 | 3장면 × 2회 |  |  |
| 내보내기 | 1회 |  |  |
| **합계** |  |  |  |

::: cost COST · 비용
계산은 무료입니다. 합계가 잔액보다 크면 장면 수나 재생성 횟수를 줄이거나, 테스트는 짧고 낮은 해상도로 합니다.
:::

| 자주 겪는 실패 | 화면 문구 | 해결 |

| 충전 버튼이 없음 | 크레딧 충전은 워크스페이스 소유자만 할 수 있습니다. | 소유자에게 요청 |

| 새 무통장 주문 불가 | 입금을 기다리는 주문이 이미 있습니다. | 기존 주문 입금 또는 취소 |

**확인 문제** 1) 내보내기가 실패하면 크레딧은? 2) 작품마다 얼마나 썼는지 보는 곳은? 3) 무통장입금이 자동 확인되려면 무엇이 맞아야 하나요?

정답: 1) 차감되지 않는다 2) `사용량·결제`의 `작품별 사용` 3) 입금자명과 금액
