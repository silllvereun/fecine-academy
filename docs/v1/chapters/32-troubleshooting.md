# 32장 초보자가 겪는 실패 상황

<ChapterGoals />

## WHY

> 버튼을 눌렀는데 아무 일도 일어나지 않거나, 빨간 문구가 떴습니다. 어디부터 봐야 할까요?

- 막혔을 때 확인하는 순서 5단계를 익힙니다.
- **AI 작업**과 **알림**에서 진행·실패를 확인합니다.
- 자주 보는 화면 문구와 해결 방법을 한 장으로 정리합니다.

**완성 결과물** 문제 해결 카드 (한 장 요약)

## HOW

### 확인 순서 5단계

| 단계 | 볼 곳 | 확인할 것 |
| --- | --- | --- |
| 1 문구 읽기 | 버튼 근처, 화면 아래 알림 | 무엇을 하라고 말하는지. 대부분 문구가 해결 방법을 알려 줌 |
| 2 AI 작업 | 상단 **AI 작업 보기** | **진행 중**인지, **최근**에 **실패**로 남았는지, **오류 세부 정보** |
| 3 알림 | 상단 **알림 열기** | 렌더링 실패, 동료의 댓글·잠금 |
| 4 크레딧 | **크레딧 · 사용량**의 잔액·사용 내역 | 잔액이 충분한지, 차감이 보류인지 |
| 5 환경 | 브라우저·인터넷·권한 | PC의 최신 Chrome·Edge인지, 편집 권한이 있는 크루인지 |

5단계까지 확인해도 해결되지 않으면 **AI 작업**의 **오류 세부 정보**를 **복사**해 강사나 관리자에게 전달합니다.

### FECINE에서 하기 — AI 작업 보기

1. 상단의 **AI 작업 보기**를 누릅니다.
2. **진행 중**에서 `대기 중 · 경과 시간`, `생성 중 · 경과 시간`을 봅니다. 차례를 기다리는 요청에는 앞선 요청이 끝나면 바로 시작한다는 안내가 보입니다. 필요 없는 작업은 **작업 취소**합니다.
3. **최근**에서 `실패 · 걸린 시간` 항목을 열고 **오류 세부 정보**를 읽습니다.

**[캡처 32-01]** <Badge type="warning" text="캡처 준비 중" /> AI 작업 — ① 진행 중 ② 최근 ③ 실패 항목 ④ 오류 세부 정보 ⑤ 복사

::: info NOTE
**작업 취소**는 요청이 AI 회사(제공자)에 접수되기 전, 또는 접수 여부를 알 수 없을 때만 할 수 있습니다. 제공자가 이미 만들기 시작한 작업은 중간에 멈출 수 없으니 끝날 때까지 기다립니다. 접수 여부를 알 수 없는 영상 요청은 2시간이 지나면 과금 없이 자동으로 종료됩니다.
:::

::: tip TIP
실수로 지운 씬·이미지·오디오·등장인물·배경·소품·콘티는 **작품정보**의 **휴지통**에서 7일 동안 **복원**할 수 있습니다. 씬을 합치면서 사라진 씬도 같은 곳에 보관됩니다. 남은 날짜가 `n일 남음`으로 표시됩니다. 작품을 통째로 지웠다면 **설정**의 **휴지통**에서 30일 안에 복원합니다.
:::

## PRACTICE

**문제 해결 카드** — 아래 표를 한 장으로 출력해 모니터 옆에 둡니다.

| 분류 | 화면 문구 | 해결 | 장 |
| --- | --- | --- | --- |
| 크레딧 | 크레딧이 부족합니다. 충전 후 다시 생성하세요. | **충전하기** / 소유자에게 요청 | 31 |
| 크레딧 | 크레딧 충전은 워크스페이스 소유자만 할 수 있습니다. | 소유자에게 충전 요청 | 31 |
| 권한 | 영상을 생성할 권한이 없습니다. / 이 작품을 편집할 권한이 없습니다 | 작품 소유자에게 편집 권한 요청 | 16 |
| 모델 | 이 워크스페이스에 구성된 영상 모델이 아직 없습니다. | 관리자에게 모델 구성 요청 | 12 |
| 모델 | 이전에 선택한 모델을 사용할 수 없어요. | 다른 모델 직접 선택 | 12 |
| 모델 | 선택한 모델이 지원하는 해상도와 길이를 다시 선택해 주세요. | 지원하는 값으로 다시 선택 | 27 |
| 프롬프트 | 입력 길이 초과 | 프롬프트 줄이기 / 룩 덜 고르기 / 다른 모델 | 25, 27 |
| 참조 | 일부 @ 참조에 아직 이미지가 없습니다 | 참조 이미지 먼저 생성 | 24 |
| 참조 | 이 모델은 이미지를 1장만 받아요. | **샷 이미지 만들기** | 26 |
| 참조 | 이 모델은 참조 음성을 사용할 수 없어요. | 음성을 받는 모델 선택 | 23 |
| 생성 | 이 씬의 영상이 이미 생성 중입니다. | 끝날 때까지 기다림 | 27 |
| 생성 | 앞선 작업 요청이 끝나면 바로 시작해요. | 그대로 기다림 (차례가 오면 자동 시작) | 27 |
| 생성 | 생성 실패 | **재시도**, 반복되면 프롬프트·모델 변경 | 27 |
| 생성 | 이 실패는 그대로 재시도할 수 없습니다. | 다른 프롬프트나 모델 사용 | 20 |
| 생성 | 이 캐릭터의 이전 생성 결과를 확인하지 못했어요. | **이전 생성 취소** 후 다시 만들기 (크레딧 차감 없음) | 20 |
| 이미지 | 최근 오류가 잦아요 (모델 옆 표시) | 다른 이미지 모델 선택 | 26 |
| 생성 | 영상 렌더링 중…이 오래 지속 | **상태 다시 가져오기** (추가 과금 없음) | 27 |
| 편집 | 이 브라우저에서 재생할 수 없는 클립 n개는 검은 화면으로 보입니다. | Chrome·Edge에서 열기 | 28 |
| 편집 | 삭제된 씬 | 휴지통에서 **복원** 또는 클립 빼기 | 28 |
| 내보내기 | 이 브라우저에서는 내보낼 수 없습니다. | PC의 최신 Chrome·Edge·Safari | 30 |
| 내보내기 | 구간을 만들거나 올리지 못했습니다. | **이어서 진행** | 30 |
| 내보내기 | 아직 편집한 내용이 없습니다. | 편집본 저장 후 다시 | 28, 30 |
| 작업 중 | 이 작품에서 작업이 진행 중이에요. 끝난 뒤 … | AI 작업이 끝날 때까지 기다렸다가 다시 | 32 |
| 게시 | 이미 검토가 시작되어 취소할 수 없습니다. | 검토 결과를 기다림 | 30 |

::: cost COST · 비용
문제를 확인하는 것은 모두 무료입니다. 다만 원인을 모른 채 **재시도**를 여러 번 누르면 그때마다 비용이 들 수 있습니다. 두 번 같은 실패가 나면 멈추고 5단계를 확인하세요.
:::

## REVIEW

- [ ] 확인 순서 5단계를 외우고 있다.
- [ ] **AI 작업**에서 실패 항목의 오류 세부 정보를 복사할 수 있다.
- [ ] 휴지통에서 항목을 복원해 봤다.
- [ ] 문제 해결 카드를 출력했다.

**확인 문제**

1. 영상 생성이 계속 ‘영상 렌더링 중…’입니다. 비용을 더 쓰지 않고 할 수 있는 일은?
2. 어제 지운 씬을 되살리려면 어디로 가나요?
3. 같은 실패가 두 번 나왔을 때 가장 먼저 할 일은?

정답: 1. **상태 다시 가져오기**. 2. 작품정보의 휴지통(7일 이내). 3. 재시도를 멈추고 문구 → AI 작업 → 알림 → 크레딧 → 환경 순서로 확인한다.

**응용 과제** 지금까지 실습하면서 실제로 겪은 문제 하나를 골라, 화면 문구·확인한 단계·해결 방법을 문제 해결 카드에 한 줄로 더해 보세요.
