# 31장 크레딧 아끼는 제작 습관

<ChapterGoals />

## WHY

> 다 만들고 보니 예상보다 크레딧을 훨씬 많이 썼습니다. 어디서 새었을까요?

- 무료 작업과 유료 작업을 구분합니다.
- 작품 하나의 예산을 미리 계산하고, **크레딧 · 사용량** 화면에서 실제 사용과 비교합니다.
- 크레딧을 아끼는 제작 순서를 습관으로 만듭니다.

**완성 결과물** 내 작품 예산 점검표

## HOW

### 무료와 유료

| 무료 | 유료 (크레딧 차감) |
| --- | --- |
| 스토리에서 직접 씬 대본 쓰기, 씬 합치기·나누기·옮기기 | AI로 쓰기·다듬기, AI로 씬 나누기, 씬 대본으로 프롬프트 만들기, 영상 프롬프트 만들기 (텍스트 모델) |
| 등장인물·배경·소품 설명 쓰기, 이미지 올리기 | AI 자동생성 (에피소드·씬 추출, 제작설계 만들기) |
| 카메라·스타일 지정 | 이미지 생성 (등장인물·배경·소품·콘티·샷 이미지) |
| 가진 영상을 **테이크로 넣기** | 영상 생성 (테이크마다) |
| **상태 다시 가져오기** | 작품 내보내기 |
| 편집·자막·카드·색보정 | 로고 없이 내보내기·씬 다운로드, 편집 프로젝트 받기(로고가 들어가는 환경) |
| 로고 포함 씬 다운로드 | 공개 캐릭터·목소리를 작품에 추가 (사용료) |

### 예산 식

요금표는 종류마다 단위가 다릅니다: 텍스트 모델은 **크레딧/100만 토큰**, 이미지 모델은 **크레딧/장**, 비디오 모델은 **크레딧/초**. FECINE에서는 1 크레딧 = USD 1입니다. 토큰은 AI가 글을 셀 때 쓰는 작은 조각으로, 대략 단어 하나나 글자 몇 개 정도입니다.

```text
영상 예산 = 씬 수 × 씬 길이(초) × 초당 단가 × 씬당 테이크 수
이미지 예산 = 만들 이미지 장수 × 장당 단가
작품 예산 = 영상 예산 + 이미지 예산 + 텍스트·AI 자동생성 비용 + 내보내기 요금
```

가장 큰 변수는 **테이크 수**입니다. 씬당 테이크가 1개에서 3개로 늘면 영상 예산은 그대로 3배가 됩니다.

### 아끼는 순서 6가지

1. **글로 먼저 끝낸다.** 씬 대본·씬 구성·카메라를 무료 단계에서 충분히 정합니다.
2. **이미지로 확인하고 영상으로 넘어간다.** 샷 이미지는 영상보다 훨씬 싸고, 영상의 실패를 줄여 줍니다. 후보 **장수**를 필요한 만큼만 고르면 더 아낄 수 있고, 후보는 실제로 받은 장만 차감됩니다.
3. **짧고 낮게 테스트한다.** 방향을 잡을 때는 짧은 길이·낮은 해상도로, 확정할 때만 올립니다.
4. **한 번에 하나만 바꾼다.** 여러 가지를 한꺼번에 바꾸면 원인을 모른 채 테이크만 늘어납니다(27장).
5. **다시 만들기 전에 편집을 생각한다.** 앞뒤 어색함은 트림, 색 차이는 색보정으로 무료로 고칩니다.
6. **로고 없이는 마지막에 한 번.** 로고 없는 씬 다운로드는 다시 받을 때마다 다시 차감됩니다.

### FECINE에서 하기 — 사용량 확인

1. 계정 메뉴의 **설정** > **사용량·결제**(또는 사이드 아래 크레딧 잔액 카드)로 **크레딧 · 사용량** 화면을 엽니다.
2. 잔액 카드에서 **현재 잔액**, **이번 달 사용**, **누적 획득**, **누적 사용**을 봅니다.
3. **작품별** 탭에서 작품마다 **이미지**·**영상**·**텍스트**·**합계**를 확인합니다.
4. **사용 내역** 탭(크레딧이 들어오고 나간 기록, 원장)에서 항목별로 **시간 / 콘텐츠 / 범위 / 크레딧 / 모델 / 멤버**를 봅니다. 상태는 **보류**(진행 중이라 잠시 잡아 둠), **정산됨**(차감 확정), **환불됨**(실패 등으로 돌려받음)입니다. 항목의 **계산 방식**에서 단가×수량을 확인할 수 있습니다.
5. 모자라면 **크레딧 충전**으로 충전합니다. 충전은 워크스페이스 소유자(회사 스튜디오는 기업관리자)만 할 수 있습니다. 모델별 단가는 **모델 가격표**에서 봅니다.

## REVIEW

- [ ] 무료·유료 작업을 구분할 수 있다.
- [ ] 영상 예산 식에서 가장 큰 변수가 무엇인지 안다.
- [ ] **사용 내역**의 보류·정산됨·환불됨을 구분할 수 있다.
- [ ] 예산 점검표를 채웠다.

| 상황 | 화면 문구 | 해결 |
| --- | --- | --- |
| 잔액 부족 | 크레딧이 부족합니다. 충전 후 다시 생성하세요. | **충전하기** 또는 소유자에게 요청 |
| 충전이 안 됨 | 크레딧 충전은 워크스페이스 소유자만 할 수 있습니다. | 소유자(회사 스튜디오는 기업관리자)에게 충전 요청 |
| 실패했는데 차감된 것 같음 | (사용 내역에 보류) | 작업이 끝나면 정산됨 또는 환불됨으로 바뀜. 잠시 후 다시 확인 |
| 같은 씬을 계속 재생성 | (테이크가 계속 늘어남) | 테이크 피드백으로 원인을 하나 고르고 그것만 바꿈 |

**확인 문제**

1. 씬 4개, 5초, 씬당 테이크 2개일 때 생성하는 영상은 모두 몇 초인가요?
2. 사용 내역의 ‘보류’는 무엇을 뜻하나요?
3. 샷 이미지를 먼저 만들면 비용이 어떻게 줄어드나요?

정답: 1. 4 × 5 × 2 = 40초. 2. 작업이 진행 중이라 크레딧을 잠시 잡아 둔 상태. 끝나면 정산되거나 환불된다. 3. 싼 이미지로 구도·인물을 먼저 확정해 비싼 영상의 재생성 횟수를 줄인다.

**응용 과제** 실습 1–3 중 하나를 골라 예산 점검표를 미리 채우고, 제작 후 사용 내역과 비교해 다음 작품에서 바꿀 습관 한 가지를 적어 보세요.
