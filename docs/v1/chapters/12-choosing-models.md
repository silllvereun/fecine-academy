# 12장 모델을 고르는 7가지 기준

<ChapterGoals />

::: info 이 장의 예제
이 책은 예제 작품 「비 오는 정류장」을 이어서 만듭니다. 비 오는 밤, 우산 없는 수아에게 처음 보는 도윤이 우산을 건네는 15초짜리 영상(장면 3개)입니다. FECINE을 아직 써 보지 않았다면 화면 따라 하기는 건너뛰고 개념과 표만 읽어도 됩니다.
:::

## WHY — 모델이 여럿인데 무엇을 골라야 할까요?

영상 모델은 카메라 렌즈와 비슷합니다. 각자 잘하는 일과 한계가 있고, 새 모델은 계속 나옵니다. 그래서 모델 이름을 외우기보다 **고르는 기준**을 아는 편이 오래 쓸모 있습니다.

- 모델을 고르는 일곱 가지 기준을 안다.
- FECINE `모델` 탭에서 각 기준을 확인하는 위치를 안다.
- 목적별 모델 선택표를 만든다.

**완성 결과물** — 목적별 모델 선택표(테스트용·최종용·세로 영상·대사 장면)

## HOW — 일곱 가지 기준

| 기준 | 질문 | FECINE에서 확인하는 곳 |
| --- | --- | --- |
| 1. 길이 | 이 장면은 몇 초인가? | `모델` 탭 모델별 `{최소}–{최대}초`, `길이` 선택지 |
| 2. 해상도 | 어디에 내보낼까? | `해상도` 선택지(모델이 지원하는 것만 보임) |
| 3. 화면 비율 | 가로인가 세로인가? | 작품 `화면 비율`과 모델의 지원 비율(부록 A). 틀리면 비율 오류 |
| 4. 참조 이미지 수 | 등장인물·배경이 몇 개인가? | 초과 시 ‘이 모델은 참조 이미지를 {n}장만 사용할 수 있어요’ |
| 5. 음성 | 대사가 있는가? 목소리 참조가 필요한가? | `사운드`, 미지원 시 ‘이 모델은 참조 음성을 사용할 수 없어요’ |
| 6. 비용 | 얼마나 드나? | `약 {n} 크레딧`(현재 해상도·길이 기준 예상) |
| 7. 속도 | 얼마나 기다려야 하나? | `약 {시간}`(최근 완료된 작업 기준) |

모델이 회색으로 `사용 불가`이면 이 워크스페이스(내 작품과 크레딧이 모인 공간)에서 쓸 수 없는 모델입니다(`사용 안 함`, `지원 준비 중`, `요금 설정 대기`). 모델 목록은 운영 설정에 따라 달라집니다.

### 같은 모델의 ‘일반’과 ‘VIP’

v1.38.0부터 Seedance는 일반과 VIP로 나뉘어 보입니다. 길이·해상도·비율·가격은 같고, 생성을 처리하는 서버와 일부 기능이 다릅니다. 실존 인물을 쓰는 장면은 VIP를 고릅니다(11장). 그 밖의 차이는 부록 A에 둡니다.

### FECINE에서 하기 — `모델` 탭 읽기

1. 스토리보드에서 장면을 고르고 `모델` 탭을 엽니다.
2. `장면 영상 생성` 아래 모델 목록에서 각 모델의 `사용 가능` 여부, 길이 범위, `약 {n} 크레딧`, `약 {시간}`을 읽습니다.
3. 모델을 고른 뒤 `해상도`, `길이`, `사운드`(`음성 있음`/`무음`)를 정합니다. 예상 크레딧은 이 설정에 따라 바뀝니다.

**[캡처 19-01]** 모델 탭 <Badge type="warning" text="화면 확인 필요" />

::: tip TIP
‘예상 시간’에 마우스를 올리면 최근 완료된 작업 기준이며 오래 걸릴 때는 얼마까지 걸리는지 알려 줍니다. 수업 시간이 정해져 있다면 이 값으로 순서를 짭니다.
:::

## PRACTICE — 목적별 모델 선택표

기준 일곱 가지 중 무엇을 먼저 볼지 정하고, 부록 A에서 조건에 맞는 모델을 찾아 채웁니다.

| 목적 | 먼저 볼 기준 | 조건 | 내가 고른 모델 (부록 A 참고) |
| --- | --- | --- | --- |
| 구도·움직임 테스트 | 비용·속도 | 짧은 길이, 낮은 해상도가 가능하고 빠름 |  |
| 최종본 | 해상도·참조 수 | 내보낼 해상도 지원, 등장 요소를 모두 참조 |  |
| 세로(9:16) 영상 | 화면 비율 | 9:16 지원 |  |
| 대사가 있는 장면 | 음성 | 음성 생성 + 참조 음성 지원 |  |
| 긴 한 호흡 장면 | 길이 | 최대 길이가 김 |  |
| 실존 인물 등장 | 기능 | 실존 인물 인증 지원(VIP) |  |

::: cost COST · 비용
모델을 고르는 것은 무료입니다. 테스트는 싸고 빠른 조건으로, 최종본만 높은 조건으로 만들면 비용이 크게 줄어듭니다(31장).
:::

## REVIEW — 제대로 했나요?

- [ ] 모델을 고르는 일곱 가지 기준을 말할 수 있다.
- [ ] `모델` 탭에서 길이 범위·예상 크레딧·예상 시간을 읽을 수 있다.
- [ ] 목적별 선택표를 채웠다.

| 자주 겪는 실패 | 해결 |
| --- | --- |
| ‘선택한 모델이 지원하는 해상도와 길이를 다시 선택해 주세요’ | 모델을 바꾼 뒤 해상도·길이를 다시 고르기 |
| ‘이 모델은 이미지를 1장만 받아요’ | 참조를 하나만 남기거나 참조를 많이 받는 모델로 |
| 모델이 하나도 안 보임(‘이 워크스페이스에 구성된 영상 모델이 아직 없습니다’) | 관리자에게 모델 사용 설정 요청 |

**확인 문제** 1) 예상 크레딧은 무엇을 기준으로 계산되나요? 2) 실존 인물 장면에 고를 Seedance 등급은? 3) 모델 이름·수치를 확인하는 곳은?

정답: 1) 현재 고른 해상도와 길이 2) VIP 3) `모델` 탭과 부록 A

**응용 과제** — 내 작품의 장면 하나를 골라 일곱 기준 중 가장 중요한 것 두 가지를 고르고, 그 이유를 적어 보세요.
