# 15장 로그인·기본 화면·튜토리얼

<ChapterGoals />

## WHY — 처음 들어가면 무엇을 봐야 할까요?

가입은 1분이면 끝납니다. 그보다 중요한 것은 첫 화면에서 ‘어디에 무엇이 있는지’를 익히는 일입니다. 그리고 튜토리얼 작품으로 첫 영상을 빠르게 만들어 봅니다.

- Google 계정으로 가입하고 로그인한다.
- 사이드 메뉴, 상단 바, 아바타 메뉴, 크레딧 잔액의 위치를 안다.
- 튜토리얼 16단계의 안내 카드를 읽고 첫 씬 영상을 만든다.

**완성 결과물** — 튜토리얼 첫 씬 영상 (결과 15-A)

## HOW — 화면 따라 하기

### 1. 가입과 로그인

1. 홈페이지 오른쪽 위의 `로그인`(옆의 크레딧 알약은 누르면 같은 로그인 창이 열립니다), 또는 첫 화면의 시작 버튼 `내 첫 작품 시작하기`를 누릅니다.
2. `Fecine에 로그인` 창에서 `Google 계정으로 계속하기`를 누르고 Google 계정을 고릅니다.
3. 처음이라면 `이름`을 적고 `약관 동의`의 세 항목(이용약관, 개인정보처리방침, 만 14세 이상)을 체크한 뒤 `스튜디오 열기`를 누릅니다.
4. ‘OOO님의 스튜디오’가 만들어지고 `작품` 화면이 열립니다. 가입 혜택 크레딧도 함께 들어옵니다.

### 3. 튜토리얼 작품

새로 만든 개인 스튜디오에 작품이 하나도 없으면 튜토리얼 작품이 한 번 만들어집니다(이미 작품이 있던 스튜디오에는 만들어지지 않고, 운영자가 튜토리얼 원작을 공개해 둔 경우에만 생깁니다). `작품` 화면의 `첫 영상 튜토리얼` 카드에서 `환영해요 · 첫 작품을 함께 만들어봐요`라는 문구와 함께 `튜토리얼 시작 / 이어하기`를 누르면 화면 가운데에 안내 카드가 뜨고, `{현재}/16 단계`로 진행됩니다. 이 튜토리얼 작품의 공개 캐릭터 단계가 없으면 15단계입니다.

::: info NOTE
새 스튜디오의 작품은 튜토리얼을 포함해 1개만 만들 수 있게 열릴 수 있습니다(운영 설정에 따라 다릅니다). 이때 새 작품을 만들면 `워크스페이스의 작품 생성 한도에 도달했어요.`가 나옵니다. 튜토리얼 작품에서 이어서 만들거나, 한도를 넓히려면 관리자에게 요청합니다(작품을 휴지통으로 옮기면 자리가 비는지는 운영 설정에 따라 다를 수 있습니다).
:::

**단계마다 안내 카드는 한 번만** 뜹니다. 카드를 읽은 뒤에는 안내 없이 내가 직접 하고, 같은 단계에서 캐릭터를 더 넣거나 이미지를 더 만들어도 카드가 다시 뜨지 않습니다. 카드는 화면 가운데에 같은 높이로 뜨고, 안내하는 버튼이나 메뉴는 보라색 테두리로 강조됩니다. 단계는 두 종류입니다.

- **설명 카드** — 화면의 기능을 읽기만 하는 단계입니다(1·2·4·5·7·8·9·12·13·15단계). 한 문장 소개와 세 줄 이내의 설명이 있고, `다음`을 누르면 읽은 것으로 기록되어 다음 단계로 넘어갑니다. `이 화면 열어보기`를 누르면 카드를 닫고 그 기능의 화면을 열어 줍니다. 막히는 단계는 없습니다. 읽은 기록은 이 브라우저에 작품별로 저장되어 새로고침해도 이미 읽은 설명은 다시 뜨지 않고, 이미 뒤 단계를 하고 있으면 앞의 설명도 다시 보여 주지 않습니다.
- **직접 해 보는 단계** — 3·6·10·11·14·16단계입니다. 카드의 `해당 제작 화면으로`가 그 단계의 화면을 열고, 화면이 맞으면 버튼이 `직접 해보기`로 바뀌며 눌러야 할 버튼을 강조해 줍니다. 이 단계들은 요청이 아니라 **저장된 결과**를 기준으로 넘어갑니다.

| 단계 | 단계 이름 | 종류 | 하는 일 | 자세히 배우는 장 |
| --- | --- | --- | --- | --- |
| 1 | 작품 설정 | 설명 | 설정 패널이 카드 옆에 열린 채 `화면 비율` → `해상도` → `스타일` → `형식·설명·태그`를 하나씩 짚습니다. 바꾸면 바로 저장되고 크레딧은 들지 않습니다 | 16장 |
| 2 | 작품 정보 | 설명 | `다음 단계` 버튼 → `제작 현황`(끝난 단계에 초록 체크) → `휴지통`을 하나씩 짚습니다 | 14·16장 |
| 3 | AI 자동생성 | 직접 | ‘첫 이야기를 작품으로 만들어 보세요’ → `AI로 작품 구성`. 원문에 대본이 준비되어 있고, 정해진 `구성 비용`이 표시됩니다(「마지막 용맥 90초 예고편」 튜토리얼은 3.00 크레딧). 작품을 구성하기 전에만 나타납니다 | 19장 |
| 4 | 작품 위키 | 설명 | 등장인물·장소·소품·규칙을 적어 두면 AI가 읽고 씬마다 같은 세계를 만듭니다. `작품 위키` 탭이 강조됩니다 | 16장 |
| 5 | AI 어시스턴트 | 설명 | 지금 보는 등장인물·씬을 바탕으로 프롬프트를 함께 다듬는 도우미입니다. 제안만 하고 `적용`은 직접 누릅니다 | 18장 |
| 6 | 공개 캐릭터 | 직접 | **주인공 한 명만** 안내합니다. 등장인물 화면의 `공개 캐릭터 추가`로 한 명을 추가하고(확인 창의 사용료 0.50 크레딧), 스토리 화면에서 `S#1`의 등장인물 `추가`로 첫 씬에 연결합니다. 나머지 인물은 안내하지 않으며 원하면 직접 추가합니다. 튜토리얼에 공개 캐릭터가 없으면 이 단계가 없습니다 | 20장, 실습 4 |
| 7 | 미술·소품 | 설명 | 소품·의상·오브젝트를 디자인으로 만들어 두면 영상마다 같은 모습으로 나옵니다 | 21장 |
| 8 | 공간·배경 | 설명 | 이야기가 벌어지는 장소를 한 번 만들어 두면 여러 씬에서 같은 장소로 씁니다 | 21장 |
| 9 | 음향 | 설명 | 음성·음악 파일을 올려 등장인물의 보이스나 편집의 배경음악·효과음으로 씁니다. 올리는 것은 크레딧이 들지 않습니다 | 23·29장 |
| 10 | 참조 이미지 | 직접 | ‘이야기 속 모습을 만들어 주세요’ — 공개 캐릭터가 아닌 이미지 **하나만** 만들면 넘어갑니다. 카드에 `참조 이미지 {완료}/{전체}개 완료`와 `완료`·`생성 필요` 목록이 보입니다. 나머지 이미지는 직접 만듭니다 | 20–21장 |
| 11 | 콘티 | 직접 | ‘첫 씬의 구도를 완성해 보세요’ — 카드가 알려 주는 이미지를 생성해 첫 씬이 어떻게 보일지 구성합니다 | 24장 |
| 12 | 샷 이미지 | 설명 | 씬의 중요한 순간을 이미지 후보로 만들어 고르고, 확정한 프레임이 스토리보드에서 영상의 시작(과 끝)이 됩니다 | 26장 |
| 13 | 스토리보드 | 설명 | 씬을 구성하고 영상을 만드는 화면입니다. 결과는 T1, T2… 테이크로 쌓이고 이전 영상은 남습니다 | 24·27장 |
| 14 | 영상 생성 | 직접 | ‘이제 씬을 움직여 볼 차례예요’ — 첫 씬의 모델·길이·차감액을 확인하고 생성한 뒤 결과가 저장될 때까지 기다립니다 | 27장 |
| 15 | 편집 | 설명 | 씬 영상을 타임라인에 이어 붙이고 다듬는 화면입니다. 내보내기는 `편집본 저장`한 편집본으로 만들어지고, 편집 자체는 크레딧이 들지 않습니다 | 28·29장 |
| 16 | 내보내기 | 직접 | ‘첫 영상을 파일로 간직하세요’ — 첫 씬을 포함해 준비된 영상을 내보냅니다. 파일이 완성되면 `튜토리얼 마치기`와 함께 ‘첫 영상 작품을 완성했어요!’가 나옵니다 | 30장 |

이미 끝난 단계(예: 작품을 이미 구성했으면 3단계)는 건너뛰어 번호가 이어집니다. 분모는 그대로 16입니다.

카드를 닫으면(`잠시 닫고 둘러보기` 또는 오른쪽 위 닫기) 화면 아래 가운데에 진행 알림이 뜹니다. 설명 단계에서는 `다음 설명: {이름}`, 참조 이미지 단계에서는 `다음 이미지: {이름}`, 공개 캐릭터 단계에서는 `다음 캐릭터: {이름}`과 `{현재}/16`이 보이고, 영상을 만드는 중에는 `결과를 기다리는 중`이 보입니다. 알림을 누르면 카드가 다시 열립니다. 폰처럼 좁은 화면에서는 왼쪽 아래의 둥근 아이콘입니다.

**[캡처 05-05]** 카드를 닫은 뒤의 진행 알림 — ① `다음 설명: 작품 위키` `4/16`

튜토리얼 씬이나 참조 이미지가 바뀌어 안내를 이어갈 수 없으면 `제작 계속하기` 안내가 나옵니다. `안내 종료`를 누르면 안내만 끝나고 작품은 그대로 이어서 만들 수 있습니다.

::: info NOTE
3단계 카드의 `구성 비용` 금액과 6단계의 공개 캐릭터 사용료는 환경과 튜토리얼에 따라 다릅니다. 실제 값은 화면에 표시되는 값을 따르세요.
:::

::: tip TIP
튜토리얼은 ‘한 번 끝까지 가 본다’는 데 의미가 있습니다. 각 단계를 완벽하게 이해하려고 멈추지 말고, 카드를 읽고 어느 화면으로 이동하는지만 보면 됩니다. 설명 카드는 `다음`만 눌러도 넘어가고, 읽고 싶으면 `이 화면 열어보기`로 화면을 바로 열어 봅니다. 자세한 설명은 표의 장에서 다시 배웁니다.
:::

## PRACTICE — 튜토리얼로 첫 영상 만들기

1. 가입을 마치고 `크레딧 잔액`을 확인합니다.
2. `튜토리얼 시작 / 이어하기`를 누르고 1단계부터 안내 카드를 읽습니다. 설명 카드는 `다음`으로 넘기고, 궁금한 기능은 `이 화면 열어보기`로 열어 봅니다.
3. 직접 해 보는 단계(3·6·10·11·14·16단계)에서는 카드를 읽은 뒤 `직접 해보기`로 강조된 버튼을 스스로 누릅니다. 14단계에서 영상이 만들어지는 동안 상단 `AI 작업 보기`를 눌러 진행 상태를 봅니다.
4. 16단계에서 내보낸 파일을 재생해 봅니다.
5. 끝난 뒤 `크레딧 잔액`이 얼마나 줄었는지 적어 둡니다. 씬 영상 하나에 크레딧이 얼마나 드는지 감을 잡을 수 있습니다(자세한 예산은 13장).

::: cost COST · 비용
튜토리얼의 3단계(`AI로 작품 구성`)는 안내 카드에 적힌 `구성 비용`만큼 크레딧이 듭니다. 6단계의 공개 캐릭터 추가는 사용료가 들고(확인 창에 표시), 이미지·영상 생성과 내보내기도 크레딧이 듭니다. 1·2단계의 작품 설정·작품 정보와 설명 카드를 읽는 것, 편집은 크레딧이 들지 않습니다. 각 단계 버튼 옆의 예상 크레딧을 확인하고 진행합니다.
:::
