# 15장 로그인·기본 화면·튜토리얼

<ChapterGoals />

## WHY — 처음 들어가면 무엇을 봐야 할까요?

가입은 1분이면 끝납니다. 그보다 중요한 것은 첫 화면에서 ‘어디에 무엇이 있는지’를 익히는 일입니다. 그리고 튜토리얼 작품으로 첫 영상을 빠르게 만들어 봅니다.

- Google 계정으로 가입하고 로그인한다.
- 사이드 메뉴, 상단 바, 아바타 메뉴, 크레딧 잔액의 위치를 안다.
- 튜토리얼 5단계를 따라 첫 씬 영상을 만든다.

**완성 결과물** — 튜토리얼 첫 씬 영상 (결과 15-A)

## HOW — 화면 따라 하기

### 1. 가입과 로그인

1. 홈페이지 오른쪽 위의 `로그인`(옆의 크레딧 알약은 누르면 같은 로그인 창이 열립니다), 또는 첫 화면의 시작 버튼 `내 첫 작품 시작하기`를 누릅니다.
2. `Fecine에 로그인` 창에서 `Google 계정으로 계속하기`를 누르고 Google 계정을 고릅니다.
3. 처음이라면 `이름`을 적고 `약관 동의`의 세 항목(이용약관, 개인정보처리방침, 만 14세 이상)을 체크한 뒤 `스튜디오 열기`를 누릅니다.
4. ‘OOO님의 스튜디오’가 만들어지고 `작품` 화면이 열립니다. 가입 혜택 크레딧도 함께 들어옵니다.

### 2. 기본 화면

| 위치 | 있는 것 |
| --- | --- |
| ① 사이드 메뉴 · 위쪽 | `작품`, `라이브러리`, `스튜디오 멤버`(뷰어에게는 보이지 않음), 이어서 `템플릿`, `프리소스`, `캐릭터` |
| ① 사이드 메뉴 · 구분선 아래 | `모델·가격`, `제작 레퍼런스`, `아카데미`, `크리에이터` |
| ① 사이드 메뉴 · 아래쪽 | `도움말`, `업데이트 소식`(새 소식이 있으면 점 표시) |
| ② 상단 `새 작품` | 작품 목록에서 보입니다. 입력창 없이 바로 새 작품을 만들고 `작품 설정` 패널이 열립니다(16장) |
| ③ 상단 `AI 작업 보기` | `AI 작업` 패널 — `진행 중`·`최근` AI 작업과 상태, `작업 취소` |
| ④ 사이드 맨 아래 `크레딧 잔액` | 남은 크레딧, `크레딧 구매`(구매 권한이 있는 사람) |
| 상단 검색 | `작품·에셋 검색`(Ctrl K) |
| 상단 종 | 알림(생성 실패 등) |
| 아바타 메뉴 | `UID`(내 계정의 고유 번호. 스튜디오 초대에 사용, 눌러서 복사), `언어`, `다크`/`라이트`, `계정`, `설정`, `로그아웃`(누르면 로그인 창 없이 바로 홈으로 갑니다) |

### 3. 튜토리얼 작품

새로 만든 개인 스튜디오에 작품이 하나도 없으면 튜토리얼 작품이 한 번 만들어집니다(이미 작품이 있던 스튜디오에는 만들어지지 않고, 운영자가 튜토리얼 원작을 공개해 둔 경우에만 생깁니다). `작품` 화면의 `첫 영상 튜토리얼` 카드에서 `환영해요 · 첫 작품을 함께 만들어봐요`라는 문구와 함께 `튜토리얼 시작 / 이어하기`를 누르면 화면 위에 단계 안내가 뜨고, `{현재}/5 단계`로 진행됩니다.

::: info NOTE
새 스튜디오의 작품은 튜토리얼을 포함해 1개만 만들 수 있게 열릴 수 있습니다(운영 설정에 따라 다릅니다). 이때 새 작품을 만들면 `워크스페이스의 작품 생성 한도에 도달했어요.`가 나옵니다. 튜토리얼 작품에서 이어서 만들거나, 한도를 넓히려면 관리자에게 요청합니다(작품을 휴지통으로 옮기면 자리가 비는지는 운영 설정에 따라 다를 수 있습니다).
:::

| 단계 | 단계 이름 | 하는 일 | 자세히 배우는 장 |
| --- | --- | --- | --- |
| 1 | AI 자동생성 | ‘첫 이야기를 작품으로 만들어 보세요’ → `AI로 작품 구성`. 원문에 대본이 준비되어 있고, 정해진 `구성 비용`이 표시됩니다 | 19장 |
| 2 | 참조 이미지 | ‘이야기 속 모습을 만들어 주세요’ — 첫 씬에 필요한 등장 요소 이미지 만들기 | 20–21장 |
| 3 | 콘티 | ‘첫 씬의 구도를 완성해 보세요’ | 21장 |
| 4 | 영상 생성 | ‘이제 씬을 움직여 볼 차례예요’ | 27장 |
| 5 | 내보내기 | ‘첫 영상을 파일로 간직하세요’ | 30장 |

안내 카드의 `해당 제작 화면으로`는 그 단계의 화면을 열고, 화면이 맞으면 버튼이 `직접 해보기`로 바뀌며 눌러야 할 버튼을 강조해 줍니다. `잠시 닫고 둘러보기`는 안내를 숨기고, 다시 보려면 왼쪽 아래의 `튜토리얼 안내 보기`를 누릅니다. 2단계에서는 첫 씬에 필요한 참조 이미지를 하나씩 안내하며 `참조 이미지 {완료}/{전체}개 완료`로 진행을 보여 줍니다. 모든 단계는 요청이 아니라 **저장된 결과**를 기준으로 넘어갑니다. 다 마치면 `튜토리얼 마치기`와 함께 ‘첫 영상 작품을 완성했어요!’가 나옵니다.

튜토리얼 씬이나 참조 이미지가 바뀌어 안내를 이어갈 수 없으면 `제작 계속하기` 안내가 나옵니다. `안내 종료`를 누르면 안내만 끝나고 작품은 그대로 이어서 만들 수 있습니다.

## PRACTICE — 튜토리얼로 첫 영상 만들기

1. 가입을 마치고 `크레딧 잔액`을 확인합니다.
2. `튜토리얼 시작 / 이어하기`를 누르고 1단계부터 안내를 따릅니다.
3. 4단계에서 영상이 만들어지는 동안 상단 `AI 작업 보기`를 눌러 진행 상태를 봅니다.
4. 5단계에서 내보낸 파일을 재생해 봅니다.
5. 끝난 뒤 `크레딧 잔액`이 얼마나 줄었는지 적어 둡니다. 씬 영상 하나에 크레딧이 얼마나 드는지 감을 잡을 수 있습니다(자세한 예산은 13장).

::: cost COST · 비용
튜토리얼의 1단계(`AI로 작품 구성`)는 안내 카드에 적힌 `구성 비용`만큼 크레딧이 듭니다. 이미지·영상 생성과 내보내기도 크레딧이 듭니다. 각 단계 버튼 옆의 예상 크레딧을 확인하고 진행합니다.
:::

## REVIEW — 제대로 했나요?

- [ ] Google 계정으로 로그인했다.
- [ ] 새 작품·AI 작업·크레딧 잔액·언어의 위치를 안다.
- [ ] 튜토리얼을 끝까지 마쳤다.

| 자주 겪는 실패 | 화면 문구 | 해결 |
| --- | --- | --- |
| 이메일 가입을 찾음 | — | Google 계정으로만 가입 |
| 다른 계정으로 로그인해 작품이 안 보임 | — | 아바타 메뉴의 이메일 확인 후 `로그아웃` |
| 로그인이 끝나지 않음 | 로그인을 마치지 못했어요. 다시 시도해 주세요. | 잠시 후 다시. 계속되면 브라우저 쿠키 허용 확인 |
| 튜토리얼 안내가 사라짐 | — | 왼쪽 아래 `튜토리얼 안내 보기` |
| 새 작품이 만들어지지 않음 | 워크스페이스의 작품 생성 한도에 도달했어요. | 기존 작품에서 이어 하거나 관리자에게 한도 변경 요청 |

**확인 문제** 1) 스튜디오 초대에 쓰는 번호는 어디서 보나요? 2) AI 작업 진행 상태를 보는 곳은? 3) 튜토리얼의 네 번째 단계는?

정답: 1) 아바타 메뉴의 `UID` 2) 상단 `AI 작업 보기`(`AI 작업` 패널) 3) 영상 생성

**응용 과제** — 아바타 메뉴에서 테마를 `라이트`로 바꾸고, 언어를 영어로 바꿨다가 다시 한국어로 돌려 보세요. 일본어와 중국어(간체·번체)도 있습니다. 언어 설정은 이 브라우저에 저장됩니다. 사이드 아래쪽의 `업데이트 소식`도 열어 최근에 바뀐 기능을 확인해 보세요.
