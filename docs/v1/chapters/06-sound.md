# 6장 소리: 대사·음악·효과음

<ChapterGoals />

::: info 이 장의 예제
이 책은 예제 작품 「비 오는 정류장」을 이어서 만듭니다. 비 오는 밤, 우산 없는 수아에게 처음 보는 도윤이 우산을 건네는 15초짜리 영상(장면 3개)입니다. FECINE을 아직 써 보지 않았다면 화면 따라 하기는 건너뛰고 개념과 표만 읽어도 됩니다.
:::

## WHY — 영상의 절반은 소리입니다

소리를 끄고 영화를 보면 긴장도 감동도 크게 줄어듭니다. 빗소리 하나, 작은 한마디가 장면을 살립니다. AI 영상에서도 소리를 미리 설계해야 완성도가 높아집니다.

- 영상 소리의 다섯 요소를 구분한다.
- FECINE에서 각 소리가 어디서 만들어지는지 안다.
- 예제의 소리 설계 메모를 쓴다.

**완성 결과물** — 「비 오는 정류장」 장면별 소리 설계 메모

## HOW — 소리의 구성

| 요소 | 뜻 | 예제에서 |
| --- | --- | --- |
| 대사 | 인물이 하는 말 | 도윤: “같이 써요.” |
| 내레이션 | 화면 밖 목소리 | (없음) |
| 앰비언스 | 장소의 배경 소리 | 빗소리, 멀리서 지나는 차 |
| 효과음 | 특정 동작의 소리 | 우산 펼치는 소리, 버스 브레이크 |
| 음악 | 감정을 이끄는 배경음악 | 조용한 피아노 |

### FECINE에서는 소리가 어디서 올까?

FECINE V1에는 목소리를 따로 만드는 음성 합성(TTS)이나 음악 생성 기능이 없습니다. 대신 **영상 모델이 영상을 만들 때 대사와 소리를 함께 만듭니다.** 음악과 추가 효과음은 파일을 올려 편집에서 얹습니다.

| 소리 | FECINE에서 하는 곳 |
| --- | --- |
| 대사·내레이션 | 스토리보드 `장면` 탭 `대사 / 내레이션`에 입력(종류 `대사`·`내레이션`·`가사`, `말하는 인물`, 시작 시각) → `모델` 탭 `사운드`를 `음성 있음`으로 |
| 인물의 목소리 톤 | `오디오`에 목소리 파일을 `업로드` → `캐릭터 연결`(23장). 지원하는 모델은 이 목소리를 참고함 |
| 앰비언스 | 프롬프트에 소리를 묘사(‘거센 빗소리’)하고 `음성 있음`으로 생성 |
| 음악·효과음 | `오디오` 업로드(MP3·WAV·AAC·OGG) → `편집`의 `배경음악`·`효과음` 트랙 |
| 자막 | 입력한 대사로 `대사에서 자막 자동 생성`(29장) |

::: info NOTE
장면에 대사를 넣으면 `사운드`는 자동으로 `음성 있음`이 됩니다. 대사 없는 무드 영상이고 음악만 입힐 계획이라면 `무음`을 고르는 편이 편집하기 쉽습니다. 음성 있음은 대사뿐 아니라 빗소리 같은 장면의 소리도 함께 만든다는 뜻입니다.
:::

::: warning 주의
인터넷에서 받은 음악은 저작권을 확인하고 씁니다. 다른 사람의 목소리는 본인 동의 없이 캐릭터 보이스로 쓰지 않습니다.
:::

## PRACTICE — 소리 설계 메모 쓰기

장면마다 들릴 소리를 적고, FECINE의 어느 칸에 넣을지 표시합니다.

```text
[소리 설계] 「비 오는 정류장」

장면 1  앰비언스: 거센 빗소리, 멀리 지나는 차     → 프롬프트 + 사운드: 음성 있음
        대사: 수아 (작게) "오늘따라 왜 이렇게 안 와." → 장면 탭 대사, 말하는 인물: 수아
장면 2  효과음: 우산 위로 떨어지는 빗방울         → 프롬프트
        대사: 도윤 "같이 써요. 저도 같은 버스 기다리거든요." → 말하는 인물: 도윤
장면 3  효과음: 버스 브레이크, 문 열리는 소리       → 프롬프트
        대사: 수아 (미소) "고마워요."
전체   음악: 조용한 피아노 (직접 준비한 파일)  → 편집 > 배경음악, 장면 3에서 커짐
```

::: cost COST · 비용
메모 작성과 파일 업로드는 무료입니다. 소리는 영상과 함께 생성되므로 별도 요금이 없지만, 음성 유무에 따라 영상 요금이 다를 수 있으니 `모델` 탭의 예상 크레딧을 확인합니다.
:::

## REVIEW — 제대로 했나요?

- [ ] 대사·내레이션·앰비언스·효과음·음악을 구분한다.
- [ ] 대사 음성은 영상 모델이 만든다는 것을 안다.
- [ ] 소리 설계 메모를 완성했다.

| 자주 겪는 실패 | 원인 | 해결 |
| --- | --- | --- |
| 대사가 다른 사람 목소리로 나옴 | `말하는 인물`을 안 고름, 캐릭터 미연결 | 말하는 인물 지정, 캐릭터를 장면에 연결 |
| 자막을 다른 언어로 바꿔도 번역되지 않음 | 자동 번역 기능 없음 | 대사를 그 언어로 직접 입력 |
| 음성 합성 메뉴를 찾음 | V1에 없음(부록 D) | 대사 + `음성 있음`으로 생성 |

**확인 문제** 1) 장소의 배경 소리를 무엇이라 하나요? 2) 대사를 입력하는 곳은? 3) 음악 파일을 까는 트랙은?

정답: 1) 앰비언스 2) 스토리보드 `장면` 탭 `대사 / 내레이션` 3) `배경음악`

**응용 과제** — 장면 2를 대사 없이 소리만으로 표현한다면 어떤 효과음을 쓸지 적어 보세요.
