# 19장 [선택] 대본 파일이 있을 때: AI 자동생성

<ChapterGoals />

## WHY — 긴 대본을 한 번에 씬으로 바꿀 수 있을까요?

이미 쓴 대본·소설이 있다면 17–18장처럼 씬을 하나씩 만들 필요가 없습니다. `스토리` 화면의 ✦ `AI 자동생성` 탭은 원문을 읽고 에피소드·씬·씬 대본과 등장 요소 목록을 한 번에 만듭니다. 결과는 `스토리`와 `등장인물`·`공간·배경`·`미술·소품`·`콘티`에 모이므로, 이후 과정은 같습니다.

- 대본 파일을 원문에 올리고 읽을 범위를 정한다.
- 1단계(에피소드·씬 추출)와 2단계(제작설계 만들기)를 실행한다.
- 결과를 스토리·등장인물·공간·배경·미술·소품에서 확인한다.

**완성 결과물** — 예제 대본 파일로 만든 에피소드·씬과 등장 요소 (결과 19-A)

::: info NOTE
17–18장에서 이미 씬을 만들었다면, 이 장은 **새 작품**(예: ‘비 오는 정류장 — AI 자동생성판’)에서 연습합니다. 같은 작품에서 다시 추출하면 씬이 겹치기 때문입니다.
:::

## HOW — 화면 따라 하기

`AI 자동생성` 화면은 세 부분입니다. 왼쪽 ① `원문`(`대본`·`참고 자료` 탭), 가운데 ② `원문 보기`·`진행` 탭, 오른쪽 패널입니다. 오른쪽 패널 위에는 두 가지 작업 `에피소드·씬 추가`(원문에서 추출)와 `제작설계 만들기`(등장 요소 · 콘티)가 있고, 그 아래는 `설정`·`요청 프롬프트`·`모델` 탭입니다.

**[캡처 08-01] <Badge type="info" text="화면 갱신 예정" />** AI 자동생성 — ① 원문 ② 원문 보기 ③ `에피소드·씬 추출`

![캡처 08-01](/images/v1/captures/cap-08-01.png)

### 1. 원문 넣기

1. 왼쪽 제작 모듈에서 `스토리`를 누르고, 화면 위의 `AI 자동생성` 탭을 엽니다. (`스토리` 빈 화면의 `대본이 있어요` 카드에서 `AI 자동생성으로 이동`을 눌러도 됩니다.)
2. `원문`의 `대본` 탭 상자에 파일을 끌어다 놓거나 클릭해 고릅니다. TXT·MD·DOCX·PDF·ZIP을 올릴 수 있고, 폴더도 됩니다. 파일 하나가 대본 하나입니다.
3. 파일 없이 글로 써 둔 이야기가 있다면 `스토리 작성`을 눌러 바로 붙여 넣거나 씁니다(최대 200,000자). 저장하면 대본 목록에 들어가고, 올린 대본처럼 읽힙니다.
4. 긴 대본이라면 가운데 `원문 보기`에서 쪽을 넘기며 `이 쪽부터`·`이 쪽까지`로 `읽을 범위`를 정합니다. 한 번에 읽을 수 있는 분량은 최대 18,000자입니다. 나머지는 나중에 이어서 추출합니다.

::: info NOTE
`참고 자료` 탭에는 인물 자료, 배경·설정, 문헌·고증, 프롬프트 규칙을 올립니다. 이 자료는 `작품 위키`(16장)를 채우는 데 쓰이고, AI 자동생성의 원문으로는 읽지 않습니다.
:::

### 2. 1단계 · 에피소드·씬 추출

1. 오른쪽 위 작업에서 `에피소드·씬 추가`를 고릅니다.
2. `모델` 탭에서 `텍스트 모델`을 고릅니다.
3. `읽을 범위`를 확인하고 ③ `에피소드·씬 추출`을 누릅니다.
4. 가운데가 `진행` 탭으로 바뀌고 진행 상황이 보입니다.
5. 긴 대본의 다음 쪽은 `다음 부분 이어서 추출 ({from}–{to}쪽)`으로 이어 갑니다. 앞 에피소드 요약이 맥락으로 함께 들어가고, 읽은 범위는 `추출 기록`에 남습니다.

### 3. 2단계 · 제작설계 만들기

1. `추출한 에피소드 {n}개로 항목 만들기`를 누르거나, 오른쪽 위 작업에서 `제작설계 만들기`를 고릅니다.
2. `만들 것`에서 고릅니다: `등장 요소`(등장인물·공간·배경·미술·소품), `콘티`.
3. 만들 에피소드를 고릅니다(`전체`/`해제`).
4. (선택) `원하는 느낌`에 프리셋(`밝고 경쾌한 톤`, `현대 배경`, `인물 외형을 자세히`, `빠른 전개`)을 넣거나 직접 적습니다.
5. `제작설계 만들기`를 누릅니다.
6. 끝나면 `결과 확인`에서 `에피소드 {n} · 씬 {n}`, `등장인물 {n}`, `공간·배경 {n}`, `미술·소품 {n}`, `콘티 {n}`을 눌러 확인합니다.

::: info NOTE
AI 자동생성은 글(에피소드·씬·씬 대본·등장 요소 설정·이미지 프롬프트·콘티)만 만들고 **이미지는 만들지 않습니다.** 등장인물·배경 이미지는 20–21장처럼 각 메뉴에서 따로 만듭니다. 씬 영상 프롬프트도 여기서 만들지 않습니다. 등장 요소와 씬 대본이 정해진 뒤 `스토리보드`의 `영상 프롬프트 만들기 · 빈 씬 {n}개`로 만듭니다(25장).
:::

::: warning 주의
`스토리`에서 씬을 직접 합치거나 나누는 등 구성을 바꾼 에피소드는 2단계에서 고를 수 없습니다. 제작설계를 먼저 만든 뒤 씬 구성을 다듬으세요.
:::

## PRACTICE — 예제 대본으로 만들기

메모장에 아래를 붙여 넣고 `비오는정류장.txt`로 저장한 뒤 올립니다. (파일을 만들기 어렵다면 `스토리 작성`에 그대로 붙여 넣어도 됩니다.)

```text
비 오는 정류장

1화

#1. 버스 정류장 / 밤
비가 쏟아지는 도시의 버스 정류장. 수아(20대)가 우산 없이 서 있다.
수아: 오늘따라 왜 이렇게 안 와.

#2. 버스 정류장 / 밤
수아의 머리 위로 검은 우산이 들어온다. 도윤(20대)이 웃는다.
도윤: 같이 써요. 저도 같은 버스 기다리거든요.

#3. 버스 정류장 / 밤
두 사람이 한 우산 아래 서 있다. 버스가 들어온다.
수아: 고마워요.
```

| 설정 | 값 |
| --- | --- |
| `만들 것` | `등장 요소` |
| 에피소드 | `전체`(1화) |
| `원하는 느낌` | `인물 외형을 자세히` |

결과를 확인하고 17장에서 직접 쓴 씬과 비교합니다. 무엇이 더 빠르고, 무엇이 더 내 의도에 가까운가요?

::: cost COST · 비용
1단계·2단계 모두 텍스트 AI 사용량만큼 크레딧이 듭니다(‘사용한 만큼만 크레딧이 차감됩니다’). 대본이 길수록, 만들 것이 많을수록 많이 듭니다. 처음에는 `읽을 범위`를 짧게 잡아 보세요.
:::

## REVIEW — 제대로 했나요?

- [ ] 대본 파일을 원문에 올리고 읽을 범위를 정할 수 있다.
- [ ] 1단계와 2단계의 차이를 안다.
- [ ] AI 자동생성은 이미지와 씬 영상 프롬프트를 만들지 않는다는 것을 안다.

| 자주 겪는 실패 | 화면 문구 | 해결 |
| --- | --- | --- |
| 버튼이 눌리지 않음 | 대본이나 참고 자료를 먼저 넣으세요. / 모델을 선택하세요 | 파일 올리기, `모델` 탭에서 선택 |
| 범위가 너무 김 | 한 번에 18,000자까지 읽을 수 있어요. 범위를 줄여 주세요. | `원문 보기`에서 쪽 범위 줄이기 |
| 중간에 멈춤 | AI 자동생성이 실패했습니다. 위의 작업 상태에서 자세한 내용을 확인하세요. | 멈춘 작업 이어서 진행, 끄거나 줄인 항목은 `남은 작업 만들기` |
| 커다란 파일이 안 올라감 | (업로드 실패) | 파일을 나눠 올리거나 읽을 범위를 줄이기 |
| 에피소드를 2단계에서 고를 수 없음 | AI로 추출하지 않았거나 씬 구성을 직접 바꾼 에피소드라 고를 수 없습니다 | 직접 만든 에피소드는 각 메뉴에서 직접 만들기 |
| 등장인물 이미지가 없음 | — | AI 자동생성은 글만 만듦. `등장인물`에서 이미지 생성 |

**확인 문제** 1) 업로드할 수 있는 대본 형식 다섯 가지는? 2) AI 자동생성이 만들지 않는 씬 영상 프롬프트는 어디서 만드나요? 3) 긴 대본의 다음 쪽을 이어서 추출하는 버튼은?

정답: 1) TXT·MD·DOCX·PDF·ZIP 2) `스토리보드`의 `영상 프롬프트 만들기` 3) `다음 부분 이어서 추출 ({from}–{to}쪽)`

**응용 과제** — 나만의 A4 한 장 분량 대본을 `스토리 작성`으로 넣고 AI 자동생성으로 추출해 보세요. 몇 개의 씬으로 나뉘었나요?
