# 19장 [선택] 대본 파일이 있을 때: AI 자동생성

<ChapterGoals />

## WHY — 긴 대본을 한 번에 씬으로 바꿀 수 있을까요?

이미 쓴 대본·소설이 있다면 17–18장처럼 씬을 하나씩 만들 필요가 없습니다. `스토리` 화면의 ✦ `작품 자료` 탭에 대본을 올리고 오른쪽 `AI 어시스턴트`에 요청하면, AI가 원문을 읽고 에피소드·씬·씬 대본(과 선택한 등장 요소 목록)을 만들어 작품에 넣습니다. 결과는 `스토리`와 `등장인물`·`공간·배경`·`미술·소품`·`콘티`에 모이므로, 이후 과정은 같습니다.

- 대본 파일을 원문에 올리고 읽을 범위를 정한다.
- `에피소드·씬 추출`을 요청하고, 이어서 `등장 요소 만들기`·`촬영 설계 만들기`를 요청한다.
- `진행 상황`에서 작업을 확인하고 결과를 스토리·등장인물·공간·배경·미술·소품에서 확인한다.

**완성 결과물** — 예제 대본 파일로 만든 에피소드·씬과 등장 요소 (결과 19-A)

::: info NOTE
17–18장에서 이미 씬을 만들었다면, 이 장은 **새 작품**(예: ‘비 오는 정류장 — AI 자동생성판’)에서 연습합니다. 같은 작품에서 다시 추출하면 씬이 겹치기 때문입니다.
:::

## HOW — 화면 따라 하기

`작품 자료` 화면은 세 부분입니다. 왼쪽 ① `원문`(`대본`과 `참고 자료` 두 칸), 가운데 ② 대본을 쪽 단위로 읽는 `원문 보기`, 오른쪽 ③ `AI 어시스턴트`입니다. 어시스턴트 아래쪽에는 작품에 바로 넣는 요청이 세 가지 있습니다.

| 요청 | 하는 일 |
| --- | --- |
| `에피소드·씬 추출` | 원문에서 에피소드와 씬을 나눠 만듭니다. 원하면 등장 요소·촬영 설계 항목도 함께 만듭니다 |
| `등장 요소 만들기` | 고른 에피소드에 나오는 등장인물·공간·소품의 설정과 이미지 프롬프트를 만듭니다 |
| `촬영 설계 만들기` | 고른 에피소드(또는 씬 하나)의 콘티 시트와 샷·영상 프롬프트를 만듭니다 |

`스토리`의 `진행 상황` 탭에는 요청이 카드로 쌓입니다. `스토리` 빈 화면의 `대본이 있어요` 카드(`AI 자동생성으로 이동`)로도 이 화면에 올 수 있습니다.

**[캡처 08-01]** 작품 자료 — ① 원문(`대본`) ② 원문 보기 ③ AI 어시스턴트의 `에피소드·씬 추출` 질문

![캡처 08-01](/images/v1/captures/cap-08-01.png)

**[캡처 08-00]** 대본을 아직 올리지 않은 `작품 자료` — `작품 만들기 3단계`(`원문 넣기` → `AI 자동생성` → `결과 확인`)

![캡처 08-00](/images/v1/captures/cap-08-00.png)

### 1. 원문 넣기

1. 왼쪽 제작 모듈에서 `스토리`를 누르고, 화면 위의 `작품 자료` 탭을 엽니다.
2. `원문`의 `대본` 칸에 파일을 끌어다 놓거나 클릭해 고릅니다. TXT·MD·DOCX·PDF·ZIP을 올릴 수 있고, 폴더도 됩니다. 파일 하나가 대본 하나입니다.
3. 파일 없이 글로 써 둔 이야기가 있다면 `스토리 작성`을 눌러 바로 붙여 넣거나 씁니다(최대 200,000자). 저장하면 대본 목록에 들어가고(`직접 작성` 표시), 올린 대본처럼 읽힙니다.
4. 대본 이름을 누르면 가운데 `원문 보기`에서 쪽을 넘기며 읽을 수 있습니다(‹ › 또는 ← → 키, `쪽 이동`). 잘못 올린 대본은 `삭제`를 눌러 고른 뒤 지웁니다.

::: info NOTE
`참고 자료`에는 인물 자료, 배경·설정, 문헌·고증, 프롬프트 규칙을 올립니다. 이 자료는 `작품 위키`(16장)를 채우는 데 쓰이고, AI 자동생성의 원문으로는 읽지 않습니다.
:::

### 2. 에피소드·씬 추출

어시스턴트가 질문을 한 번에 하나씩 하고, 답한 것은 질문 위에 남습니다. 답을 바꾸려면 그 줄의 `고치기`를 누릅니다. 설명은 질문 옆 ⓘ에 있습니다.

1. 어시스턴트의 `에피소드·씬 추출`을 누릅니다.
2. ‘어떤 대본에서 에피소드·씬을 뽑을까요?’에서 대본을 하나 이상 체크합니다(`전체 선택`·`선택 해제`) → `다음`
3. (올린 파일이 있을 때) ‘대본마다 읽을 쪽을 정해 주세요.’에서 `읽을 쪽`의 시작 쪽과 끝 쪽을 숫자로 적습니다. 정하지 않으면 `전체`를 읽습니다(`전체` 버튼으로 되돌릴 수 있습니다). 쪽 수와 글자 수가 함께 보이고, 한 번에 읽을 수 있는 분량은 합계 최대 18,000자입니다. 넘으면 ‘한 번에 18,000자까지 읽을 수 있어요. 쪽 범위를 줄여 주세요.’가 뜹니다. `원문 보기`를 누르면 가운데에 그 대본이 열립니다. → `다음`
4. ‘이 씬들과 함께 무엇을 만들까요?’에서 고릅니다. 에피소드·씬(제목·요약·대본·연출 노트)은 항상 만들고, 선택으로 `등장 요소`(`등장인물`·`공간·배경`·`미술·소품`)와 `촬영 설계`(`콘티`·`씬 영상 프롬프트`)를 함께 켤 수 있습니다. → `다음`
5. ‘요청사항이 있나요? 없으면 바로 시작해요.’에 톤·시대·인물·연출을 적습니다(예: 밝고 경쾌한 톤으로, 주인공은 20대 후반). 비우면 원문대로 만듭니다. 작품 위키가 있으면 함께 읽습니다.
6. `이대로 추출 요청`(또는 요청사항을 적었다면 `입력한 내용으로 추출 요청`)을 누릅니다. 버튼 옆에 예상 크레딧이 보입니다.

긴 대본은 읽은 쪽이 `추출 기록`에 남고, 다음에 같은 질문의 `읽을 쪽`에서 `다음 부분 이어서 추출 ({from}–{to}쪽)`을 누르면 이어서 읽습니다. 앞 에피소드 요약이 맥락으로 함께 들어가고, 가운데 원문 보기에는 이미 읽은 쪽이 `추출됨`으로 표시됩니다.

### 3. 등장 요소 만들기 · 촬영 설계 만들기

에피소드가 만들어진 뒤에 따로 요청할 수도 있습니다. 4번 단계에서 껐거나, 에피소드를 나중에 더 추출했을 때 씁니다.

1. 어시스턴트의 `등장 요소 만들기`(또는 `촬영 설계 만들기`)를 누릅니다.
2. ‘어느 에피소드에 만들까요?’에서 에피소드를 고릅니다. 방금 추출한 에피소드가 `방금 추출`로 표시됩니다.
3. (촬영 설계, 에피소드를 하나만 골랐을 때) ‘어느 씬에 만들까요?’에서 `에피소드 전체`나 `씬 고르기`를 고릅니다. 고른 씬만의 콘티 시트와 영상 프롬프트가 따로 만들어지고, 다른 씬은 건드리지 않습니다.
4. ‘만들 것’을 고릅니다. 등장 요소는 `등장인물`·`공간·배경`·`미술·소품`, 촬영 설계는 `콘티`와 `샷 나누기`입니다. 이미 있는 것은 그대로 두고 없는 것만 만듭니다.
5. 요청사항을 적거나 비우고 `이대로 생성 요청`(또는 `입력한 내용으로 생성 요청`)을 누릅니다.

### 4. 진행 상황과 결과 확인

1. 요청하면 `진행 상황` 탭에 카드가 생깁니다. 카드에는 고른 값(대본, 읽은 쪽, 에피소드, 함께 만든 것, 요청사항, 모델)이 기록되고, `원문 읽기` → `에피소드·씬 추출` → `등장 요소` → `촬영 설계` → `작품에 저장` 단계가 `완료`·`진행 중`·`대기`로 보입니다. 새 요청은 이전 기록을 지우지 않고 아래로 쌓입니다.
2. 작업이 진행되는 동안에는 ‘작업이 진행 중이에요. 끝나면 다음 요청을 할 수 있어요.’가 보이고 새 요청을 시작할 수 없습니다. 다른 화면으로 가도 계속됩니다.
3. 끝나면 `스토리`에서 에피소드와 씬을, `등장인물`·`공간·배경`·`미술·소품`·`콘티`에서 만든 설정을 확인합니다. 멈춘 작업이 있으면 어시스턴트에 ‘멈춘 AI 자동생성이 있어요’와 `이어서 진행`이 보이고, 받은 결과는 다시 청구하지 않고 멈춘 곳부터 이어 갑니다.

::: info NOTE
AI 자동생성은 글(에피소드·씬·씬 대본·등장 요소 설정·이미지 프롬프트·콘티·샷 프롬프트)만 만들고 **이미지는 만들지 않습니다.** 등장인물·배경 이미지는 20–21장처럼 각 메뉴에서 따로 만듭니다. 씬 영상 프롬프트는 `촬영 설계`로 만들 수 있고, 비어 있는 씬은 `스토리보드`의 `영상 프롬프트 만들기 · 빈 씬 {n}개`로 채울 수도 있습니다(25장).
:::

::: warning 주의
`스토리`에서 씬을 직접 합치거나 나누는 등 구성을 바꾼 에피소드는 `등장 요소 만들기`·`촬영 설계 만들기`에서 고를 수 없습니다(‘AI로 추출하지 않았거나 씬 구성을 직접 바꾼 에피소드라 고를 수 없어요’). 이런 요청을 먼저 한 뒤 씬 구성을 다듬으세요.
:::

## PRACTICE — 예제 대본으로 만들기

메모장에 아래를 붙여 넣고 `비오는정류장.txt`로 저장한 뒤 올립니다. (파일을 만들기 어렵다면 `스토리 작성`에 그대로 붙여 넣어도 됩니다.)

```text
비 오는 정류장

1화

#1. 버스 정류장 / 밤
비가 쏟아지는 도시의 버스 정류장. 수아(20대)가 우산 없이 서 있다.
수아: 오늘따라 왜 이렇게 안 와.

#2. 버스 정류장 / 밤
수아의 머리 위로 검은 우산이 들어온다. 도윤(20대)이 웃는다.
도윤: 같이 써요. 저도 같은 버스 기다리거든요.

#3. 버스 정류장 / 밤
두 사람이 한 우산 아래 서 있다. 버스가 들어온다.
수아: 고마워요.
```

| 질문 | 답 |
| --- | --- |
| 읽을 대본 | 방금 올린 `비오는정류장` |
| 읽을 쪽 | 전체 |
| 함께 만들 것 | `등장 요소`(`등장인물`·`공간·배경`·`미술·소품`) |
| 요청사항 | 인물 외형을 자세히 |

`이대로 추출 요청`이 아니라 `입력한 내용으로 추출 요청`을 눌러 시작합니다. `진행 상황`에서 끝나는 것을 보고, 결과를 17장에서 직접 쓴 씬과 비교합니다. 무엇이 더 빠르고, 무엇이 더 내 의도에 가까운가요?

::: cost COST · 비용
요청은 모두 텍스트 AI 사용량만큼 크레딧이 듭니다(‘사용한 만큼만 크레딧이 차감돼요. 이미 반영된 대본과 직접 고친 내용은 그대로 둬요.’). 대본이 길수록, 함께 만들 것이 많을수록 많이 듭니다. 처음에는 `읽을 쪽`을 짧게 잡아 보세요.
:::

## REVIEW — 제대로 했나요?

- [ ] 대본 파일을 원문에 올리고 읽을 쪽을 정할 수 있다.
- [ ] `에피소드·씬 추출`, `등장 요소 만들기`, `촬영 설계 만들기`의 차이를 안다.
- [ ] AI 자동생성은 이미지를 만들지 않는다는 것을 안다.

| 자주 겪는 실패 | 화면 문구 | 해결 |
| --- | --- | --- |
| 시작할 수 없음 | 대본이 없어요. 원문에 대본을 넣으면 에피소드·씬을 만들 수 있어요. / 대본을 하나 이상 골라 주세요. | 파일 올리기, 체크하기 |
| 범위가 너무 김 | 한 번에 18,000자까지 읽을 수 있어요. 쪽 범위를 줄여 주세요. | `읽을 쪽`의 끝 쪽 줄이기 |
| 다른 요청이 눌리지 않음 | 작업이 진행 중이에요. 끝나면 다음 요청을 할 수 있어요. | `진행 상황`에서 끝난 뒤 요청 |
| 중간에 멈춤 | AI 자동생성이 실패했어요. 위의 작업 상태에서 자세한 내용을 확인하세요. | `이어서 진행`. 끄거나 줄인 항목은 `등장 요소 만들기`·`촬영 설계 만들기`로 |
