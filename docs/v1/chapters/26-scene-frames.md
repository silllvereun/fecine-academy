# 26장 샷 이미지로 시작 화면 정하기

<ChapterGoals />

## WHY — 첫 화면을 정해 두면 왜 결과가 안정될까요?

영상을 바로 만들면 구도·얼굴·빛을 한꺼번에 AI에 맡기는 셈입니다. 먼저 정지 이미지로 첫 화면을 고르면, 영상은 그 그림에서 움직이기만 하면 됩니다. 이미지는 영상보다 빠르고 싸서, 여러 장 만들어 고르기 좋습니다.

- 씬별 후보 이미지를 만들고 프레임을 확정한다.
- 프레임 1장과 2–4장, 샷별 프레임의 차이를 안다.
- 확정한 프레임을 영상의 시작으로 연결한다.

**완성 결과물** — 씬 1 시작 프레임 (결과 01-A)

## HOW — 화면 따라 하기

1. 작품 왼쪽 `제작 모듈` 메뉴에서 `샷 이미지`를 누릅니다(`콘티` 다음, `스토리보드` 바로 위). 에피소드는 화면 위쪽 띠의 `에피소드 고르기` 메뉴에서 고릅니다. 왼쪽에는 `씬 {n}개`와 `S#1 씬 제목` 목록이 있고, 씬마다 상태(`프레임 없음`·`확정 전`·`프레임 {n}장`)가 표시됩니다. `전체 씬`을 누르면 모든 씬의 프레임을 한눈에 봅니다.
2. 씬 1을 고릅니다. ‘스토리보드 씬 1에 연결됨’이 표시됩니다. 오른쪽 탭은 `등장 요소`·`스토리`·`프롬프트`·`모델`입니다. `스토리` 탭에서는 이 씬의 요약·대본·연출 노트를 읽고 고칠 수 있고, `등장 요소` 탭은 스토리보드와 같은 연결입니다.
3. `프롬프트` 탭의 `프롬프트`에는 씬 설명이 들어 있습니다. 정지 화면에 맞게 고칩니다(움직임 대신 ‘한 순간’을 묘사). 원래대로 돌리려면 `씬 설명으로 되돌리기`.
4. 같은 탭 아래 `등장 요소`에서 씬에 연결한 등장인물·배경·소품을 확인합니다. 스토리보드와 같은 규칙으로, 프롬프트에 `@수아`처럼 부른 항목이 참조로 쓰입니다. 이미지가 없는 @ 항목이 있으면 ‘일부 @ 참조에 아직 이미지가 없어요’ 안내가 뜨고 생성되기 전에 멈춥니다(이 모델이 참조 이미지를 받지 않으면 ‘이 모델은 참조 이미지를 받지 않아요.’가 보입니다).
5. `모델` 탭에서 모델을 고릅니다. 오른쪽 아래에 `비율`(모델이 여러 비율을 지원할 때)과 `이미지 수`(모델이 여러 장을 지원할 때)를 고르는 작은 선택 상자가 있고, 그 아래 `생성 · 예상 크레딧` 버튼을 누릅니다. 후보는 끝나는 대로 하나씩 나타납니다. 더 필요하면 `생성`을 다시 누릅니다.
6. 마음에 드는 후보에서 `프레임에 추가`를 누릅니다. 프레임은 최대 4장이며 `앞으로`·`뒤로`로 순서를, `프레임에서 빼기`·`모두 빼기`로 제외를 합니다. 마음에 들지 않는 후보는 `이 이미지 지우기` → `지우기`로 작품 정보의 휴지통에 보냅니다(보관 기간 안에는 복원할 수 있습니다).
7. `이 프레임으로 영상 만들기`를 누릅니다. 이제 스토리보드 씬 1의 영상은 이 프레임에서 시작합니다.

### 프레임 수에 따른 차이

| 프레임 | 영상에서의 역할 |
| --- | --- |
| 1장 | 영상의 **첫 프레임**이 됩니다. |
| 2–4장 | 씬의 **연속 프레임**으로 순서대로 보내고, 영상이 그 순서를 따라갑니다. 등장인물 참조와 목소리도 함께 갑니다. |
| 없음 | 샷 이미지 대신 디자인 참조(등장인물·배경·소품·콘티)로 만듭니다. |

### 샷별 프레임

25장에서 씬을 샷으로 나눴다면, 프레임 순서가 샷 순서와 짝을 이룹니다. 프레임 1은 샷 1의 시작, 프레임 2는 샷 2의 시작입니다. 프레임마다 ‘샷 1 · 내용’ 표시가 붙고, 샷보다 많은 프레임은 ‘추가 프레임’으로 표시됩니다. 프레임이 없는 샷은 빈 칸으로 보이며, `샷 {n} 프레임 만들기`를 누르면 그 샷의 글과 앞 프레임을 참조해 만듭니다. 스토리보드의 샷 카드에도 그 샷의 프레임이 작게 보입니다.

::: info NOTE
영상의 마지막 화면을 직접 정하는 기능은 아직 없습니다(‘끝 프레임: 지금 연결된 영상 모델은 아직 받지 않습니다.’). 끝 모습을 정하고 싶으면 프레임을 2–4장 넣어 순서를 주거나, 25장 `샷별 카메라`의 `끝 화면`을 씁니다.
:::

::: tip TIP
프레임 없는 씬이 많으면 왼쪽 목록 아래의 `프레임 없는 씬 {n}개 후보 만들기`로 한 번에 만듭니다(씬마다 이미지 수와 예상 비용을 확인하는 창이 뜹니다). 같은 장소·시간에서 바로 이어지는 씬이면 스토리보드의 시작 이미지 칸에서 `앞 씬과 이어짐`을 켜고 `앞 씬 끝 장면으로 시작`을 누르면, 앞 씬 영상의 끝 무렵 장면이 이 씬의 첫 프레임이 됩니다.
:::

## PRACTICE — 씬 1 시작 프레임

`프롬프트`를 아래처럼 정지 화면용으로 고치고 `이미지 수`를 4장(모델이 허용하는 만큼)으로 해서 후보를 만듭니다.

```text
비 오는 밤의 도시 버스 정류장. @수아 가 우산 없이 어깨를 움츠린 채 혼자 서 있다.
젖은 아스팔트에 가로등 빛이 번진다. 와이드, 눈높이, 차가운 푸른 밤빛, 영화 같은 실사.
```

후보를 고를 때는 10장 체크리스트(얼굴·의상·배경)와 1장 비교표(장소·인물·빛·카메라·분위기)로 판단합니다. 고른 1장을 `프레임에 추가` → `이 프레임으로 영상 만들기`.

| (이미지 삽입 자리 — 캡션에 모델·비율·크레딧 표기) |

::: cost COST · 비용
후보 한 장마다 이미지 요금이 듭니다. `생성` 버튼 옆의 예상 크레딧은 모델이 만드는 후보 수와 크기 기준이며, 실제로는 사용량으로 정산됩니다. 후보 일부만 만들어졌다면 ‘만들지 못한 후보는 크레딧이 차감되지 않았어요.’라고 안내합니다. `이미지 수`를 줄이면 비용도 줄어듭니다. 그래도 영상을 여러 번 다시 만드는 것보다는 대개 저렴합니다.
:::

## REVIEW — 제대로 했나요?

- [ ] 씬 1의 상태가 `프레임 1장`이다.
- [ ] 프레임 1장과 2–4장, 샷별 프레임의 차이를 안다.
- [ ] 끝 프레임 지정은 아직 없다는 것을 안다.

| 자주 겪는 실패 | 화면 문구 | 해결 |
| --- | --- | --- |
| 가격 미정 모델 | 이 모델의 가격이 아직 정해지지 않았어요. 잠시 뒤 다시 시도하세요. | 다른 모델 선택 |
| 크레딧 부족 | 크레딧이 부족해요. 충전한 뒤 다시 시도하세요. | 충전 또는 `이미지 수` 줄이기 |
| 모델이 자주 실패 | 최근 오류 잦음 | 다른 모델 선택 |
| 모델에 요청이 몰림 | 이 AI 모델에 요청이 몰려 10분 동안 다시 보냈지만 생성하지 못했어요. 크레딧은 차감되지 않았어요. | 잠시 후 다시, 또는 다른 모델 |
| 참조 이미지가 없음 | 일부 @ 참조에 아직 이미지가 없어요 | 안내에 나온 이름을 눌러 이미지를 먼저 만들기 |
| 후보마다 얼굴이 다름 | — | 씬에 등장인물이 연결됐는지, 등장인물에 대표 이미지가 있는지 확인 |
| 프레임과 다른 모습으로 시작 | — | `이 프레임으로 영상 만들기`를 눌렀는지 확인 |

**확인 문제** 1) 프레임은 최대 몇 장까지 넣을 수 있나요? 2) 프레임을 영상에 연결하는 버튼은? 3) 마음에 들지 않는 후보 이미지를 지우면 어디로 가나요?

정답: 1) 4장 2) `이 프레임으로 영상 만들기` 3) 작품 정보의 휴지통(보관 기간 안에는 복원 가능)

**응용 과제** — 씬 3에 프레임 2장(두 사람 서 있음 → 버스 도착)을 순서대로 넣어, 영상이 그 흐름을 따르도록 계획해 보세요. 씬 3을 샷 2개로 나눴다면 각 프레임이 어느 샷의 시작인지도 확인해 보세요.
