# 파트너사 강의 진행 가이드

강의의 성패는 수업 전 준비에서 갈립니다. 특히 모델 목록, 크레딧, 브라우저 렌더 세 가지를 미리 확인해야 합니다.

## 수업 전 점검

- [ ] 수강생별 Google 계정 준비 (FECINE은 Google 로그인만 지원)
- [ ] 강사 계정으로 `스토리보드` > `모델` 탭을 열어, 수업에서 쓸 영상 모델이 `사용 가능`인지 확인 (모델 목록은 서버 설정·워크스페이스별로 다름)
- [ ] 수강생 1인당 예상 크레딧 계산: 가입 시 10 크레딧, 씬 영상은 `약 {n} 크레딧` 표시로 확인, 합친 영상 내보내기 기본 3 크레딧(공개 캐릭터·목소리를 작품에 추가하면 사용료 별도)
- [ ] 실습용 PC에 최신 크롬·엣지·사파리 설치 (내보내기 렌더는 수강생 브라우저에서 실행)
- [ ] 예제 대본 파일(.txt)과 예제 프롬프트 문서를 공유 폴더에 배포
- [ ] 영상 생성 대기 시간을 채울 예비 활동(기획 메모 발표, 프롬프트 고치기) 준비
- [ ] 팀 단위 실습이면 강사가 사이드 메뉴 `팀`에서 `회원 UID`로 수강생 초대 (수강생은 아바타 메뉴에서 UID 복사)
- [ ] 충전 권한 확인: 개인 스튜디오는 소유자, 회사 스튜디오는 기업관리자만 크레딧을 충전할 수 있음

## 2시간 온보딩 특강 진행안

## 강사가 자주 받는 질문

| 질문 | 답변 |
| --- | --- |
| ‘새 작품’을 눌렀는데 입력창이 안 나와요 | 정상입니다. ‘새 작품’이 바로 만들어지고, 제목·설정은 `작품정보`에서 바꿉니다 |
| 목소리를 AI로 만들 수 있나요? | 대사를 입력하고 `사운드`를 `음성 있음`으로 두면 영상 모델이 함께 만듭니다. 별도 음성 합성 기능 여부는 <Badge type="warning" text="확인 필요" /> |
| 내 유튜브 채널에 바로 올릴 수 있나요? | 아니요. `채널` 탭은 FECINE 공식 채널 게시 요청입니다. 내 채널에는 다운로드한 MP4를 올립니다 |
| 모델 목록이 교재와 달라요 | 워크스페이스·요금 설정에 따라 달라집니다. `사용 가능` 표시가 있는 모델로 진행합니다 |
| 렌더가 멈췄어요 | 탭을 닫거나 절전 모드가 되면 멈춥니다. `이어서 진행`을 누르고, 실패한 내보내기는 크레딧이 차감되지 않습니다 |

| 시간 | 내용 | 교재 | 강사 포인트 |
| --- | --- | --- | --- |
| 0:00–0:15 | AI 영상 제작 개념, 홈페이지 제작 흐름 | 1장, 14장 | ‘긴 영상 = 짧은 씬의 연결’을 먼저 각인 |
| 0:15–0:30 | 로그인, 기본 화면, 크레딧 확인 | 15장, 13장 | 전원이 `크레딧 잔액`을 확인한 뒤 다음으로 |
| 0:30–1:20 | 튜토리얼 작품 5단계 따라 하기 <Badge type="warning" text="튜토리얼 제공 여부 확인 필요" /> | 15장 | 생성 대기 중 `AI 작업`으로 진행 상황 보는 법 설명 |
| 1:20–1:45 | 편집에서 씬 잇기, 내보내기 | 28, 30장 | 렌더 중 탭을 닫지 않도록 반복 안내 |
| 1:45–2:00 | 실패 사례 공유, 질의응답, 다음 학습 안내 | 32장 | 남은 크레딧으로 할 수 있는 과제 제시 |

버전이 올라가면(예: 검토 모듈 공개) 부록 A·D와 해당 장만 고치면 되도록, 기능별 설명을 장 단위로 묶어 두었습니다.
