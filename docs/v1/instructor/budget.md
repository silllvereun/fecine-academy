# 수업 예산 짜기

FECINE으로 수업을 하면 AI 생성과 내보내기에 크레딧이 듭니다. 이 페이지는 수업 전에 **수강생 1인당 예산**과 **운영 방식**을 정하는 틀입니다. 금액은 실습 결과물을 실제로 만들며 측정한 값을 채워 넣을 예정입니다.

::: warning 금액에 대하여
아래 표의 크레딧 칸은 아직 비어 있습니다. 교재 예제를 FECINE에서 실제로 만들며 측정한 값으로 채웁니다. 그 전까지는 FECINE 화면에 표시되는 예상 크레딧과 [부록 A](/v1/appendix/a-models-cost)의 요금으로 계산하세요. <Badge type="warning" text="자료 준비 중" />
:::

## 1. 크레딧은 누구의 것인가

| 사실 (FECINE v1.38.0) | 수업에 주는 의미 |
| --- | --- |
| AI 생성에는 **워크스페이스**의 크레딧 잔액이 쓰입니다. | 한 워크스페이스에 여러 수강생이 있으면 잔액을 함께 씁니다. |
| 크레딧 충전은 **워크스페이스 소유자**만 할 수 있습니다. | 수강생은 직접 충전할 수 없습니다. 강사나 기관이 충전을 맡습니다. |
| 팀은 회원 UID로 초대하고, 역할은 관리자 · 멤버(초대 화면에서는 ‘편집자’) · 뷰어입니다. | 뷰어는 작품을 볼 수만 있습니다. 실습하는 수강생은 멤버로 초대합니다. |
| **사용량·결제**에서 작품별 사용량과 원장(누가 · 무엇에 · 얼마)을 볼 수 있습니다. | 수강생마다 작품을 따로 만들게 하면 1인당 사용량을 확인하기 쉽습니다. |
| 가입하면 개인 스튜디오가 생기고 무료 크레딧이 지급됩니다(금액은 운영 설정). | 짧은 체험 수업은 각자 개인 스튜디오의 가입 크레딧으로 할 수도 있습니다. |
| 충전은 카드(운영 설정에 따라 숨김) 또는 무통장입금(입금 기한 72시간, 자동 확인)입니다. | 기관 결제는 입금 확인 시간까지 고려해 수업 며칠 전에 충전합니다. |

## 2. 운영 방식 고르기

| 방식 | 진행 | 크레딧을 쓰는 사람 | 맞는 수업 |
| --- | --- | --- | --- |
| 시연형 | 생성은 강사가 화면으로 보여 주고, 수강생은 무료 단계(기획·장면 구성·편집)를 직접 함 | 강사만 | 1회 특강, 입문 체험 |
| 공유 워크스페이스형 | 강사의 워크스페이스에 수강생을 멤버로 초대해 같은 잔액을 씀 | 강사가 충전한 잔액을 함께 | 정규 과정, 기관 수업 |
| 개인 스튜디오형 | 수강생이 각자 가입 크레딧·충전으로 실습 | 수강생 각자 | 자율 학습, 온라인 과정 |

::: tip TIP
공유 워크스페이스형은 잔액이 한꺼번에 줄어들 수 있습니다. 수업 첫 시간에 [31장](/v1/chapters/31-saving-credits)의 “아끼는 순서”와 [무료로 해 볼 수 있는 범위](/guide/free)를 함께 안내하고, 장면당 테이크 수를 정해 두세요.
:::

## 3. 1인당 예산 계산 틀

[13장](/v1/chapters/13-credits-and-cost)과 [31장](/v1/chapters/31-saving-credits)의 예산 식을 수업 단위로 옮긴 표입니다. **절약형**은 테스트를 낮은 해상도·짧은 길이로 하고 장면당 테이크를 1–2개로, **권장형**은 장면당 테이크를 2–3개로 잡습니다.

| 항목 | 절약형 수량 | 권장형 수량 | 단가 (크레딧) | 절약형 소계 | 권장형 소계 |
| --- | --- | --- | --- | --- | --- |
| 캐릭터 대표 이미지 | 2명 × 후보 1장 | 2명 × 후보 2장 | | | |
| 캐릭터 시트 | 없음 | 주인공 1명 | | | |
| 배경·소품 | 2장 | 2장 | | | |
| 장면 프레임 후보 | 3장면 × 1장 | 3장면 × 4장 | | | |
| 장면 영상 | 3장면 × 1–2회 | 3장면 × 2–3회 | | | |
| 텍스트 AI(원고·프롬프트) | 선택 | 사용 | | | |
| 내보내기 | 1회 | 1–2회 | | | |
| **「비 오는 정류장」 1편 합계** | | | | | |

| 여유분 (재생성·실수) | 합계의 20–30% 권장 | | | | |

## 4. 수업 전 점검표

- [ ] 운영 방식(시연형 · 공유 워크스페이스형 · 개인 스튜디오형)을 정했다.
- [ ] 수강생 수 × 1인당 예산 + 여유분으로 총 예산을 계산했다.
- [ ] 워크스페이스에 텍스트·이미지·영상 모델이 열려 있는지 확인했다(모델이 없으면 관리자에게 요청).
- [ ] 수업 며칠 전에 충전을 마쳤다(무통장입금은 확인 시간 고려).
- [ ] 수강생을 멤버로 초대하고, 작품을 1인 1개로 만들게 안내했다.
- [ ] 장면당 테이크 수와 테스트 해상도 규칙을 공지했다.
- [ ] 수업 후 **사용량·결제**의 작품별 사용과 원장으로 실제 사용량을 확인할 계획을 세웠다.

## 5. 수업 중 자주 생기는 일

| 상황 | 화면 문구 | 대처 |
| --- | --- | --- |
| 수강생이 충전하려 함 | 크레딧 충전은 워크스페이스 소유자만 할 수 있습니다. … | 강사가 충전하거나 운영 방식을 안내 |
| 잔액이 바닥남 | 크레딧이 부족합니다. 충전 후 다시 생성하세요. | 남은 시간은 무료 단계(편집·장면 구성)로 진행 |
| 같은 장면을 계속 재생성 | (원장에 같은 장면이 반복) | 테이크 피드백으로 원인을 하나 고르고 그것만 바꾸게 지도([27장](/v1/chapters/27-video-generation)) |
| 생성이 오래 걸림 | 영상 렌더링 중… | 예상 시간을 보고 다음 장면 준비를 병행. 기다리는 동안 다른 장면의 장면 구성 |
