# PART 06. 영상 완성하기

장면을 한 편으로 편집하고 자막·음악을 넣어 파일로 내보냅니다.

### [28장 편집: 장면 잇기·트림·전환](/v1/chapters/28-editing)

> 좋은 테이크를 모았는데, 이어 붙이니 왜 어색할까요?

- 컷 길이와 전환이 이야기의 리듬을 만든다는 것을 이해합니다.
- 장면을 타임라인에 놓고, 쓸 테이크를 고르고, 앞뒤를 잘라 냅니다.
- 편집한 결과를 편집본으로 저장합니다.

**완성 결과물** 「비 오는 정류장」 편집본 v1 (캡처 23-01)

### [29장 자막·음악·제목 카드·색보정](/v1/chapters/29-subtitles-music-cards)

> 영상은 좋은데 왜 '완성된 작품'처럼 보이지 않을까요?

- 자막을 읽기 쉽게 넣고 위치·크기를 다듬습니다.
- 배경음악과 효과음을 넣고 음량을 맞춥니다.
- 제목 카드·엔딩 카드와 색보정으로 작품의 통일감을 만듭니다.

**완성 결과물** 「비 오는 정류장」 편집본 v2 (자막·빗소리·배경음악·제목/엔딩 카드·따뜻한 룩)

### [30장 내보내기·다운로드·게시 요청](/v1/chapters/30-export-publish)

> 완성한 영상을 YouTube에 올릴 때와 Shorts에 올릴 때, 같은 파일을 써도 될까요?

- 코덱·비율·해상도가 무엇인지, 플랫폼마다 무엇이 다른지 이해합니다.
- 출력 프리셋을 골라 렌더(편집본을 영상 파일 하나로 만드는 일)하고 파일을 내려받습니다.
- 장면 하나만 받기, 로고 없이 받기, FECINE 공식 채널에 게시 요청하기를 구분합니다.

**완성 결과물** 「비 오는 정류장」 완성 MP4 (결과 30-A, 캡처 25-01)
