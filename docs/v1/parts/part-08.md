# PART 08. 활용과 문제 해결

비용을 관리하고, 막혔을 때 원인을 찾고, 결과물을 스스로 평가합니다.

### [31장 크레딧 아끼는 제작 습관](/v1/chapters/31-saving-credits)

> 다 만들고 보니 예상보다 크레딧을 훨씬 많이 썼습니다. 어디서 새었을까요?

- 무료 작업과 유료 작업을 구분합니다.
- 작품 하나의 예산을 미리 계산하고, 크레딧 · 사용량 화면에서 실제 사용과 비교합니다.
- 크레딧을 아끼는 제작 순서를 습관으로 만듭니다.

**완성 결과물** 내 작품 예산 점검표

### [32장 초보자가 겪는 실패 상황](/v1/chapters/32-troubleshooting)

> 버튼을 눌렀는데 아무 일도 일어나지 않거나, 빨간 문구가 떴습니다. 어디부터 봐야 할까요?

- 막혔을 때 확인하는 순서 5단계를 익힙니다.
- AI 작업과 알림에서 진행·실패를 확인합니다.
- 자주 보는 화면 문구와 해결 방법을 한 장으로 정리합니다.

**완성 결과물** 문제 해결 카드 (한 장 요약)

### [33장 품질 높이기와 셀프 리뷰](/v1/chapters/33-quality-review)

> 내 작품이 어디가 부족한지 어떻게 알 수 있을까요?

- 완성한 영상을 다섯 가지 축으로 나눠 봅니다.
- 결과가 아니라 원인을 찾고, 그 원인을 고칠 화면으로 돌아갑니다.
- 실습 1–3을 같은 기준으로 채점합니다.

**완성 결과물** 실습 1–3 셀프 리뷰표
