# Text-to-Image · Image-to-Video · Text-to-Video

<ChapterGoals />

## WHY — 같은 장면인데 왜 만드는 방법이 여러 가지일까요?

> 글만 써서 영상을 만들 수도 있고, 그림을 먼저 그린 뒤 영상을 만들 수도 있습니다. 무엇이 다를까요?

생성형 AI는 **무엇을 넣고(입력), 무엇을 받는지(출력)**에 따라 이름이 붙습니다. 방식마다 잘하는 일과 통제할 수 있는 정도가 다릅니다. [8장](/v1/chapters/08-how-ai-generates)에서 AI가 그림을 만드는 원리를 배웠다면, 이 페이지에서는 그 원리가 **어떤 입력으로** 쓰이는지 정리합니다.

- T2I · I2I · T2V · I2V를 입력과 출력으로 구분한다.
- FECINE의 각 단계가 어떤 생성 방식인지 안다.
- 씬마다 어떤 방식으로 만들지 고른다.

**완성 결과물** 「비 오는 정류장」 씬별 생성 방식 계획표

## HOW — 입력과 출력으로 나누기

### 네 가지 기본 방식

| 방식 | 입력 → 출력 | 장점 | 약점 |
| --- | --- | --- | --- |
| Text-to-Image (T2I) | 글 → 그림 | 빠르고 싸게 여러 안을 볼 수 있음 | 같은 인물을 다시 그리기 어려움 |
| Image-to-Image (I2I) · 참조 기반 | 글 + 그림 → 그림 | 참고한 그림의 얼굴·옷·구도를 이어 감 | 참고 그림의 품질에 결과가 묶임 |
| Text-to-Video (T2V) | 글 → 영상 | 준비 없이 바로 움직임을 봄 | 인물·배경이 매번 달라지기 쉬움 |
| Image-to-Video (I2V) | 그림(+ 글) → 영상 | 첫 화면을 정할 수 있어 결과가 안정됨 | 그림을 먼저 만들어야 함 |

영상에서는 그림을 **첫 프레임**(시작 화면)으로 쓰는 방식과, 그림을 **참조**(외형을 참고)로만 쓰는 방식을 나누어 생각하면 좋습니다.

| 그림의 역할 | 뜻 | 결과 |
| --- | --- | --- |
| 첫 프레임 | 영상이 그 그림에서 시작함 | 구도·인물·배경이 그대로 시작됨 |
| 참조 | 그림 속 얼굴·옷·장소를 참고만 함 | 구도는 모델이 정하고 외형만 이어 감 |
| 연속 프레임(키프레임 여러 장) | 여러 그림을 순서대로 지나감 | 장면의 흐름을 더 세밀하게 정함 |

### FECINE에서는 어떤 방식인가

| 하는 일 | 방식 | 화면 | 장 |
| --- | --- | --- | --- |
| 등장인물·배경·소품 대표 이미지 만들기 | T2I | **등장인물** > **새 등장인물**(배경·소품은 **공간·배경**·**미술·소품**) > 생성 | [20](/v1/chapters/20-characters)·[21](/v1/chapters/21-backgrounds-props) |
| 참고 이미지를 붙여 만들기, 이미지 고치기 | I2I · 참조 | 새 디자인의 **참고 이미지**(최대 4장), 상세 화면의 이미지 편집 | 20 |
| 캐릭터 시트(정면·측면·후면·표정) | I2I · 참조 | **캐릭터 시트** — 대표 이미지를 참조 | [22](/v1/chapters/22-character-sheets) |
| 샷 이미지 후보 | I2I · 참조 | **샷 이미지** — 씬에 연결된 디자인을 자동 참조 | [26](/v1/chapters/26-scene-frames) |
| 씬 영상 (샷 이미지 1장) | I2V | 샷 이미지가 영상의 **첫 프레임** | [26](/v1/chapters/26-scene-frames)·[27](/v1/chapters/27-video-generation) |
| 씬 영상 (샷 이미지 2–4장) | 연속 프레임 | 프레임을 순서대로 따라감 | 26 |
| 씬 영상 (샷 이미지 없음) | 참조 기반 영상 | 등장인물·배경·소품·콘티를 참조로 사용 | [24](/v1/chapters/24-storyboard)·27 |
| 참고 영상 만들기 | T2V | **콘티** > **참고 영상** 탭 — 프롬프트만으로 만들고 작품의 스타일이 함께 적용됨 | 21 |

::: info NOTE
모델마다 받을 수 있는 이미지 수가 다릅니다. 예를 들어 Kling v3는 이미지를 1장만 받고 그 이미지를 항상 첫 프레임으로 씁니다. 그래서 FECINE은 참조 이미지를 1장만 쓰는 모델에는 샷 이미지를 먼저 만들라고 안내합니다(`샷 이미지 만들기`). 모델별 값은 [부록 A](/v1/appendix/a-models-cost)를 보세요.
:::

::: tip TIP
처음에는 **T2I로 인물·장소를 고정 → 샷 이미지 → I2V** 순서가 가장 안정적입니다. 이 책의 예제가 이 순서를 따릅니다. T2V는 분위기를 빠르게 확인하거나 참고 영상을 만들 때 씁니다.
:::

:::

## REVIEW — 제대로 했나요?

- [ ] 네 가지 방식을 입력과 출력으로 설명할 수 있다.
- [ ] 첫 프레임과 참조의 차이를 안다.
- [ ] 씬별 생성 방식 계획표를 채웠다.

| 상황 | 화면 문구 | 해결 |
| --- | --- | --- |
| 이미지 1장만 받는 모델에 참조가 여러 개 | 이 모델은 이미지를 1장만 받아요. 참조를 하나만 남기고 다시 시도해 주세요. | 샷 이미지 1장을 만들거나 다른 모델 고르기 |
| 참조할 이미지가 아직 없음 | 일부 @ 참조에 아직 이미지가 없습니다 | 참조 항목의 이미지를 먼저 생성 |
| 끝 화면을 정하고 싶음 | (끝 프레임 지정 기능 없음) | 샷 이미지 2–4장으로 순서 지정 ([부록 D](/v1/appendix/d-future)) |

**확인 문제**

1. 그림을 넣어 영상을 만드는 방식의 이름은?
2. FECINE에서 샷 이미지를 1장 넣으면 그 그림은 영상에서 어떤 역할을 하나요?
3. 같은 인물을 여러 장면에 등장시키기 가장 어려운 방식은?

정답: 1. Image-to-Video (I2V) 2. 첫 프레임 3. Text-to-Video (T2V)

**응용 과제** 씬 1을 샷 이미지 없이 한 번, 샷 이미지 1장으로 한 번 생성하고(테이크 2개), **대비 바뀐 점**과 결과를 비교해 보세요.
