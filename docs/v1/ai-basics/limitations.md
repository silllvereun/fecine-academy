# AI 생성 영상의 기술적 한계

<ChapterGoals />

## WHY — 프롬프트를 아무리 고쳐도 안 되는 것이 있을까요?

> 손가락이 여섯 개가 되고, 우산 손잡이가 사라지고, 버스 옆 글자는 알아볼 수 없습니다. 프롬프트를 열 번 고쳐도 그대로입니다.

AI 영상에는 **입력을 고치면 나아지는 문제**와 **지금 기술로는 피하기 어려운 한계**가 섞여 있습니다. 둘을 구분하지 못하면 같은 조건으로 재생성을 되풀이하며 크레딧만 쓰게 됩니다. 한계를 미리 알면 **그 한계가 드러나지 않게 기획하고 편집**할 수 있습니다.

- AI 영상의 대표적인 한계 일곱 가지를 안다.
- 결과의 문제가 한계 때문인지, 입력 때문인지 구분한다.
- 한계를 기획·연출·편집으로 피해 가는 방법을 고른다.

**완성 결과물** 「비 오는 정류장」 한계 점검표

## HOW — 한계와 이유, 피하는 법

### 일곱 가지 대표 한계

| 한계 | 나타나는 모습 | 이유 (요약) | 피하는 법 |
| --- | --- | --- | --- |
| 길이 | 한 번에 수 초~수십 초까지만 생성 | 길수록 계산량이 커지고 일관성이 무너짐 | 장면을 나누고 편집으로 잇기 ([3장](/v1/chapters/03-shot-cut-scene-sequence)) |
| 일관성 | 장면마다 얼굴·옷·배경이 조금씩 달라짐 | 장면을 매번 새로 만듦 ([8장](/v1/chapters/08-how-ai-generates)) | 참조 이미지·캐릭터 시트·장면 프레임 ([10장](/v1/chapters/10-consistency)) |
| 손·작은 물체 | 손가락 수, 쥐는 동작, 손잡이가 어색함 | 자주 가려지고 모양이 다양해 학습이 어려움 | 손을 크게 보여 주는 샷 피하기, 동작을 단순하게 |
| 글자 | 간판·자막 글자가 깨지거나 엉뚱한 글자가 나옴 | 글자를 ‘모양’으로 그림 | 화면 글자는 편집의 자막·카드로 넣기 ([29장](/v1/chapters/29-subtitles-music-cards)) |
| 물리·복잡한 동작 | 물체가 통과하거나, 여러 사람의 동작이 엉킴 | 물리 법칙을 계산하지 않고 ‘그럴듯한 모습’을 그림 | 샷마다 동작 하나, 등장인물 수 줄이기 |
| 립싱크 | 입 모양과 대사가 어긋남 | 모델마다 수준이 다름 | 대사를 짧게, 옆모습·뒷모습·먼 샷에 대사 두기 ([실습 3](/v1/chapters/project-3-short-film)) |
| 지시의 정확도 | 카메라 움직임·순서가 지시와 다름 | 모델이 지시를 확률적으로 따름 | 지시를 하나씩, 장면 프레임으로 시작 고정 |

### 입력 문제인지, 한계인지 구분하기

| 이런 경우는 입력을 고칩니다 | 이런 경우는 한계로 보고 피합니다 |
| --- | --- |
| 참조를 연결하지 않아 얼굴이 바뀜 | 참조를 연결했는데도 손가락이 어색함 |
| 프롬프트에 서로 다른 지시가 있음 | 지시를 하나로 줄였는데도 글자가 깨짐 |
| 모델이 받지 않는 입력(음성·이미지 수)을 넣음 | 같은 조건으로 두 번 만들어도 같은 문제가 반복됨 |

같은 조건으로 **두 번** 만들어도 같은 문제가 나오면, 세 번째를 누르기 전에 기획이나 편집으로 피할 방법을 먼저 찾습니다([32장](/v1/chapters/32-troubleshooting)).

### FECINE에서 확인하기

1. 테이크의 **이 테이크 어땠나요?**에서 **아쉬워요**를 누르고 이유를 고릅니다. **스타일이 다름** · **얼굴·의상이 바뀜** · **움직임이 어색함** · **카메라가 지시와 다름** · **글자·워터마크** · **소리** 가운데 하나를 고르면 고칠 탭을 안내받습니다([27장](/v1/chapters/27-video-generation)).
2. **생성 정보**의 **대비 바뀐 점**으로 이전 테이크와 무엇이 달랐는지 확인합니다. 바뀐 것이 없는데 결과가 다르면 생성의 무작위성입니다.
3. 모델의 길이·해상도·참조 수 한도는 모델 탭과 [부록 A](/v1/appendix/a-models-cost)에서 확인합니다.

::: info NOTE
FECINE v1.38.0 기준으로 지원하지 않는 것도 한계로 알아 두세요.
- 끝 프레임을 지정할 수 없습니다. 장면 프레임 2–4장으로 순서를 정하거나 샷별 카메라의 **끝 화면**으로 대신합니다.
- 목소리를 새로 만드는 음성 합성(TTS)과 음악 생성, 단독 립싱크 기능이 없습니다.
- 자막의 음성 인식·자동 번역이 없습니다.

자세한 내용과 대안은 [부록 D](/v1/appendix/d-future)에 있습니다.
:::

안전 정책에 걸리는 요청은 생성되지 않습니다. `콘텐츠 안전 필터에 의해 요청이 차단되었습니다.`가 나오면 프롬프트·대사·참고 이미지를 고칩니다. 캐릭터 시트에서는 `안전 정책으로 거절됐어요. 다른 모델로 다시 시도해 보세요.`가 나올 수 있습니다([11장](/v1/chapters/11-evaluation-safety-copyright)).
:::

## REVIEW — 제대로 했나요?

- [ ] 일곱 가지 한계와 피하는 법을 말할 수 있다.
- [ ] 같은 문제가 두 번 나오면 멈추고 원인을 구분한다.
- [ ] 예제의 위험한 요소를 기획 단계에서 바꿨다.

| 상황 | 화면 문구 | 해결 |
| --- | --- | --- |
| 요청이 차단됨 | 콘텐츠 안전 필터에 의해 요청이 차단되었습니다. | 프롬프트·대사·참고 이미지 수정 |
| 화면에 이상한 글자 | (테이크 결과) | 프롬프트에서 글자 표현 빼기, 글자는 자막·카드로 |
| 원하는 길이보다 짧게만 만들어짐 | (모델 길이 범위) | 장면을 나누거나 더 긴 길이를 받는 모델 고르기 |
| 끝 모습을 고정하고 싶음 | (끝 프레임 없음) | 장면 프레임 2–4장, 샷별 카메라 끝 화면 |

**확인 문제**

1. 간판 글자가 계속 깨질 때 가장 좋은 해결은?
2. 참조를 연결했는데도 같은 문제가 두 번 나오면 먼저 할 일은?
3. FECINE v1.38.0에서 끝 프레임 대신 쓸 수 있는 방법 두 가지는?

정답: 1. 화면 속 글자를 빼고 편집의 자막·카드로 넣는다. 2. 재생성을 멈추고 기획·편집으로 피할 방법을 찾는다. 3. 장면 프레임 2–4장으로 순서 지정, 샷별 카메라의 끝 화면.

**응용 과제** 실습 2(제품 홍보 영상)의 네 장면에서 한계가 드러나기 쉬운 곳을 찾아, 연출을 어떻게 바꿀지 표로 정리해 보세요.
