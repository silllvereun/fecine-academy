# 멀티모달 AI

<ChapterGoals />

## WHY — 글, 그림, 목소리를 한꺼번에 넣으면 어떻게 될까요?

> 수아의 얼굴 사진, 목소리 파일, 장면 설명을 모두 넣었는데 어떤 모델은 목소리를 무시합니다. 왜일까요?

**모달리티**는 정보의 종류(글 · 그림 · 소리 · 영상)를 뜻합니다. 여러 종류를 함께 받아들이거나 만들어 내는 AI를 **멀티모달 AI**라고 합니다. AI 영상은 대표적인 멀티모달 작업입니다. 글로 장면을 설명하고, 그림으로 외형을 보여 주고, 소리로 목소리를 정해 **움직이는 그림과 소리**를 함께 받기 때문입니다.

- 멀티모달 AI가 무엇인지 입력·출력의 종류로 설명한다.
- FECINE에서 글·그림·소리를 함께 넣는 곳을 안다.
- 모델마다 받을 수 있는 입력이 다를 때 대처한다.

**완성 결과물** 「비 오는 정류장」 장면별 입력 구성표

## HOW — 여러 입력을 함께 쓰기

### 입력의 종류와 역할

| 입력 | 맡는 역할 | 예 |
| --- | --- | --- |
| 글 (프롬프트·대사) | 무엇이 일어나는지, 카메라·분위기, 말하는 내용 | “도윤이 우산을 내민다”, 대사 “같이 쓸래요?” |
| 그림 (참조 이미지·장면 프레임) | 누가, 어디서, 어떤 모습으로 | 수아 대표 이미지, 정류장 배경 |
| 소리 (참조 음성) | 어떤 목소리로 | 수아 목소리 파일 |

여러 입력이 서로 **같은 것을 말해야** 결과가 안정됩니다. 그림 속 수아는 어깨 길이의 생머리인데 프롬프트에 “짧은 단발”이라고 쓰면, 모델은 둘 중 하나를 고르거나 섞습니다.

### 출력도 여러 종류

영상 모델 가운데에는 그림과 함께 **소리(대사·효과음)**까지 만드는 모델이 있습니다. FECINE의 장면 영상 생성에서 **사운드**를 **음성 있음**으로 두면 소리를 함께 만들고, **무음**이면 영상만 만듭니다.

### FECINE에서 하기

| 입력 | 넣는 곳 | 장 |
| --- | --- | --- |
| 장면 설명·연출 | 스토리보드 **장면** 탭 **장면 설명 / 연출 의도**, **프롬프트** 탭 | [24](/v1/chapters/24-storyboard)·[25](/v1/chapters/25-camera-style) |
| 대사 | **장면** 탭 **대사 / 내레이션** (말하는 인물, 시작 시각) | 24 |
| 인물·장소·물건 그림 | **장면** 탭 **참고 레퍼런스**, 프롬프트의 @ 참조 | 24 |
| 시작 화면 그림 | **장면 프레임** | [26](/v1/chapters/26-scene-frames) |
| 목소리 | **오디오**에 업로드 → 캐릭터 연결. 그 캐릭터가 나오는 영상 생성에 함께 전달 | [23](/v1/chapters/23-character-voice) |
| 소리 출력 | **모델** 탭 **사운드**: 음성 있음 / 무음 | [27](/v1/chapters/27-video-generation) |

모델마다 받을 수 있는 입력의 종류와 수가 다릅니다(FECINE v1.38.0).

| 모델 | 받는 입력 (확인된 것) |
| --- | --- |
| Seedance 2.0 / 2.5 계열 | 참조 이미지 여러 장, 음성 생성 |
| Kling v3 | 이미지 1장(항상 첫 프레임), 참조 보이스 없음 |
| Wan 3.0 | 참조 이미지 최대 10장, 오디오 참조 최대 5개 |

자세한 값은 [부록 A](/v1/appendix/a-models-cost)와 [AI 모델 가이드](/v1/models/)에 있습니다.

::: warning 주의
다른 사람의 얼굴이나 목소리는 본인 동의 없이 참조로 쓰지 않습니다. 실존 인물을 쓰려면 본인 인증이 필요하며, v1.38.0에서는 Seedance VIP 모델에서만 쓰입니다([11장](/v1/chapters/11-evaluation-safety-copyright)).
:::

## PRACTICE — 장면별 입력 구성표

**실습 A2-1 입력 맞추기**

장면 2의 입력이 서로 같은 것을 말하는지 확인합니다.

| 입력 | 내용 | 다른 입력과 어긋나는 곳 |
| --- | --- | --- |
| 참조: 수아 대표 이미지 | 어깨 길이의 검은 생머리, 베이지 트렌치코트, 흰 니트 | |
| 참조: 도윤 대표 이미지 | 짧은 검은 머리, 네이비 코트, 검은 우산 | |
| 프롬프트 | 도윤이 수아에게 우산을 내민다 | |
| 대사 | 도윤: “같이 쓸래요?” | |
| 목소리 | 도윤 보이스 (연결했다면) | |
| 사운드 | 음성 있음 | |

**실습 A2-2 모델과 입력 확인**

| 장면 | 필요한 입력 | 고를 모델의 조건 |
| --- | --- | --- |
| 1 (대사 없음) | 장면 프레임 1장, 빗소리 | 이미지 1장만 받아도 됨 |
| 2 (대사 있음) | 인물 참조 2장, 대사, 목소리 | |
| 3 (대사 있음) | | |

::: cost COST · 비용
입력을 정리하는 것은 무료입니다. 입력이 어긋난 채 생성하면 재생성이 늘어나므로, 생성 전에 이 표를 채우는 것이 가장 큰 절약입니다.
:::

## REVIEW — 제대로 했나요?

- [ ] 모달리티와 멀티모달 AI를 설명할 수 있다.
- [ ] FECINE에서 글·그림·소리를 넣는 곳을 안다.
- [ ] 모델이 받는 입력을 확인하고 골랐다.

| 상황 | 화면 문구 | 해결 |
| --- | --- | --- |
| 참조 이미지가 너무 많음 | 이 모델은 참조 이미지를 n장만 사용할 수 있어요. | 참조를 줄이거나 더 많이 받는 모델 고르기 |
| 목소리를 쓸 수 없음 | 이 모델은 참조 음성을 사용할 수 없어요. | 음성을 받는 모델 고르기 |
| 이미지 1장 모델 + 음성이 있는 참조 | …음성 샘플이 있어 보낼 수 없어요. | 장면 프레임을 만들거나 음성을 받는 모델 고르기 |
| 얼굴이 참조와 다름 | (결과 차이) | 프롬프트의 외형 묘사를 참조 그림과 맞추기 |

**확인 문제**

1. 글·그림·소리처럼 정보의 종류를 무엇이라고 부르나요?
2. 장면 영상에서 소리를 함께 만들지 정하는 설정은?
3. 참조 그림과 프롬프트가 서로 다른 외형을 말하면 어떻게 되나요?

정답: 1. 모달리티 2. 모델 탭의 사운드(음성 있음 / 무음) 3. 모델이 하나를 고르거나 섞어서 결과가 흔들린다.

**응용 과제** 장면 2를 목소리 연결 없이 한 번, 도윤 보이스를 연결하고 한 번 생성해 목소리 차이를 비교해 보세요(음성을 받는 모델에서).
